## 2. 제어 구조: MPC 단독
- **토크 제어**로 한다.
- **슬립 제어기는 이번 단계에서 뺀다.** EST, DSD, GS, CTL, CPS 블록과 Δτ_slip 보상 경로가 빠지고, 제어는 MPC만으로 한다.
- **토크 상한**은 MPC 제약 |τᵢ| ≤ τ_max,i(t_k) ≤ τ_lim으로 넣는다. **식은 미정이다.**
  - 후보 ① μ 기반 마찰 한계: τ_max = μ·(mg/4)·r
  - 후보 ② MTTE 기반: T_max = k·r·F̂_d, k = 1 + J_w/(α·M_w·r²). 이 경우 ω와 전류가 제어 루프에 다시 들어간다.
- **슬립률**은 계산하되 **로깅 전용**이다(slip_logger). 제어로 되먹이지 않고, 슬립이 실제로 잡히는지 확인하는 데만 쓴다.
  - ω_nom = (1/r)·B·v̂
  - λᵢ = (ωᵢ − ωᵢ,nom)·sgn(ωᵢ,nom) / max(|ωᵢ|, |ωᵢ,nom|, ω_ε)
- **엔코더 ω**는 다음 세 곳에서 쓴다. 토크 상한을 MTTE 기반으로 정하면 상한 계산에도 쓰게 된다.
  - 슬립률 로깅
  - fault_monitor
  - 평가 지표 계산(토크 사용 에너지)
- **MPC**
  - 시간 레퍼런스 맵을 추종한다. 8자 경로 글로벌 플래너로 Xmap(t)·Ymap(t)를 0.01 s 간격 표로 미리 만든다.
  - 매 시각 t에는 차 위치와 관계없이 Xmap·Ymap의 [t, t + 예측구간] 구간을 레퍼런스로 읽는다(필기 예: 0초 → Xmap(0~1초), 10초 → Xmap(10~11초)).
  - 레퍼런스: ψ_ref = 경로 접선 방향(dY/dX), vy,ref = 0, vx,ref는 속도 프로파일, r_ref = vx·κ(곡률).
  - 비용함수는 6개 상태 전부를 맵 레퍼런스와 비교한다: J = Σ_m ‖x(k+m|k) − x_ref(k+m)‖²_Q + ‖τ‖²_R, x = [vx, vy, r, X, Y, ψ]. 위치 오차는 횡방향 오차가 아니라 전역 XY 좌표 오차로 둔다.
  - 매 스텝 현재 상태 기준으로 선형화한 뒤 이산화한다(Ts = 0.01 s).
- **속도 프로파일 (교수님 안)**: vx = 1 m/s (0~30 s) → 2 m/s (30~45 s) → 3 m/s (45~55 s). 30 m 8자를 속도별로 한 바퀴씩, 총 90 m를 55 s에 돈다.
- **질량**은 MPC 파라미터 m으로 둔다. 10 kg과 적재 20 kg을 비교한다.

## 3. 상태 추정: SLAM + IMU (칼만필터 개념을 변형)
- SLAM(라이다 오도메트리)은 10 Hz, 제어는 100 Hz다.
- SLAM 값이 들어오는 스텝에서는 그 값을 참으로 믿는다.
- 그 사이 9스텝은 마지막 SLAM 값에서 시작해 IMU 가속도로 속도와 위치를 적분한다.
- 다음 SLAM 값이 들어오면 리셋한다.
- 적분식(가속도계는 v̇ + ω×v를 측정하므로 이 형태가 된다):
  - v̇x = ax + ωz·vy
  - v̇y = ay − ωz·vx
  - ψ̇ = ωz
  - Ẋ = vx·cosψ − vy·sinψ
  - Ẏ = vx·sinψ + vy·cosψ
- 칼만필터에 대응시키면 측정 스텝은 게인이 1인 보정, 나머지 스텝은 예측만 하는 구조다.
- 교수님 필기에는 사이 구간을 모델로 전파하는 방법(x_{k+1} = A·x_k + B·u_k)도 같이 적혀 있다. IMU 적분의 대안이나 비교 대상으로 둘 수 있다.
- 필기에 적힌 슬립 추정 아이디어(SLAM 사이 구간에서 ω_v를 구하는 방법):
  - ① 휠 모델 J·ω̇ = τ − r·F_d를 이산화해서 ω를 예측(F_d는 직전 값 유지)
  - ② ω̇/τ로 슬립 유무만 판정
  - ③ 직전 ω_v를 그대로 사용(ZOH)
  - 지금은 IMU 적분으로 v̂가 100 Hz로 나오므로 ω_nom도 100 Hz로 계산된다.

## 4. 토크 입력 동역학 모델 (교수님 정리본)

**가정과 좌표계**
- 45° 롤러, X 배열이다.
- 슬립, 마찰, 구름저항, 휠 관성은 무시한다.
- 좌표계는 body frame이다: x 전방, y 좌측, yaw는 반시계 방향이 +.
- 휠 순서는 FL, FR, RL, RR이다.

**유도 관점 (필기)**: 일률 보존 Στᵢ·ωᵢ = F·v에서 F = Στω / v(ω₁…ω₄), a_pred = F/m. 바퀴 하나의 롤러 방향 힘은 F = τ/(R·cosα)이고, 성분은 Fx = τ/R, Fy = (τ/R)·tanα다(45°에서 크기가 같다).

**토크 → 힘**
- [Fx; Fy; Mz] = (1/R)·H·u
- H = [[1, 1, 1, 1], [−1, 1, 1, −1], [−L, L, −L, L]], L = a + b

**3-state 모델**, x = [vx, vy, r]
- v̇x = r·vy + (τFL + τFR + τRL + τRR)/(mR)
- v̇y = −r·vx + (−τFL + τFR + τRL − τRR)/(mR)
- ṙ = L(−τFL + τFR − τRL + τRR)/(Iz·R)

**6-state 모델**, x = [X, Y, ψ, vx, vy, r]
- 3-state 모델에 다음을 추가한다.
  - Ẋ = vx·cosψ − vy·sinψ
  - Ẏ = vx·sinψ + vy·cosψ
  - ψ̇ = r
- B6 = [0₃ₓ₄; B3]

**선형화**
- 3-state: Ac = [[0, r̄, v̄y], [−r̄, 0, −v̄x], [0, 0, 0]], Bc = B3
- 6-state는 ψ 편미분이 추가로 필요하다.
  - ∂Ẋ/∂ψ = −vx·sinψ − vy·cosψ
  - ∂Ẏ/∂ψ = vx·cosψ − vy·sinψ

**주의**
- null space [1, 1, −1, −1]이 있다. 앞바퀴와 뒷바퀴가 서로 반대로 미는 조합은 차체 운동에 영향이 없으므로, MPC에 토크 가중치 R이 필요하다.
- H의 부호는 롤러 배치와 모터 장착 방향에 따라 달라지므로 실차에서 확인해야 한다.
