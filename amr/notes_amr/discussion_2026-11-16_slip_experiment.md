## 1. 결정 — 기준은 속도 (교수님 지시)

- 기준 경로에는 **속도**를 입힌다. 가속도를 기준으로 바꾸지 않는다.
- 실험에서 바꾸는 손잡이는 **순항 속도**(`speed`, `lap_speeds`). 출발·정지 때 속도를 올리고 내리는 기울기(`accel`, 지금 0.40 m/s²)는 속도 기준 안의 값이고 실험 중에는 고정한다.
- 기준 메시지(PlanarReference) 한 줄은 위치·방향·속도(vx, vy, ω)뿐이다. 가속은 0.05 s 간격 줄 사이의 속도 차이로 MPC 가 알아서 계산한다.

## 2. 비교군 정리 (이해 맞춤)

| 비교군 | 제어기 | 토크 상한 | 값 (4.56 kg, μ̂ 0.3) |
|---|---|---|---|
| A | 퓨어 퍼슛 + 바퀴별 PI | 모터 한계 (B 와 같게, 공정 비교) | 1.2 N·m |
| B | MPC | 모터 한계 = 정격 1.3 − 마찰 보상 몫 0.1 | 1.2 N·m |
| C | MPC | 바닥 마찰 한계 τ_μ = (r/√2)·μ̂·(mg/4) | 약 0.076 N·m |

- 변화율 상한은 셋 다 크기 상한의 1/3.
- **B 와 C 의 MPC 모델은 둘 다 "슬립 없음"** 이다. C 도 슬립을 계산하지 않고, 상한으로 토크를 묶어 그 가정이 현실에서 맞도록 지킨다. 그래서 C 는 μ̂ 가 맞아야 한다(크게 잡으면 C 도 미끄러진다).
- 외란 추정치 d̂ 는 기본 끔 → 지금 B 는 슬립에 대해 아무것도 안 하는 순수 기준선.
- 실차 첫 8자(2026-11-14 밤)에서 B 가 옆걸음 힘을 바닥 한계(약 12 N)의 7 배인 86 N 까지 내 발산한 것이 "B 는 슬립을 고려하지 않는다" 의 실제 모습.

## 3. 바닥 마찰 한계 vs MTTE (자료: `amr/자료/MTTE 논문.pdf`, `MTTE 논문 리뷰.pdf` — Hu, Yin, Hori 2011)

| | 바닥 마찰 한계 τ_μ (지금 C) | MTTE |
|---|---|---|
| 계산 | μ̂ 로 미리 정한 고정값 | 달리는 중 F̂_d = (T − J_w·ω̇)/r → T_max = (J_w/(αMr²) + 1)·r·F̂_d |
| 필요 | μ̂ | 토크 명령, 바퀴 속도와 그 미분 ω̇, J_w (차체 속도·μ 는 필요 없음) |
| 바퀴별·시간별 | 네 바퀴 같음, 고정 | 바퀴마다, 매 순간 |
| μ̂ 가 틀릴 때 | 그대로 미끄러지거나 쓸데없이 느림 | 실제 바닥에 맞춰 낮아짐 |
| 첫 슬립 | μ̂ 가 맞으면 막음 | 미끄러지기 시작해야 앎 (반응형) |
| 약점 | μ̂ 의존 | ω̇ 잡음(필터 → 지연), J_w 에 민감 (논문은 PI 형 관측기로 보완) |

- 우리 로봇 숫자: J_w/(αMr²) ≈ 0.6 (J_w 8.9e-4, 바퀴당 약 1 kg, r 0.04, α 0.9). 논문 차량은 약 0.13 → **우리는 J_w 항이 크다**, J_w 가 틀리면 T_max 가 바로 틀어진다(팀원 벤치로 J_w 는 잼).
- ω̇ 양자화 잡음: 속도 한 칸 0.022 rad/s ÷ 10 ms = 2.2 rad/s² → J_w 곱해 약 0.002 N·m (C 상한의 3 %). 실제 속도 잡음은 실차 로그로 봐야 함 (`To do.md` "MTTE에 쓸 각가속도 잡음").
- 기존 계획(`torque_mpc_todo.md` "토크 상한 — 마찰 한계 + MTTE 병용"): τ̄ᵢ = min(모터 한계, τ_μ, τ_MTTE,i). 미구현, "나중에, 필요하면". 남은 설계 문제: MTTE 상한이 한 틱에 변화율보다 크게 떨어질 때 QP 해 없음(지금은 상한 우선), ω̇ 필터 대역.

## 4. "슬립 줄이면 속도 추종을 못 하는 트레이드오프인가" 에 대한 정리

- **토크는 속도가 아니라 가속(출발·정지·방향 꺾기)을 정한다.** 상한을 낮춰도 느려지는 게 아니라 급한 변화가 안 되는 것.
- **미끄러지는 바퀴는 오히려 힘을 덜 낸다** (μ–λ 곡선은 작은 슬립에서 최대). 슬립 나는 바퀴의 토크를 줄여 접지를 되찾으면 미는 힘이 커진다 → 마찰 한계 근처에서 슬립 제어는 추종을 돕는다.
- **MPC 는 다 같이 줄이지 않는다.** 상한 안에서 오차가 가장 작은 조합을 찾으므로 남은 바퀴 여유로 메운다(메카넘 4 바퀴 3 자유도).
- **진짜 트레이드오프는 기준 경로가 바닥이 줄 수 있는 것보다 많이 요구할 때뿐**(물리 한계). 그때 B 는 슬립, C 는 늦어짐을 택한다 → B·C 비교가 보여 주는 것. 해결은 기준 경로를 바닥 한계 안에서 만드는 것.

## 5. 등속 기준에서도 슬립이 나는 곳 — 코너

- 직선 등속: 바닥을 미는 힘은 구름 저항 정도(구동계 마찰은 torque_output 이 보상). 속도가 흔들리는 원인은 되먹임 보정(추정기 잡음, SLAM 10 Hz 보정 계단, 마찰 보상 90 % 의 남은 몫). B 는 이 보정 토크가 순간적으로 커져 바닥 한계를 넘을 수 있다(시뮬 μ 0.3 이탈).
- 곡선 등속: 속력이 일정해도 방향이 바뀌므로 구심 가속도 v²/R 이 계속 필요하다. 8자 최소 반경 0.31 m 에서:

| 순항 속도 | 0.3 m/s | 0.4 | 0.5 | 0.7 |
|---|---|---|---|---|
| v²/R | 0.29 m/s² | 0.52 | 0.80 | 1.58 |

- 속도 두 배 → 코너 힘 네 배. 8자는 헤딩이 접선을 따라 회전도 같이 하고, 실차에서 옆·회전은 앞뒤보다 약했다.
- **결론: 교수님 방식(속도 기준) 그대로, 순항 속도를 단계로 올리는 것이 곧 코너에서 바닥에 요구하는 힘을 올리는 것.**

## 6. 실차에서 느낀 것 (사용자, 2026-11-15) 과 해석

- 0.05 N·m 에서 거의 안 움직임 → 벤치 값과 맞음: 바퀴마다 구동계 쿨롱 마찰 약 0.02 N·m, 출발(정지 마찰) 0.04~0.1 N·m.
- 0.2 N·m 에서 토크가 셌고 슬립이 눈에 보임 → 두 가지가 섞였을 수 있다 (**미확인**):
  - 구동 슬립: 0.2 − 마찰 ≈ 0.18 N·m 가 바퀴당 바닥 한계(약 0.08~0.1 N·m, μ 0.3) 근처. 옆걸음 왼쪽 0.2 의 FL 헛돎이 이쪽.
  - **제동 슬립 (DAMPING)**: DAMPING 토크 = kd 0.02 × 바퀴 속도 → 10 rad/s(0.4 m/s)면 0.2 N·m, 20 rad/s 면 0.4 N·m. 바퀴 속도 약 4~5 rad/s(0.2 m/s) 위에서 DAMPING 으로 바뀌면 제동이 바닥 한계를 넘어 바퀴가 먼저 서고 차체가 미끄러진다. 0.2 N·m 로 0.7 s 밀면 그 속도를 넘는다.
- 가르는 법: 5-2 CSV(`tw1`·`lat1`·`diag1`·`rot1`)에서 바퀴 속도와 SLAM·IMU 속도가 벌어진 때가 **토크 구간**인지 **DAMPING 으로 바뀐 뒤**인지 본다.
- 의미: 실제 주행에서 fault_monitor 가 세울 때도 DAMPING 이 나가므로, 맞다면 비상 정지 때마다 미끄러진다.

## 7. 실험 계획 (후보) — "슬립이 거의 없는 곳에서 시작해 제어 가능한 슬립 범위로"

| 영역 | B 와 C |
|---|---|
| 한계보다 한참 아래 | 둘 다 슬립 없음, 비슷 |
| **한계 근처** | B 는 미끄러지기 시작, C 는 상한으로 버팀 → 차이가 보이는 곳 |
| 한계 위 | B 는 발산(첫 8자), C 는 늦어지지만 버팀 |

1. 개루프(5-2 보강): 토크를 0.05 → 0.08 → 0.1 → 0.12 → 0.15 → 0.2 처럼 한계 근처를 촘촘하게, 방향별 **슬립 시작 토크**.
2. 폐루프(5-3, 5-4): `accel` 고정, **순항 속도** 0.2 → 0.3 → 0.4 → 0.5 m/s. 판마다 기준 대비 실제 속도 흔들림, 추종 오차, 바퀴별 슬립률, 상한 포화 비율.
3. 슬립은 눈이 아니라 slip_logger 슬립률로. 잡음 바닥 약 0.1 위를 "슬립" 으로 정의해 판끼리 비교.
4. 구동 슬립과 제동 슬립을 따로 센다. 기본 동작 시험 도구에 "토크를 서서히 줄인 뒤 멈춤" 옵션을 두면 제동 슬립이 섞이지 않는다.
5. 슬립률이 잡음 바닥을 넘기 시작하는 순항 속도 = "제어 가능한 슬립 범위" 의 시작점 → 그 근처에서 B·C 비교.
