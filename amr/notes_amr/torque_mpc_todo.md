## 결정됨

- **비교군**: 발표 자료대로 A = 퓨어 퍼슛(기존), B = 토크 입력 MPC(슬립 대응 없음), C = MPC + 토크 상한(제안).
- **적재 조건**: 발표 자료대로 적재 없음 / +5 kg. 1판 문서의 m = 4 kg을 쓰면 4 kg / 9 kg이다.
  - 1판 문서의 예시값 10·20 kg은 이 조건으로 바꿔야 한다.
- **슬립률**: 구조도 정의를 쓴다. λᵢ = (ωᵢ − ωᵢ,nom)·sgn(ωᵢ,nom) / max(|ωᵢ|, |ωᵢ,nom|, ω_ε).
  - 발표 8쪽의 (ω_v,i − ωᵢ)/ωᵢ는 쓰지 않는다. 부호가 반대이고, 바퀴가 멈추면 발산한다.
- **토크 상한 위치**: MPC 입력 box 제약 |τᵢ| ≤ τ_max,i(t_k)로 넣는다.
  - 식은 미정이다. 마찰 한계와 MTTE를 둘 다 고려하는 방향으로 검토 중이다(아래 과제).
- **포즈 입력** (2026-11-11 변경): Cartographer 외삽을 끈다(`use_pose_extrapolator = false`). `/tracked_pose`는 스캔 매칭 결과만, 그 스캔 시각 stamp로 받는다. 스캔 사이 구간과 132 ms 지연은 state_estimator가 IMU 가속도 적분으로 메운다(`pose_source: stamped`). 이전 결정(2026-11-06, 외삽 포함 100 Hz 그대로 사용)을 대체한다 — 외삽된 값을 참값으로 쓰면 시뮬 폐루프가 발산했다.
- ~~**포즈 입력**: `/tracked_pose`를 지금 설정 그대로 쓴다(map 프레임, Cartographer 외삽 포함 100 Hz).~~ (2026-11-11 대체)
  - 따라서 MPC 상태 좌표계는 v3대로 map이다.
  - 전역 최적화 때의 포즈 튐은 fault_monitor의 "SLAM 포즈 튐 검사"로 감시한다.
- **선형화**: 기준궤적을 따라 한다. 1판 문서는 B 안의 R(θ_r)로 이미 이렇게 되어 있다.
- **마찰**: 구동계 마찰은 torque_output의 τ_fric(ω), 구름 저항 같은 나머지는 MPC 외란 추정치 d̂가 맡는다(1판 04절). 별도 과제는 없다.
- **슬립 제어기(PID)**: 이번 범위에서 뺀다(종설 후보).
- **노미널 MPC가 기본, 1판의 추가 항은 스위치** (2026-11-10 결정)
  - 기본은 10/28·10/29 방향대로 외란·불확실성을 고려하지 않는 노미널 MPC다.
  - d̂(외란 추정치·적분 작용): 파라미터 스위치, **기본 끔**. 정상상태 오차가 보이면 켜서 비교하는 실험용.
  - τ_fric(구동계 마찰 보상, torque_output): 구조는 두고 **기본값 0**. 벤치 측정 후 값을 넣을지 정한다.
  - J_w(모델의 바퀴 관성): 모델 스위치, **기본 끔**(10/29 모델의 "휠 관성 무시"). 값 9.7×10⁻⁴는 YAML에 남겨 MTTE 등에 쓴다.
  - 모든 값과 스위치는 패키지 `config/*.yaml` 한 곳에 둔다(기존 `plant_wheel.yaml` 방식).
- **MPC 실행 방식** (2026-11-11, 구현하며 정함 — 이의 있으면 바꿀 수 있다): torque_mpc_node는 타이머가 아니라 **상태 추정값 메시지가 올 때마다** 한 번 푼다. 추정값 나이가 틱마다 달라지지 않고, 명령 stamp가 그 추정값 시각 그대로라 종단 지연을 잴 수 있다. 추종 중이 아닐 때(기준·상태 끊김, hold, 종료)는 항상 DAMPING을 낸다.
- **스위치 위치** (2026-11-11): d̂ 켜기·끄기와 B/C 선택은 `config/torque_mpc.yaml`, 로봇·노면 값은 `config/torque_plant.yaml`. 한 번만 바꿀 때는 launch 인자(`limit_mode:=friction`, `disturbance:=true`, `mu_hat:=`, `payload_kg:=`, `ctrl_payload_kg:=`).
- **8자 트랙은 지도에 고정** (2026-11-11): 교차점 지도 좌표·방향은 `config/torque_track.yaml`. 로봇을 출발점 근처(30 cm·30° 안)에 놓고 무장하면 천천히 출발점으로 들어간 뒤 8자를 시작하고, 밖이면 출발을 거부한다. 8자 모양·속도도 같은 파일에 둔다(launch 인자로 한 번만 덮어쓸 수 있음).
- **비교군 B/C 선택**: torque_mpc_node 파라미터로 고른다(B = 모터 한계만, C = 마찰 한계 + MTTE). 메시지의 `mode`(TORQUE/DAMPING)는 정지 방식이고 B/C와 무관하다.

## 보류 — 실측 후 결정

- **속도 프로파일**: 잠정안은 8자 1바퀴마다 0.5 → 1.0 → 1.5 m/s(바퀴당 30 m면 110 s). 모터를 달고 속도를 측정한 뒤 확정한다.
  - 30 m 8자에서 1.5 m/s를 내려면 바퀴가 388~427 rpm이어야 한다(경로 모양에 따라 다름).
  - AK40-10 무부하 속도 추정치는 22.2 V에서 약 402 rpm이라 여유가 거의 없다.

### 문서 정합 (구조도 v3·1판 문서와 결정사항이 다른 곳)

- [ ] **토크 상한 — 마찰 한계 + MTTE 병용** (2026-11-06 병용 방향 동의). 아래 주의점(변화율 충돌, MTTE 필터, C 분할)은 나중에 정한다. ~~v3·1판 식-21의 "MTTE 폐기" 문구도 고쳐야 한다.~~ (옛 문서 무시) **(리뷰 0번) 코드의 C 는 τ_μ 만 쓰고 MTTE 는 없다 — 문구가 아니라 설계 결정으로 남김.**
  - 식: τ̄ᵢ(t_k) = min(τ_lim − τ_fric,max, τ_μ, τ_MTTE,i(t_k)), τ_μ = (r/√2)·μ̂·(mg/4)·c_s.
  - 역할 분담: τ_μ는 사전값(노면을 안다고 가정한 상한), τ_MTTE는 μ̂가 틀렸거나 국부적으로 미끄러울 때 바퀴별로 낮추는 온라인 보정이다.
  - [ ] 변화율 제약과의 충돌 처리
    - MTTE 상한이 한 스텝에 Δτ̄보다 크게 떨어지면 |τ₀| ≤ τ̄와 |τ₀ − τ_prev| ≤ Δτ̄를 동시에 만족할 수 없어 QP 해가 없다.
    - 첫 스텝은 상한을 우선하고 변화율 하한을 완화한다(l₀ = max(τ_prev − Δτ̄, −τ̄) 꼴로 교집합 보장).
  - [ ] MTTE 입력 필터: F̂_d = (τ − J_w·ω̇)/r 중 ω̇은 100 Hz 엔코더 미분이라 잡음이 크다. 필터 대역과 지연을 정한다.
  - [ ] 평가에서 C를 "τ_μ만"과 "τ_μ + MTTE"로 나눌지 정한다(선택).

### 측정 (1판 10절 목록 + 트랙)

- [ ] m: 저울. 적재 조건마다.
- [ ] I_z: CAD, 또는 제자리 회전 가속 시험. 적재 위치마다.
- [ ] J_w: 데이터시트 값 9.7×10⁻⁴ kg·m²를 바퀴를 띄운 가속 시험으로 확인한다. MTTE에도 쓰인다. — (2026-11-12) 팀원 벤치(`amr/notes_amr/CAN/BENCH_RESULTS_KO.md`): FL 8.65 / FR 8.89 / RL 9.18 / RR 8.76 ×10⁻⁴ (바퀴 장착·출력축 기준, 명령 토크 기준). 추정값과 10 % 안. FR·RL 은 중단된 판 일부라 재시험 뒤 닫기
  - 이 값은 사이트 관성 97.35 g·cm²를 **로터 기준**이라고 보고 기어비² (100)을 곱한 것이다.
  - 사이트 값이 이미 출력축 기준이면 J_w는 약 1/100이 되고, 바퀴 반영 질량 μ도 2.425 kg에서 약 0.02 kg으로 바뀐다(m_eff·τ̄·w 전부 영향).
- [ ] μ̂: 노면마다 토크 램프 시험.
- [ ] τ_fric(ω): 바퀴를 띄운 등속 시험. torque_output에 쓴다. — (2026-11-12 R2) 4개 평균을 `torque_plant.yaml` 에 넣고 시뮬 플랜트에도 같은 마찰을 넣음. 남은 것: 하중이 실린 바닥에서 보상 확인, 고속 구간 — (2026-11-12) 팀원 벤치: 쿨롱 τc 0.024~0.028 N·m, 점성 bv 0.0008~0.0024 N·m·s/rad (10 rad/s 까지, 무부하, 짧은 자극). C 상한 0.0666 의 약 40 % 라 무시 못 함. 고속 구간·재현성은 남음. `torque_plant.yaml friction` 반영은 R1·R2 에서
- [ ] AK40-10 무부하 속도: 속도 프로파일 확정용.
- [ ] 작은 토크의 정확도
  - 저 μ에서 τ̄는 0.067 N·m(4 kg)~0.150 N·m(9 kg)이다(μ̂ = 0.3). 전류로는 약 0.1~0.25 A다(토크상수 약 0.59 N·m/A 추정).
  - 이 범위에서 명령 토크와 실제 토크가 맞는지(선형성, τ_fric 보상 오차)를 확인한다.
