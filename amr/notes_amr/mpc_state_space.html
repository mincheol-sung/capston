메카넘 AMR 상태공간 모델

바퀴 네 개의 토크가 로봇의 위치를 어떻게 바꾸는지를, MPC 가 예측에 쓰는 행렬 그대로 정리했습니다. 숫자는 2026-11-28 기본값(torque_plant.yaml · torque_mpc.yaml)입니다.

1. 운동 방정식과 상태공간

Newton–Euler (manipulator form)

뜻

  • q = [x, y, θ]: 지도에서의 위치와 헤딩. 몸체 x 앞, y 왼쪽, θ 반시계 +.
  • 좌변은 유효 질량 × 가속도, 우변 첫 항은 바퀴 토크가 만든 힘입니다.
  • h 는 속도에 따라 붙는 항입니다(아래 5 절): 바퀴 관성의 회전 결합, 구동계 마찰, 롤러 구름 저항, 외란.
continuous-time state space

뜻

  • Ac 의 윗줄 I3: 위치의 미분이 속도(운동학). 아랫줄이 0: 속도는 힘으로만 바뀝니다.
  • Ac 는 3 자유도 이중 적분기이고, Ac² = 0 (nilpotent) 입니다.
  • 헤딩 θ 는 Bc 안의 R(θ) 로만 들어갑니다. MPC 는 θ 자리에 기준 헤딩 θr 를 넣어 지평 스텝마다 다른 B 를 씁니다(LTV).

2. 입력 행렬의 세 인수

r = 0.04 m, k = lx + ly = (0.1724 + 0.2140)/2 = 0.1932 m.

force map (mecanum configuration matrix)

행마다

  • 1행 앞 힘: 네 바퀴 모두 +. 같은 토크면 앞으로 갑니다.
  • 2행 옆 힘: FR·RL +, FL·RR −. 롤러가 45° 라 대각선 짝끼리 같은 부호입니다.
  • 3행 요 모멘트: 오른쪽(FR·RR) +, 왼쪽 −. 팔 길이 k.
  • 영공간 n = [1, 1, −1, −1]: Fn = 0. 앞·뒤 바퀴가 서로 미는 성분은 몸체를 움직이지 않습니다(입력 4 > 자유도 3).
rotation body → map

뜻

  • 몸체 좌표에서 만든 힘 [Fx, Fy] 를 지도 좌표로 돌립니다. 모멘트는 그대로.
  • 모델에서 유일한 헤딩 의존 부분입니다.
effective mass (reflected wheel inertia)

뜻

  • μ = 4Jw/r² = 4 × 8.9·10⁻⁴ / 0.04² = 2.225 kg: 바퀴 네 개의 회전 관성을 몸체 질량으로 옮긴 값.
  • 병진: 몸체 4.56 kg 에 2.225 kg 이 더해져 6.785 kg. 유효 질량의 33 % 가 바퀴입니다.
  • 회전: Iz 0.03 에 μk² 0.083 이 더해져 0.113 kg·m². 요 관성의 73 % 가 바퀴입니다.
input gain at θ = 0

숫자로 읽기

  • 한 바퀴에 1 N·m 를 주면 앞으로 3.68 m/s², 요 42.7 rad/s².
  • 네 바퀴에 같은 0.1 N·m 를 주면 앞 가속 4 × 0.368 = 1.47 m/s².
  • 검산: 코드의 Python 모델 TorquePlant.G(0) 과 손 계산 차이 0.

구동 방향 보정 MPC 는 F 의 앞·옆 두 행을 δ = 3.1° 돌려 씁니다(구동계 쪽 앞방향 어긋남 보정, 선회 계수 0.8). 위 숫자는 δ = 0 입니다.

3. 이산화 (MPC 가 실제로 쓰는 식)

ZOH discretization, LTV along reference

뜻

  • Ac² = 0 이라 eAcTs = I + AcTs 가 근사가 아니라 정확합니다. B 도 [Ts²/2·G ; Ts·G] 가 정확합니다(증강 행렬 지수와 차이 0).
  • 한 스텝에 토크 1 N·m 가 바꾸는 양: 속도 Ts·3.68 = 0.037 m/s, 위치 0.18 mm.
  • 지평 75 스텝마다 기준 헤딩 θr,k 로 G 를 다시 계산합니다.

4. 바퀴 속도: 같은 행렬의 전치

duality (Jacobian transpose / virtual work)

뜻

  • 미끄러지지 않으면 바퀴 각속도는 몸체 속도 u 에 Fᵀ 를 곱한 값입니다(메카넘 inverse kinematics).
  • 힘 사상의 전치가 속도 사상입니다. 가상 일 τ·ω = (Fτ)·u 에서 나옵니다. 코드의 T⁻¹ 과 Fᵀ 차이 0.
  • 슬립 되먹임은 실제 ω 와 이 무슬립 ωnom 의 차이를 씁니다(7 절).

5. 속도 의존 항 h(q̇) — 켜져 있는 것

terms in the prediction

항마다

  • 바퀴 관성 회전 결합 μθ̇Sṗ: 바퀴 관성은 몸체 좌표에서만 작용해, 선회로 속도 방향이 돌 때 생깁니다. 1 m/s · 2 rad/s 면 옆 0.66 m/s². (manipulator form 의 C(q, q̇)q̇ 자리, 코드 이름 w 항)
  • 구동계 마찰 τb: 쿨롱 + 점성, 바퀴 속도 함수(벤치 측정값).
  • 롤러 구름 저항 Qrr: 롤러마다 0.88 N. 옆걸음·회전에서만 생기고 직진에서는 0.
  • 외란 추정 d̂: offset-free MPC 의 입력 외란(몸체 좌표, 시정수 1 s).

6. 제약과 비용

constraints

뜻

  • 모터: 바퀴 토크 1.2 N·m.
  • 바닥 마찰: 바닥에 실제로 넘어가는 토크 P(τ − f) 를 묶습니다. P 는 모터 토크 중 바퀴 자신을 가속하는 몫을 뺀 바닥 몫입니다(앞 방향 0.672). f 는 구동계 마찰.
  • τ̄i = (r/√2)·μ̂·Ni·cs, μ̂ 0.60 · cs 0.8 → [0.145 0.145 0.158 0.159] N·m (FL FR RL RR, 뒤가 무거움).
  • 변화율: 한 스텝 Δτ̄ = τ̄/3.
cost

뜻

  • W = diag[80, 80, 10, 2, 2, 1]: 위치 오차를 가장 무겁게.
  • rΔ = 100/스텝: 토크 변화율 벌점(떨림 억제).
  • rU = 10: 목표 입력 Us 에서 벗어난 토크 벌점. Us 는 모델이 맞을 때 기준을 따라가는 데 드는 최소 노름 토크로, 영공간 성분이 0 입니다.

7. MPC 바깥 슬립 되먹임

wheel-space slip feedback (LQR gain)

뜻

  • 바퀴가 무슬립 속도보다 빨리 돌면(헛돎) 그 바퀴 토크를 줄이고, 느리면(끌림) 늘립니다.
  • Kω = 배율 1.2 × LQR 대각 0.0162 = 0.0194 N·m/(rad/s), 바퀴끼리 엮이지 않는 대각.
  • 예: 림이 0.2 m/s(5 rad/s) 더 빠르면 그 바퀴에서 0.097 N·m 를 뺍니다.

8. 다 펼친 식

cθ = cos θ, sθ = sin θ. 위 행렬을 원소까지 곱해 풀었습니다. 코드의 Python 모델 G(θ) 와 θ = 0, 0.7, −2.1 에서 차이 10⁻¹⁵ 이하입니다.

A_c (6×6), B_c(θ) (6×4)

뜻

  • a = 1/(r(m+μ)) = 3.685, b = k/(r(Iz+μk²)) = 42.72 (단위: 가속도 per N·m).
  • cθ ± sθ = √2 cos(θ ∓ 45°) 라서 각 바퀴 토크는 45° 대각선 방향으로 몸체를 밉니다. FL·RR 은 헤딩에서 오른쪽 45°(θ − 45°), FR·RL 은 왼쪽 45°(θ + 45°). 크기 a√2 = 5.21 m/s² per N·m.
  • 요: 오른쪽 바퀴(FR·RR) 는 +, 왼쪽(FL·RL) 은 −.
six scalar equations

뜻

  • τ̃i = τi − τb,i: 모터 토크에서 구동계 마찰을 뺀, 바퀴가 실제로 쓰는 토크.
  • κ = μ/(m+μ) = 0.328: 바퀴 관성 회전 결합. 선회(θ̇) 중 속도에 수직한 가속.
  • Qy, Qz: 롤러 구름 저항(몸체 옆 힘·요 모멘트). 몸체 좌표라 ẍ·ÿ 에는 R(θ) 로 돌아 들어갑니다.
  • d̂ = [dx, dy, dθ]: 외란 추정(가속도 단위).
friction · roller terms

값

  • 쿨롱 ci = [0.0174 0.0206 0.0155 0.0157] N·m, 점성 bi = [1.07 1.16 1.11 1.18]·10⁻³ N·m·s/rad, ωs = 0.5 rad/s (벤치 측정).
  • Frr = 0.88 N, lx = 0.0862 m: 순수 옆걸음 Qy = −4√2Frr = −4.98 N, 순수 회전 Qz = −4√2 lxFrr = −0.43 N·m (실측 4.99 N · 0.37~0.44 N·m).
  • 직진(vy = ωz = 0)이면 sf = sr = 0 이라 롤러 항이 0 입니다. sgn 은 코드에서 매끄럽게(|s| ≈ √(s² + s₀²)).
  • MPC 안에서는 이 항들을 기준 궤적의 속도로 미리 계산해 상수 ck 로 넣습니다(QP 는 선형 그대로).
discrete, T_s = 0.01 s

뜻

  • 위치는 한 스텝에 Ts·속도 + Ts²/2·가속도, 속도는 Ts·가속도만큼 바뀝니다. 가속도는 위 ẍ, ÿ, θ̈ (θ 자리에 기준 θr,k).
  • A 의 0 이 아닌 원소는 대각 1 과 위 오른쪽 블록의 0.01 뿐입니다.
