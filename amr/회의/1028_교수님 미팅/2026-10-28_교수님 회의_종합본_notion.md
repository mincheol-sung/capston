## 1. 보고 내용 요약

### 1.1 제어기 구조 초안
- **한화 과제 구조 이식**  
  한화 과제의 휠슬립 제어기에서 쓸 수 있는 부분을 뽑아 기존 AMR 코드에 연결하는 구조도를 만들었습니다. 아직 초기 단계입니다.
- **목표 슬립률과 보상 방식**  
  노면을 간단히 분류해 노면별 목표 슬립률을 상수 하나로 정하고, 슬립률 오차로 PID 제어해 구한 델타 토크로 MPC 출력 토크를 보상하는 구조입니다. 세부 로직은 아직 정하지 않았습니다.
- **슬립 정의**  
  선속도 대신 예상 각속도와 실제 각속도의 차이로 슬립을 정의합니다. 교수님이 이 정의를 그대로 써도 된다고 하셨습니다.

### 1.2 센서 주기 문제와 슬립 판정 아이디어
- **라이다 10Hz와 제어 100Hz의 차이**  
  휠 오도메트리 대신 라이다 오도메트리를 쓰면 SLAM 속도가 10Hz로만 들어와, 100Hz 제어 주기의 나머지 9스텝 동안 노미널 각속도를 알 수 없습니다. 엔코더는 100Hz로 들어오므로 그 사이의 슬립 값은 실제와 다를 수 있습니다.
- **토크 대비 각가속도로 슬립 유무 판정**  
  휠 동역학 Jω̇ = τ − r·Fd를 이용해 넣어 준 토크 대비 각가속도로 슬립 발생 여부만 판정하는 보조 지표를 제안했습니다. 슬립이 해소되면 슬립 제어기를 끄는 데 쓰는 방안입니다.

### 1.3 하중 강건성 범위
- **Fz 추정의 어려움**  
  Fz를 차체 무게 나누기 4로 두기로 했는데, 하중을 바꿨을 때 Fz 변화를 알려면 관측기가 필요해 범위가 커집니다. 우선 노면 조건만 다루려 합니다.

### 1.4 하드웨어와 일정
- **모터**  
  모터 신청이 오늘 완료되었습니다. 재고가 있으면 금요일 안에, 없으면 일주일 정도 걸립니다. 24V, 피크 전류 약 7A, 스펙상 최대 약 90W입니다.
- **배선**  
  배선은 거의 마쳤으며, 끝나면 제어기 작업으로 넘어갑니다.
- **발표 일정**  
  다음 주 2차 발표, 11월 말 3차 발표(포스터), 12월 3일 최종 발표입니다.

## 2. 주요 의견

- **1. 토크 입력 동역학 모델 먼저 정리**  
  네 바퀴 토크가 vx, vy, 요 레이트에 어떻게 작용하는지 수식이 있어야 MPC와 휠슬립 제어를 할 수 있음. 메카넘 휠은 일률(Στω = F·v) 관점으로 유도. 이상적 조건에서 종방향 힘은 Fx = Στ/R로 일반 타이어와 같고, 횡방향 힘 Fy = (τ/R)·tanα가 더해지며 45°에서는 두 크기가 같음. 노미널 플랜트이므로 구름 저항 등은 고려하지 않음
  - **반영 방향**  
    토크 입력 3-state·6-state 상태공간 모델(A, B 행렬)을 정리
  - **(내부) 메모**  
    교수님이 회의 중 ChatGPT로 유도한 대화를 메일로 공유하기로 함 (94:56)

- **2. 토크 제어로 진행**  
  토크 모델이 생각보다 간단해 토크 제어와 휠 속도 제어의 난이도가 비슷함
  - **반영 방향**  
    제개설 제어기를 토크 제어 기반으로 구성
  - **(내부) 메모**  
    각속도 제어(제개설)·토크 제어(종설)로 나누자는 제안(38:49)이 있었으나 토크로 결정

- **3. SLAM 빈 구간은 IMU 적분으로 채움**  
  SLAM 값이 들어오는 스텝에서는 측정값을 믿고, 그 사이 9스텝은 IMU 가속도로 속도·위치를 적분. 0.1초 적분 오차는 작고 다음 측정에서 리셋됨
  - **반영 방향**  
    측정 시 측정값, 측정 없을 때 모델 적분으로 바꾸는 방식으로 구현
  - **(내부) 메모**  
    발표에서는 GPS 음영 구간 위치 추정, 모델 기반 적분기·관측기로 설명하면 좋다고 함

- **4. 세 시나리오 비교로 정량 평가**  
  A 기존 제어기(퓨어 퍼슛), B MPC, C MPC + 휠 슬립 제어. 지표는 MPC 코스트, 최대 토크, 휠 슬립률, 토크 사용 에너지, 추종 오차. 제안 방법 하나만 보여 주기보다 비교가 좋음
  - **반영 방향**  
    평가 표를 A·B·C 비교 형식으로 구성
  - **(내부) 메모**  
    수업 담당 노유정 교수님이 정량 평가를 강조한다는 질문에 대한 답

- **5. 질량은 추정하지 않고 파라미터로 반영**  
  질량은 적재물이라 안다고 가정. 시험체에 10kg을 올려 20kg으로 만들고 MPC의 m만 10에서 20으로 바꾸면 질량에 강건한 결과를 보일 수 있음. 실제 시연은 질량 하나로 하고 나머지는 시뮬레이션·영상으로 보여도 됨
  - **반영 방향**  
    질량은 MPC 파라미터로 두고 질량별 비교
  - **(내부) 메모**  
    제개설에서는 하중·노면 둘 다는 어렵고 노미널 하나만, 종설에서 같은 플랫폼으로 시험 확장 (49:15)

- **6. 8자 경로 기반 시간 레퍼런스 맵**  
  실시간 플래너 대신 글로벌 플래너 하나로 시간별 X, Y 레퍼런스(Xmap, Ymap)를 미리 만들고, 차 위치와 관계없이 시각에 맞는 구간을 MPC 레퍼런스로 읽음. 8자 경로에 바퀴별 속도(1, 2, 3m/s)를 입히면 30m 서킷 기준 55초 계획이 되고 X, Y, 헤딩, vx, vy, 요 레이트 레퍼런스가 함께 나옴. 헤딩은 경로 접선 방향, vy = 0
  - **반영 방향**  
    8자 경로 플래너와 속도 프로파일 제작
  - **(내부) 메모**  
    슬립이 나서 뒤처지면 MPC가 토크를 더 주고 슬립 보상기는 줄이려 해 서로 맞서므로, 두 성능이 드러나는 속도를 실험으로 찾아야 함 (90:18~92:20)

- **7. MPC 구성**  
  코스트는 XY 좌표 오차로 둠(횡방향 오차는 변환이 더 어려움). 모델이 비선형이므로 현재 스텝 기준 선형화 모델로 MPC를 구성
  - **반영 방향**  
    XY 좌표 코스트, 선형화 MPC로 구현

- **8. 슬립 제어기 범위 축소**  
  뮤와 질량은 주어진다고 가정하고 뮤 추정기·노면 판단·MTTE는 빼고 토크 상한만 둠. 한 번 주행 중 뮤를 바꾸지 말고 뮤 높을 때 한 번, 낮을 때 한 번 시험. 목표 슬립률은 잡아 둠. 잘 되면 뮤 추정기를 나중에 추가
  - **반영 방향**  
    토크 상한 중심으로 슬립 제어 구현, 슬립률 계산은 유지
  - **(내부) 메모**  
    토크 상한을 MPC 제약으로 넣을지 별도 PID로 둘지는 미정 (5.2)

## 5. 결정·보류 (내부)

### 5.1 결정사항
- **토크 제어 채택**  
  제개설 제어기는 토크 제어로 구성한다 (95:19 정다솔).
- **슬립 정의**  
  예상 각속도와 실제 각속도의 차이로 슬립을 정의한다 (23:25 정다솔).
- **제개설 범위**  
  하중·노면 추정은 하지 않고 뮤·질량을 아는 노미널 조건으로 한다. 슬립 제어는 토크 상한만 두고 뮤 추정기·노면 판단·MTTE는 뺀다 (49:15, 97:58~99:38 정다솔).
- **평가 시나리오**  
  8자 경로, 바퀴별 1·2·3m/s 속도 프로파일, 헤딩은 경로 접선 방향, vy = 0. A·B·C 세 제어기를 비교한다 (41:25, 73:04~73:35, 82:22 정다솔).
- **MPC 형태**  
  시간 레퍼런스 맵을 따라가는 XY 좌표 코스트, 현재 스텝 선형화 MPC (79:19, 96:14 정다솔).
