### ① 교수님 피드백 — 항목별 반영 상태 (사용자 설명 2026-11-16 반영)

#### 7번 상세 — 비용·제약·선형화 (`torque_mpc.hpp`·`torque_mpc.cpp`)

- 상태 x = [x, y, θ, ẋ, ẏ, θ̇] (map), 입력 τ ∈ ℝ⁴. Ts 0.01 s, Np 50 (0.5 s), Nc 5 (그 뒤는 τ_{Nc−1} 유지) → QP 변수 4·Nc = 20 개 (condensed QP, solver DAQP)
- 비용·예측·제약 (LaTeX, pptx 수식용):

$$
\min_{\tau_0,\dots,\tau_{N_c-1}}\;
J=\sum_{j=1}^{N_p}\big\|x_j-x_{r,j}\big\|_{W}^{2}
+r_\Delta\sum_{j=0}^{N_c-1}\big\|\tau_j-\tau_{j-1}\big\|_2^{2}
+r_U\sum_{j=0}^{N_c-1}\big\|\tau_j-U_{s,j}\big\|_2^{2}
+q_{\text{null}}\sum_{j=0}^{N_c-1}\big(n^\top\tau_j\big)^2
$$

$$
\text{s.t.}\quad x_{j+1}=A\,x_j+B_j\,\tau_j+s_w E\,w_j\;[+\hat d],\qquad x_0=\hat x(k),\qquad \tau_j=\tau_{N_c-1}\ (j\ge N_c)
$$

$$
|\tau_{i,j}|\le\bar\tau,\qquad |\tau_{i,j}-\tau_{i,j-1}|\le\Delta\bar\tau=\bar\tau/3,\qquad \tau_{-1}=\tau(k-1),\qquad i\in\{\text{FL},\text{FR},\text{RL},\text{RR}\}
$$

$$
U_{s,j}=\big((T^{-1})^\top\big)^{+}R(\theta_{r,j})^\top M\big(\ddot p_{r,j}-s_w w_j-\hat a_d\big),\qquad
n\propto[1,\ 1,\ -1,\ -1]^\top
$$

$$
J=\mathbf U^\top H\,\mathbf U+2g^\top\mathbf U+\text{const},\quad
H=\Phi^\top\bar W\Phi+r_\Delta D^\top D+r_U I+q_{\text{null}}\big(I_{N_c}\otimes nn^\top\big),\quad
g=\Phi^\top\bar W e_0-r_\Delta\,(e_1\otimes\tau_{-1})-r_U\,\mathbf U_s
$$

  (Φ: 토크 → 예측 상태, e₀ = 영입력 응답 − 기준, D: 이웃 스텝 차분 행렬, W̄ = I_{Np} ⊗ W)

  | 기호 | 값 | 뜻 |
  |---|---|---|
  | W | diag(100, 100, 50, 1, 1, 0.5) | x, y, θ, ẋ, ẏ, θ̇ 오차 가중. 100·(0.01 m)² = 1·(0.1 m/s)² = 0.01, 50·(0.8°)² = 0.0097 → 위치 1 cm ≈ 속도 0.1 m/s ≈ 방향 0.8° |
  | r_Δ (`w_delta`) | 10 | 이웃 스텝 토크 차 벌점. τ_{−1} = 직전 주기에 낸 토크 |
  | r_U (`r_u`) | 0.01 | 목표 입력 U_s 에서 벗어남 벌점 |
  | U_s,j | 식-14 | ((T⁻¹)ᵀ)⁺ R(θ_r,j)ᵀ M (p̈_r,j − w_j − â_d): 기준 가속을 내는 최소 노름 토크 (feedforward) |
  | n | ∝ [1, 1, −1, −1] | (T⁻¹)ᵀ 의 null space — 몸체 힘·모멘트를 안 내는 토크 조합 |
- 제약 (식-19·20): |τ_i,j| ≤ τ̄, |τ_i,j − τ_i,j−1| ≤ Δτ̄ = τ̄/3. **입력에만** 있다. XY 오차는 제약이 아니라 비용 항.
  추종 오차 한계는 MPC 밖: `fault_monitor` `max_track_error` 1.5 m, figure8 `abort_error` 1.6 m
- 선형화
  - `reference` (기본): G(θ) 에 지평 각 스텝의 기준 방향 θ_r,j 를 넣은 LTV 예측. A 는 상수 [I, Ts·I; 0, I], θ 에 대한 1차 항 없음
  - `current_state` (교수님 "현재 스텝 기준"): 매 주기 (x̂(k), τ(k−1)) 에서 Jacobian 선형화 ẋ ≈ A_c x + B_c τ + c_c →
    증강행렬 행렬지수로 ZOH 이산화 → 그 한 모델(LTI)을 지평 50 스텝 전체에 사용, 다음 주기에 다시 선형화 (successive linearization)
  - 검산 (스크립트): A_c(3,2)·A_c(4,2) 식 vs 유한차분 차이 3.5e-11, θ̇ = 0·τ₀ = 0 이면 ZOH 결과가 reference 의 A, B(θ) 와 같음 (차이 7e-18)
  - `amrall` 로는 선형화 방식을 못 고른다 (`_PASS` 에 없음) → `torque_mpc.yaml` `linearization.mode` 수정

#### 8번 상세 — 토크 상한 (식-21, 계산값)

τ̄ = min( τ_lim − τ_fric,max ,  (r/√2)·μ̂·(mg/4)·c_s )

| 항 | 식 | 값 |
|---|---|---|
| 모터 항 (B 는 이것만) | 1.3 − 0.1 | **1.2 N·m**, Δτ̄ 0.4 N·m/스텝 |
| 마찰 항 τ_μ | 0.02828 × 0.3 × 11.183 N × 0.8 | **0.0759 N·m**, Δτ̄ 0.0253 N·m/스텝 |
| C 의 τ̄ | min(1.2, 0.0759) | 0.0759 N·m (B 의 1/15.8) |

- 유도 (LaTeX, 검산 스크립트 `tau_limit_derivation.py` 결과 포함):

$$
\textbf{(D1) 접지력 방향}\quad f_i=\frac{\tau_i}{r}\begin{bmatrix}1\\ \pm1\end{bmatrix}\ \ (\text{FL},\text{RR}: -,\ \ \text{FR},\text{RL}: +),\qquad \|f_i\|=\frac{\sqrt2\,|\tau_i|}{r}
$$

$$
\textbf{(D2) Coulomb friction}\quad \|f_i\|\le\hat\mu N_i,\qquad N_i=\frac{mg}{4}
$$

$$
\textbf{(D3)}\quad \frac{\sqrt2\,|\tau_i|}{r}\le\hat\mu\frac{mg}{4}\;\Longrightarrow\;|\tau_i|\le\frac{r}{\sqrt2}\,\hat\mu\,\frac{mg}{4}
\qquad\textbf{(D4) 여유}\quad \tau_\mu=\frac{r}{\sqrt2}\,\hat\mu\,\frac{mg}{4}\,c_s
$$

$$
\textbf{(D5)}\quad \bar\tau=\min\big(\tau_{lim}-\tau_{fric,max},\ \tau_\mu\big)=\min(1.2,\ 0.0759)=0.0759\ \text{N·m}
$$

  - D1: 바닥 롤러는 자기 축 둘레로 자유 회전 → 롤러 축에 수직인 방향으로는 힘을 못 냄 → 접지력은 롤러 축(몸체 x 에서 ±45°) 방향뿐. 바퀴 토크 평형 τ = r·f_x (J_w ω̇ 무시) → f_x = τ/r, f_y = ±τ/r.
    force_map 의 열과 같음 (바퀴 위치 (±L/2, ±W/2) 로 M_z = p_x f_y − p_y f_x 계산 → ∓k τ/r, 네 바퀴 모두 일치)
  - D2: 바퀴당 수직항력을 같게 (무게중심이 가운데, 하중 이동 없음) 둔 가정
  - D3: f_i 방향이 고정이라 friction circle 이 τ_i 하나의 상하한(box)이 된다 → QP 의 선형 bound 로 들어감
  - D4: c_s 0.8 = 가감속 하중 이동 여유 계수 (지시서 78행). 유도한 값이 아니라 설계 여유 (무게중심 높이를 안 재서 하중 이동을 계산할 수 없음)
  - 수치: r/√2 = 0.028284 m, mg/4 = 11.183 N, μ̂N = 3.355 N → c_s 없이 0.0949, c_s 곱해 0.0759 N·m. τ_μ = 0.253·μ̂ N·m (μ̂ 0.55 → 0.139, 체크리스트 값과 같음), m 4 kg 면 0.0666 (지시서 U2 와 같음)
  - 거꾸로 쓰면 μ̂ = √2·τ_slip / (r·mg/4) — `amrmu` (μ̂ 램프 시험)이 이 관계로 μ̂ 를 잰다
- τ_fric,max 0.1 을 빼는 이유: 다음 단 `torque_output` 이 마찰 보상 τ_fric(ω) 를 더하고 ±1.3 으로 클램프 → 보상 몫을 남겨 둠
- circles8, width 2.0 (원 반지름 0.5 m), 헤딩 고정에서 C 의 최대 가속 (LP 계산): 몸체 0°·90° 1.119 m/s², 45° 0.791 m/s² → 등속 원 한계 √(aR) = 0.748 / **0.629 m/s**. speed 0.7 (구심 0.98 m/s²) 은 대각 방향에서 C 한계를 넘는다 (changelog (11) 의 "≈ 0.63 m/s" 와 같음)

- 제약 쪽 변경 (지시서 = 선배 발표 17쪽 식과 코드 비교, 사용자 확인 필요):
