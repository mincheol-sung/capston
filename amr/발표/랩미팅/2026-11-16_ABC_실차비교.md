# 실차 A·B·C 비교 — circles8 0.7 m/s (2026-11-16 밤)

같은 경로·같은 속도로 비교군 A·B·C 를 한 판씩 돌린 결과다. 수치는 모두 bag 에서 스크립트로 계산했다 (`분석_스크립트/`, 맨 아래 "재현").
**조건마다 1 판**이라 A–C 처럼 차이가 작은 비교는 반복 전에는 결론으로 쓰지 않는다.

## 1. 조건

공통: `real_all.launch.py` (`amrall`), `use_mpc:=true shape:=circles8 width:=2.0 yaw_mode:=tangent speed:=0.7 bag:=true`.
circles8 = 지름 1.0 m (R 0.5 m) 원 두 개, 경로 길이 6.28 m. 기본값 그대로: `origin_mode` robot, `use_w` false, `disturbance` false, `linearization` reference.

|---|---|---|---|---|

## 2. 측정 방법

| 지표 | 정의 | 출처 |
|---|---|---|
| 슬립률 λ | λ_i = (ω_i − ω_nom,i)·sgn(ω_nom,i) / max(\|ω_i\|, \|ω_nom,i\|, ω_ε), ω_nom = T⁻¹v̂, ω_ε = 2.5 rad/s. λ > 0 헛돎, λ < 0 끌림 | `/slip_logger/slip` (`nodes/slip_logger.py`). v̂ = `/state_estimator/odom` (SLAM + IMU, 바퀴와 독립) |
| 시간 기준 추종 오차 | 그 시각의 기준점과 추정 상태의 차 [e_x, e_y, e_θ] | `/torque_mpc/status`·`/pure_pursuit/status` 앞 4 열 (`fault_monitor` 가 보는 값) |
| 경로 기준 거리 | 추정 위치에서 `/figure8/path` 까지 최단 거리 (늦게 따라가는 것은 오차로 안 침) | `/state_estimator/odom`, `/figure8/path` |
| 명령 토크 | gate 출력 | `/wheel_torque_cmd` (마찰 보상 포함 → C 최대가 τ̄ 보다 큼) |
| 바퀴 포화 | \|ω\| > 38 rad/s 비율 (무부하 최고 약 41~42 rad/s), \|ω\| > 20 rad/s 구간의 부호 뒤집힘 | `/wheel_states` |

- λ 식 검산: `223122_bag` 에서 슬립 행의 t (= `/wheel_states` header.stamp) 로 같은 메시지의 ω 를 찾아 다시 계산 → 4871 행 차이 최대 0
- 모든 통계는 arm 구간. 슬립은 \|v̂\| > 0.05 m/s 행만

## 4. 읽은 것

- **B 가 모든 항목에서 가장 나쁘다**: 바퀴 ω 가 ±40 rad/s (전압 한계 근처) 사이를 사각파처럼 뒤집히고 (그림 B 왼쪽 열), ω_nom 은 그렇게 뒤집히지 않는다 → 바퀴가 몸체와 따로 돎(헛돎). 위치 오차는 A·C 의 2~3 배, 경로 76 % 에서 `pose_jump` 로 정지.
  B 의 λ 는 끝부분 추정기 흔들림(\|ω_nom\| 최대 62.4 rad/s ≈ 몸체 2.5 m/s, 비물리적)이 섞여 있다 → 근거는 λ 보다 **바퀴 ω 자체의 ±40 rad/s 뒤집힘** (바퀴 측정값, 추정기와 무관)
- **C 는 B 보다 헛돎이 훨씬 작다** (\|ω\| > 38 rad/s 0.5 % vs 21.8 %, 뒤집힘 0 vs 8~16) — 토크 상한 C 의 효과와 맞는 방향
- **A 가 슬립이 가장 작다** (RMS λ 0.14~0.21 vs C 0.25~0.45). A 는 C 보다도 토크를 작게 냈다 (중앙값 절반, 0.15 N·m 초과 0.7 % vs 17 %).
  A 의 상한은 B 와 같은 1.2 N·m 이므로, 슬립이 작은 것은 상한 때문이 아니라 바퀴 속도 PI (kp 0.03, ki 0.15) 가 토크를 작게 낸 결과로 보인다
- **위치 추종은 A ≈ C**: RMS 는 A 가 약간 작고 (4.0 vs 4.9 cm), 경로 이탈 최대는 C 가 작다 (9.6 vs 11.9 cm). 1 판씩이라 우열 판단 보류
- **헤딩은 C 가 A 의 1/3** (RMS 1.3° vs 3.9°, 최대 7.1° vs 18.9°). MPC 비용의 θ 가중 (W 50) vs PP 의 k_heading 비례항 차이로 추정 (원인 미확인)
- 이 결과는 `torque_mpc_todo.md` 의 기존 항목 "A 가 시뮬에서 B·C 보다 좋게 나온 것 — 발표 결론(C 가 슬립을 줄인다)과 부딪힌다" 와 같은 방향이다 (이번엔 실차)

## 5. 주의·다음 확인

- 추종 오차는 추정기 (`/state_estimator/odom`) 기준 = 제어기가 본 오차. 추정기 자체 오차는 빠져 있다 → SLAM `/tracked_pose` 로 다시 재면 독립 확인
- 조건마다 1 판. A–C 위치 오차처럼 차이가 작은 것은 반복 필요
- **C 의 μ̂ 0.6 이 실제보다 클 수 있다**: 실제 μ 가 0.4 면 마찰 한계 0.253 × 0.4 = 0.101 N·m 인데 C 는 0.152 N·m (약 1.5 배) 까지 허용 → C 도 미끄러질 수 있다 (가설).
  `amrmu` 로 바닥 μ̂ 를 재고 그 값으로 C 를 다시 돌린다
- λ 의 잡음 바닥은 추정 속도 오차로 약 0.1 → \|λ\| > 0.1 비율은 슬립과 잡음이 섞인 수치
