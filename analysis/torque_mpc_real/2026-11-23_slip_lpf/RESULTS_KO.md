## 3. 주의

- 회의의 "어댑티브 PP" 와 지금 기본 PP (고정 0.30) 가 다르다. 비례 (0.15~0.60) 판은 square 2 개뿐 — 비교군 3 개를 맞추려면 이름·설정 확인 필요.
- 판마다 C 의 τ̄ 가 다르다 (μ̂ 기본값 11-21 (14), 11-22 (4) 변경). 마찰 보상은 모든 판에서 켜짐 — 회의 결정 (보상항 제거) 뒤 판과는 따로 비교해야 한다.
- λ 의 기준 속도는 추정기 속도 (잡음 ~0.1, 바퀴별 기구학 치우침 0.03~0.05) — > 0.25 문턱에는 영향 작고, > 0.1 은 못 쓴다.
- 부가 기능 켠 판 (slip_guard·disturbance·wheels·h) 은 `summary.md` 에 따로 있다. 회의 결정상 비교에는 끈 판을 쓴다.

## 4. η 시그모이드 열린 고리 재생 (`eta_replay.py` → `out_eta.md`)

η(λ̃) = 1/(1 + exp((|λ̃| − λ_c)/s)), s 0.0167 (회의: λ 10 % ≈ 1, 20 % ≈ 0.5, 25 % ≈ 0). λ̃ = 인과 1 차 LPF 10 Hz (실시간과 같게).
기록된 λ 에 η 만 계산 — 실제로는 η 가 토크를 바꿔 λ 도 바뀌므로 "얼마나 자주 걸렸을까" 만 본다. 판별 중앙값, 바퀴 4 개 × 시간.

| 시나리오 | 제어기 | 판 | \|λ̃\| 중앙값 | \|λ̃\| 90 % | λ_c 0.20: η<0.5 % / 평균 η | λ_c 0.25 | λ_c 0.30 |
|---|---|---|---|---|---|---|---|
| circles8 v0.7 (큰 슬립 적은 판) | C | 7 | 0.072 | 0.236 | 14.3 / 0.85 | 8.9 / 0.91 | 5.3 / 0.94 |
| square a1.5 vmax1.5 | C | 6 | 0.090 | 0.338 | 21.1 / 0.78 | 15.1 / 0.84 | 11.9 / 0.88 |
| line dir0 v1.0 a3.0 | C | 3 | 0.128 | 0.384 | 34.3 / 0.64 | 23.4 / 0.76 | 16.4 / 0.83 |
| circles8 랩 0.43·0.61·0.8 | C | 8 | 0.123 | 0.658 | 35.9 / 0.64 | 30.3 / 0.70 | 25.8 / 0.74 |
| line dir90 v0.3 | C | 3 | 0.106 | 0.303 | 20.4 / 0.79 | 15.1 / 0.85 | 10.3 / 0.90 |

- 큰 슬립이 적은 circles8 v0.7 에서도 |λ̃| 90 % 가 0.236 — λ_c 0.20 은 이 바닥 (추정 속도 잡음 + 바퀴별 기구학 치우침 + 작은 실제 슬립) 안에 있다.
  그 판들에서 λ_c 0.20 이면 바퀴-시간의 14 % 를 η < 0.5 로 깎는다.
- **정정 (같은 날 5 절):** 위 표만 보고 "λ_c 0.25" 를 권했는데 틀렸다. 0.236 은 느린 표본 (0.4 m/s 아래, 바닥이 넓음) 이 섞인 값 — 꺾임은 λ_c 가 아니라 η 전용 ω_ε 로 푼다.
- 세 바퀴만으로도 (F_x, F_y, M_z) 를 낸다: 어느 한 바퀴를 뺀 F 3×3 의 det = ±4k/r³ = ±12075 (k 0.1932, r 0.04). 두 바퀴를 빼면 rank ≤ 2.

## 5. η 꺾임점 근거: 바닥 분포와 μ–λ 곡선 (`lam_floor.py` → `out_floor.md`, `floor_by_speed.py` → `out_floor_speed.md`)

플래그 없는 실차 판 70 여 개, 바퀴 4 개 × 시간. 지면 토크 τ_g = τ_meas − J_w ω̇ − τ_fric(ω) (τ_meas 는 드라이버 전류 추정),
u = τ_g·sgn(ω_nom)/((r/√2)·N_i) (λ 와 같은 부호, μ 단위). "바닥" = |u| < 0.05 (지면 힘이 거의 없을 때) 의 λ̃ — 이때 토크를 깎을 이유가 없다.

**바닥은 속도에 반비례한다** (|u| < 0.05, 인과 10 Hz):

| 바퀴 기준 속도 | \|λ̃\| 95 % (ω_ε 2.5) | 절대 미끄럼 속도 \|r(ω−ω_nom)\| 95 % |
|---|---|---|
| 0.10~0.20 m/s | 0.622 | 0.113 m/s |
| 0.20~0.40 | 0.290 | 0.098 |
| 0.40~0.60 | 0.212 | 0.113 |
| 0.60~0.80 | 0.147 | 0.106 |
| 0.80~1.20 | 0.127 | 0.130 |

절대 미끄럼 속도 바닥이 ~0.1 m/s 로 거의 일정 → λ = Δv/v 라서 느릴수록 바닥이 넓다. 바퀴별 바닥 중앙값 [FL, FR, RL, RR] = [+0.022, −0.050, −0.043, +0.036] (기구학 치우침 부호와 같음).

**μ–λ 곡선 (line 앞·square, ω_nom ≥ 10 rad/s):** λ̃ 구간 중앙 0.025 / 0.075 / 0.125 / 0.175 / 0.225 → u 중앙값 0.091 / 0.154 / 0.208 / 0.221 / 0.226.
기울기 Δu/Δλ 1.26 → 1.08 → **0.26 → 0.10** — λ̃ ≈ 0.15 에서 힘이 더 안 는다. 제동 쪽도 −0.15 부터 기울기 1.06 → 0.52 → 0.20.
교재 타이어 μ–λ 곡선의 peak (0.1~0.2) 와 같은 자리. 줄어드는 구간 (peak 뒤 감소) 은 안 보이고 평평 — 메카넘 롤러 곡선은 교재에 없다.

**교수님 곡선 (λ_c 0.20, s 0.0167: η 0.95 at 0.151, 0.5 at 0.20, 0.048 at 0.25) 을 바닥에 대 보면:**

| λ 정의 | 0.1~0.4 m/s 바닥에서 η<0.5 | 0.4 m/s 위 | 전체 | 평균 η |
|---|---|---|---|---|
| ω_ε 2.5 (지금 slip_logger) | 21.3 % | 3.3 % | 12.4 % | 0.870 |
| ω_ε 17.5 (η 전용, 근사) | 2.3 % | 2.4 % | 2.4 % | 0.973 |
| ω_ε 20 (η 전용, 근사) | 1.7 % | 2.0 % | 1.9 % | 0.979 |

근사 = r(ω−ω_nom)sgn 를 인과 LPF 한 뒤 r·max(ω_nom, ω_ε) 로 나눔 (ω_ε 10 정확값 95 % 0.216 vs 근사 0.224 로 확인).
→ 꺾임 시작 0.15·중앙 0.20 은 μ–λ 곡선과 맞다. 문제는 느린 속도의 바닥이고, η 쪽 λ 의 ω_ε 를 17.5~20 rad/s (0.7~0.8 m/s) 로 올리면
그 아래 속도에서는 절대 미끄럼 속도로 판정 (η 0.5 지점 0.14~0.16 m/s) 하게 되어 바닥이 모든 속도에서 0.16 아래로 들어온다. slip_logger 지표 정의는 그대로.

주의: u 는 전류 추정 토크·정지 하중 N_i (하중 이동 안 넣음)·구간 중앙값이라 최대 마찰 μ 값으로 쓰면 안 된다. u = 0 인 λ̃ 가 −0.035 (line·square) ~ −0.06 (전체) — 치우침.
발표 지표 (> 0.25 %) 도 0.4 m/s 아래 표본의 넓은 바닥이 섞여 있다 — 재는 법 의논 때 같이.

## 6. η 전용 ω_ε 후보 비교 — 17.5 제안 철회 (`eps_tradeoff.py` → `out_eps.md`, 정확한 λ)

## 7. η 시작·0.5·0 지점 (`eta_points.py` → `out_eta_points.md`) — ω_ε 2.5 고정 (사용자 결정)

교수님 말 (전사문 50:12~): "20 % 에는 0.5, 25 %, 그리고 10 %" 와 "10 %, 15 %, 20 % 요 정도 슬로프" 둘 다 있다. 회의록은 앞의 것.
logistic 은 λ_c 에 대칭이라 (시작 = λ_c − ln19·s, 0 지점 = λ_c + ln19·s) 10/20/25 는 정확히 못 맞추고 10/15/20 은 맞춘다.

평형 슬립 λ*: MPC 가 상한에 붙으면 η(λ*)·τ̄ = 지면이 받아 주는 토크 → λ* = λ_c + s·ln(μ_max c_s / u_avail − 1) (μ_max 1.0, c_s 0.8).

| **10·15·20** λ_c 0.15, s 0.0170 | 0.100 / 0.15 / 0.200 | **0.169 / 0.159 / 0.141** | 20.0 % | 11.1 % | **1.2 %** | 1.9 % |

- 측정한 꺾임 (6 절, 0.125~0.175) 위에 평형 슬립이 오는 것은 10·15·20. 지금 기본 (0.20 중심) 은 꺾임 뒤 0.19~0.22 에 머문다 — 기울기 Δu/Δλ 가 1.1~1.3 → 0.1~0.26 인 곳이라 힘은 안 늘고 슬립만 는다.
- 10·15·20 의 대가: 바닥에서 상한이 실제로 걸리는 비율 7.4 → 11.1 % (0.1~0.4 m/s 바닥 12.6 → 19.0 %). 저속 바닥 (5·6 절) 탓이라 중심을 어디 두든 남는다.
- 폭: 좁히면 (0.05) 오작동·놓침은 같고 고리 이득만 2 배. 고리 한 스텝 이득 K·Ts/(J_w ω), K = τ̄/(4s) = 3.73 N·m (s 0.017, τ̄ 0.253):
  ω 25 rad/s 에서 1.68, 10 rad/s 에서 4.19 — 1 보다 커서 떨림 (limit cycle) 이 예상된다. 폭으로 없애려면 s 0.095 (폭 0.56) 가 필요해 쓸 수 없다 → 폭은 0.10 두고 떨림은 시뮬에서 확인.

**결정 (2026-11-23 사용자):** η 곡선 10·15·20 % — λ_c 0.15, s 0.017 (η 0.95 at 0.10, 0.5 at 0.15, 0.05 at 0.20), ω_ε 2.5 (slip_logger 와 같은 λ), 인과 1 차 LPF 10 Hz, |λ̃| (구동·제동 같음).
