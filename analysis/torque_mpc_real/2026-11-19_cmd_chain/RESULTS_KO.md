# 2026-11-19 — MPC 순토크 τ* 와 모터 토크가 왜 다른가 (bag 분석, 코드 변경 없음)

질문: "MPC 제어입력이랑 실제 모터에 들어가는 토크가 다르다". 경로 (코드):

| 단계 | 토픽 | 하는 일 |
|---|---|---|
| MPC | `/torque_mpc/cmd_raw` τ* | 바닥에 전달하려는 순토크 (상한 τ̄ 안) |
| torque_output | `/torque_output/cmd_raw` | τ_cmd = τ* + 0.9·[C_i tanh(ω/0.5) + V_i ω] + 0.9·0.08·exp(−(ω/0.5)²)·tanh(ω_ref/0.5), ±1.3 클램프 (구동계 마찰 보상) |
| 게이트 | `/wheel_torque_cmd` | 무장 중 그대로 (stamp 유지), 무장 해제·hold 면 DAMPING |
| CAN 다리 | — | MIT 명령 kp 0, kd 0, t_ff = τ_cmd (2.44 mN·m 양자화). DAMPING 이면 kd·(0 − ω) |
| 모터 | `/wheel_states` torque | 모터가 전류로 잰 토크 |
