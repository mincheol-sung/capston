# 2026-11-16 — 바퀴 축관성 J_w 계단 차분 측정 (실차 장착 그대로, 바퀴 띄움)

- 왜: 설정값 J_w 8.9e-4 (팀원 11-12 벤치) 가 맞는지. 있는 자료로는 마찰 모델에 따라 6.0e-4 ~ 1.04e-3 로 흩어졌다 (stack_changelog 2026-11-16 (13)).
- 방법: 돌고 있는 중 토크 계단 순간 앞뒤 ω̇ 차 → **J = Δτ/Δω̇** (같은 ω 라 구동계 마찰이 소거된다). `tools/jw_step_analysis.py` (ω̇ 는 ω̇ = α − β·ω 꼴로 맞춤).
- 조건: 로봇을 받침대에 올려 네 바퀴를 띄움, ROS 스택 끔, CAN 노드 없이 `tools/ak40_bench.py` 로 모터 하나씩. 시작 온도 33~34 °C, RL 다시 잴 때 36 °C.
  J 는 바퀴 축(감속기 출력축) 기준 바퀴 + 출력축·캐리어 + 기어비² × 로터 (N = 10). 명령 토크(드라이버 K_T) 기준.

- 계단 하나의 J 는 ±30 % 흩어진다: 실제 속도 잡음이 0.3~0.65 rad/s (FR 은 저속이라 0.30) — 합성 검증(양자화 0.022)보다 약 30 배.
  그래서 대표값은 중앙값. 합동 추정 ΣΔτΔω̇/ΣΔω̇² 는 Δω̇ 가 큰 이상치에 끌려 3.5~8.7e-4 로 낮게 나온다 (쓰지 않음).
- 오름(0.035→0.055)·내림 계단 차이 없음 (FL 9.77 / 9.39) → 감속기 부하 의존 마찰이 크지 않다.
- 응답 토크 기준 J 가 명령 기준보다 5~17 % 낮다 — 응답 토크(측정 전류 × K_T)가 평균적으로 명령보다 조금 작다.

## 같은 날 저녁 추가 — 구동계 마찰 다시 보기 (FR "2 배" 는 틀림)

접선 판 분석 중 J 측정 CSV 의 계단 과도 구간으로 마찰을 맞춰 "FR 마찰이 다른 바퀴의 약 2 배" 라고 했으나 **틀렸다** (`friction_now.py`, 바퀴마다
속도 범위가 다르고 0.05~0.06 N·m 에서 FL·RL 은 전압 한계 42 rad/s 에 막혀 있었다). 바퀴를 띄운 채(38~39 °C, 주행 직후) 두 가지로 다시 쟀다.

**코스트다운** (`coast_N_k.csv`, `coast_analysis.py`): 0.06 N·m 로 돌리다 토크 0 (kp = kd = 0) → 감속에서 기계 마찰 J·|ω̇| (J 공통 8.77e-4).

- **FR 은 같은 속도에 약 0.003~0.005 N·m (10~15 %) 더 든다** — 코스트다운의 기계 마찰 차이와 같은 크기 → 작은 기계적 끌림. 2 배 아님.
- **더 큰 문제는 보상표**: 네 바퀴 모두 과보상, 20 rad/s 에서 0.007~0.018 N·m (τ̄ 0.1012 의 7~18 %). 점성 항이 지금의 1.5~1.9 배.
  11-14 (30~32 °C, 길들기 전) 뒤로 마찰이 줄었다. 과보상은 진행 방향으로 미는 힘이라 MPC 가 제동해야 한다 —
  바닥 직선 판(184922)에서 앞으로 순항할 때 MPC 순토크가 음수였던 것과 같은 방향.
- 띄운 상태(무부하)·38 °C 값이다. 차가울 때(30 °C) 마찰이 약 15 % 크고, 바닥 하중이면 베어링 마찰이 더해진다 — 보상표에 넣을 때는 이 차이를 감안.
