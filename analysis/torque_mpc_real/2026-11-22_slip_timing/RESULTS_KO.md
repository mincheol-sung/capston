# 바퀴–몸체 시간차가 슬립 λ 에 섞이는 정도 (2026-11-22)

배경: 추정기 v_x 가 바퀴보다 40~80 ms 늦게 보이는데, SLAM 중앙 차분 기준으로는 0~20 ms — 바퀴가 몸체(SLAM)보다 30~60 ms 앞선다
(`../../estimator_tuning/2026-11-22_lever_arm/RESULTS_KO.md`). slip_logger λ 는 바퀴 ω 와 추정 속도로 만든 ω_nom 의 차라 이 시간차가 섞일 수 있다.

방법 (`slip_timing.py`): 바퀴 ω 를 τ 만큼 늦춰 λ 를 다시 계산. τ = 0 재계산은 logger 기록과 맞다 (circles8 큰 슬립 6.2 vs 6.4 %,
> 0.1 85.8 vs 86.4 % — 평가 시각 차이). 판: 11-21 C — circles8 0.7 (A/B 6 판), line 가속 5.0·3.5 (223401·223553), square 가속 1.5 (195636·201411).

## 1. τ 를 바꾸면 (판 평균, 전체 표 `tables.md`)

| 묶음 | 큰 슬립 % (max\|λ\| > 0.5): τ 0 → 가장 작은 값 (τ) | 미끄럼 > 0.1 %: τ 0 → 최소 | λ RMS: τ 0 → 최소 |
|---|---|---|---|
| circles8 지금 | 6.2 → 5.3 (40 ms) | 85.8 → 83.6 | 0.170 → 0.165 |
| circles8 후보 | 10.4 → 9.9 (40~60 ms) | 88.3 → 85.5 | 0.210 → 0.206 |
| line 가속 5.0·3.5 | **44.5 → 32.7 (80 ms)** | 88.7 → 85.1 | 0.397 → 0.366 |
| square 가속 1.5 | 20.8 → 18.6 (20 ms), τ 60·80 이면 23.8·26.4 로 **늘어남** | 83.6 → 79.8 | 0.292 → 0.275 |

- 시간차 몫은 circles8·square 에서 작다 (큰 슬립 ≤ 2 %p, > 0.1 ≤ 4 %p). 급가속 line 에서만 큰 슬립의 약 1/4 (12 %p).
- 맞는 τ 가 움직임마다 다르다 (line 80 ms, square 20 ms, circles8 40 ms). 시계 차이처럼 일정한 어긋남이면 같은 τ 에서 모두 줄었어야 한다
  → 견인이 클 때 커지는 물리적 앞섬 (가속 때 바퀴가 먼저 돌고 접지면이 따라오는 tire relaxation·롤러 탄성) 쪽에 가깝다.
  그렇다면 그 몫은 정의상 진짜 슬립이라 걷어낼 것이 아니다. (단정은 못 함 — /wheel_states stamp 와 센서 시계를 직접 맞춰 보지 않았다.)

## 2. "미끄럼 > 0.1" 이 늘 80~90 % 인 이유 (`smoothing.md`, `wheel_bias.md`)

| 묶음 | 평균 창 | 큰 슬립 % | 미끄럼 > 0.1 % | λ RMS |
|---|---|---|---|---|
| circles8 지금 | 없음 / 0.2 s / 0.5 s | 6.2 / 4.1 / **1.4** | 85.8 / 76.6 / **78.1** | 0.170 / 0.140 / 0.119 |
| circles8 후보 | 없음 / 0.2 s / 0.5 s | 10.4 / 7.5 / **5.3** | 88.3 / 78.5 / 73.9 | 0.210 / 0.172 / 0.144 |
| line | 없음 / 0.2 s / 0.5 s | 44.5 / 39.8 / 29.8 | 88.7 / 82.4 / 82.9 | 0.397 / 0.350 / 0.285 |
| square | 없음 / 0.2 s / 0.5 s | 20.8 / 12.8 / 6.7 | 83.6 / 79.3 / 80.1 | 0.292 / 0.214 / 0.164 |

- 시간차도 고주파 떨림도 아니다: 0.5 s 평균 뒤에도 > 0.1 이 74~83 % 남는다. 가속이 없는 circles8 정속 구간에서도 바퀴별 |λ| > 0.1 이 30~55 %,
  넷 중 하나라도 85 %. 바퀴별 중앙값은 ±0.02~0.05 로 작고 판마다 같은 쪽 (FR −, RL −, RR +) — 회전 방향에 따라 부호가 바뀌는 0.1 수준의
  지속 어긋남이 한 바퀴씩 있다 (기구학 T 의 유효 r·k 와 실물의 차, 또는 선회 중 롤러 미끄럼 — 가르지 않음).
- 큰 슬립 (> 0.5) 은 대부분 0.5 s 보다 짧은 튐 (circles8 6.2 → 1.4 %). A/B 의 후보 쪽 큰 슬립 증가는 평균 뒤에도 남는다 (1.4 → 5.3 %).

## 결론

- 바퀴–몸체 시간차는 슬립 지표를 크게 바꾸지 않는다. 급가속에서만 큰 슬립을 최대 1/4 부풀릴 수 있고, 그것도 물리적 앞섬 (진짜 슬립) 일 가능성이 크다.
- 실차에서 "미끄럼 > 0.1 %" 는 모든 조건에서 80~90 % 로 포화돼 조건을 가르지 못한다. 비교에는 큰 슬립 % (> 0.5) 와 λ RMS,
  짧은 튐을 빼려면 0.5 s 평균 뒤 큰 슬립 % 를 쓴다.
