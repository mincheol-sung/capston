- (바퀴−몸체)/바퀴 가 토크와 무관하게 약 10 % → 슬립보다 바퀴 유효 반지름·롤러 기구학 차이일 가능성 (확인 안 됨).
- 구동계 마찰(2026-11-14 실측)을 뺀 순토크로 계산한 모델 가속 대비 실측은 **0.70~0.74** — 바닥 하중에서 롤러·접지 손실이 약 27~30 % 더 있다. MPC 모델(무손실)은 앞으로 갈 때 가속을 약 1.4 배 과대 예측한다.
- 이 값으로 비교군 C 상한을 정하면: μ̂ 0.33 → τ_μ = (r/√2)·μ̂·(m g/4)·c_s = 0.0835 N·m (c_s 0.8). 옆걸음·대각은 4-2·4-3 으로 따로 봐야 한다.

- **0.05 N·m 는 옆걸음도 안 움직인다**(바퀴도 0). 앞·뒤 0.05 는 0.6~4 cm 움직였다.
- **옆걸음 이동은 같은 토크의 앞·뒤의 약 0.5~0.6 배**(0.2: 옆 25~31 vs 앞뒤 48~55, 0.15: 19~20 vs 33~36). Tinv^T τ 로는 Fy = Fx (둘 다 4τ/r) 라 모델 차이가 아니라 롤러 쪽 저항 차이.
- **예상과 다름**: 효율(SLAM/바퀴) 을 jjm·run1 값으로 0.2~0.5 로 예상했는데 실제는 0.68~1.0. 앞의 낮은 값은 SLAM 오류(translation_weight 10) 때이거나 다른 비교였을 수 있다.
- **왼쪽 0.15·0.20 만 FL 헛돎**: 왼 0.20 의 t = 0.25 s 바퀴 [−28.8 11.2 15.9 −17.3] — FL 이 나머지의 약 2 배. 회전 −11° 는 토크 중(0~0.5 s)에 생기고 제동 중엔 오히려 +2.7°. 오른쪽은 네 바퀴가 고르고(14~16) 회전 작음.
  - 모델 역산(앞 0.20 과 같은 방식, 대략값): 왼쪽 τ = [−τ τ τ −τ] 에서 FL 힘을 α 배로 두면 Fx ∝ 1 − α (앞), Fy ∝ 3 + α (왼쪽), Mz ∝ k(α − 1) (시계).
    부호가 관찰(앞 +9.0, 시계 −8.2°)과 맞고, 앞/옆 = 9.0/25.0 = 0.36 = (1 − α)/(3 + α) → α ≈ 0 — 이 판에선 FL 이 거의 힘을 못 냈다.
- **헛도는 바퀴의 규칙 (가설, 확인 안 됨) — 가속 중 하중 이동(load transfer)**: 가속하는 반대쪽 바퀴가 가벼워진다.
  앞 가속 → 앞바퀴 가벼움 → **FL** 헛돎 ✓ / 뒤 가속 → 뒷바퀴 → 시작 때 **RL** 가장 빠름 ✓ / 왼쪽 가속 → 왼쪽 바퀴 → **FL** ✓ (RL 은 아님) / 오른쪽 → 오른쪽 바퀴 → 뚜렷한 헛돎 없음.
  FL 이 자주 나오는 건 정지 상태에서도 FL 하중이 가장 작을 수 있다는 뜻 → **바퀴별 하중 측정**(바퀴 하나씩 저울)으로 확인할 수 있다.

## 5-2 4-3 대각 × 토크 (`diag1`, bag `bags/2026-11-15_lidar/diag1`, NUC 재부팅 뒤 새로 띄움)

바퀴 두 개만 쓴다: fl·br = FR + RL, fr·bl = FL + RR. 순서 fl → br → fr → bl (두 번에 한 번 제자리).

| 토크 | fl (FR+RL) | br (FR+RL) | fr (FL+RR) | bl (FL+RR) |
|---|---|---|---|---|
| 0.10 | 6.4 cm / +1.1° / 1.00 | 6.4 / +0.3° / 0.96 | 5.8 / +0.1° / 0.97 | 7.0 / +0.5° / 1.02 |
| 0.15 | 15.9 / **+5.1°** / 1.04 | 16.9 / +3.7° / 1.04 | 15.4 / −4.3° / **0.83** | 17.4 / +1.0° / 0.99 |
| 0.20 | 26.4 / +1.0° / 1.09 | 24.8 / +0.9° / 1.06 | 26.6 / **−6.4°** / 0.99 | 25.0 / −0.4° / 1.04 |

(칸 = SLAM 이동 거리 / SLAM 회전 / 효율 SLAM÷바퀴. 방향 오차는 모두 ±6° 안.)

- **대각은 잘 된다**: 효율 0.96~1.09 (fr 0.15 만 0.83), 방향 오차 ≤ 6°, 회전 ≤ 6.4°. 바퀴 헛돎이 뚜렷하지 않다 (fr 0.15 의 FL 12.6 vs RR 8.6 rad/s 정도).
- 쉬는 두 바퀴는 기구학상 0 이어야 하는데(fl: ω_FL = (vx − vy)/r = 0) 실제 0.1~2.2 rad/s — 맞다.
- **가속 비교** (추정기 속도의 0.1~0.45 s 기울기, 토크 0.2): 앞뒤 1.83~2.03, 옆 1.13~1.39, 대각 1.03~1.22 m/s².
  모델 Tinv^T τ (쿨롱 마찰을 바퀴마다 같게 빼도) 의 비는 옆/앞 = 1.0, 대각/앞 = 2√2/4 = 0.71. 실제는 옆/앞 0.62~0.69, 대각/앞 0.56~0.60 → 옆·대각에서 롤러 쪽 손실이 모델보다 크다.
- **예상과 다름 — 회전 방향**: FL 이 약하면 fr 은 반시계(Mz ∝ k(1 − α) > 0)로 돈다고 예상했는데 실제 fr 은 시계(−4.3°, −6.4°).
  이번엔 바퀴 계산 회전(−9.4°, −8.2°)과 SLAM 이 같은 쪽 → 헛돎이 아니라 FL 이 RR 보다 빨리 돌았고(16.5 vs 13.5) 몸체가 그대로 따라간 것. FL 쪽 저항이 작거나 RR 쪽이 큰 것으로 보인다(원인 미확인).
- **하중 이동 가설에 대해**: 바퀴당 토크가 같은 0.2 인데 앞(가속 1.8)에서는 FL 이 헛돌고 대각(가속 1.0~1.2)에서는 안 헛돈다 → 가속이 클수록 헛돈다는 쪽과 맞다.
  다만 왼쪽 옆걸음은 가속 1.13 에서도 FL 이 헛돌았다 → 옆 방향 하중 이동이 더 큰(바퀴 간격이 축간거리보다 좁은?) 것인지, 롤러 쪽 다른 원인인지 모름. 바퀴별 하중 측정으로 확인.
