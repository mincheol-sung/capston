# 바퀴를 띄운 토크 단계 시험 — 관성·마찰 식별 (2026-11-24 16:36~16:50)

바퀴 회전자 식별 지시서 W1·W2·W5. stack_changelog 2026-11-24 (2)·(4). 자동으로 만든 전체 표는 `wheel_param_id.md`, 그림은 `fig_wheel_<바퀴>.png`.

## 조건

- 로봇을 받침대에 올려 네 바퀴를 띄움 (사용자 안정민 입회·지시), ROS 스택 끔, `tools/ak40_bench.py lifted` 로 모터 하나씩.
- 순서 (바퀴 기준 토크, 사용자 승인): 0.08 N·m 0.5 s (출발용) → 0.045 → 0.030 → 0.040 → 0.035 → 0.045 (각 4 s) → 0 (자유 감속 1.5 s).
  바퀴마다 전진 3 판 + 후진 3 판 = 24 판. 실행 순서 FR → RR → FL → RL.
- 24 판 모두 "완료", 응답 누락 0, CAN 오류 0 (54 637 프레임), 최대 속도 26.5 rad/s (상한 38.7), 출발 실패 없음.
- **모터 온도 26 → 34 °C** (시작할 때 23~24 °C, 판이 지날수록 오름. FR 26~30, RR 27~31, FL 28~32, RL 29~34). 11-16 측정은 38~39 °C (주행 직후) 였다.

```
/usr/bin/python3 tools/ak40_bench.py lifted --id <N> --taus=0.08,0.045,0.030,0.040,0.035,0.045,0 --holds 0.5,4,4,4,4,4,1.5 --out_dir <이 폴더> --tag fwd_r<k>
/usr/bin/python3 tools/wheel_param_id.py <이 폴더> --out <이 폴더>
```

## 관성 J_w [×10⁻⁴ kg·m²] (명령 토크 기준)

| 방법 | FL | FR | RL | RR | 평균 |
|---|---|---|---|---|---|
| 회귀, 가속도를 왼쪽에 (`fit_wheel_params_accel`) | 8.93 | 9.31 | 9.09 | 8.87 | **9.05** |
| 자유 감속 (일정 속도 직선의 마찰 ÷ 감속도), 전진 · 후진 | 8.85 · 8.41 | 8.49 · 8.42 | 8.35 · 8.15 | 8.23 · 8.39 | **8.41** |
| 회귀, 지시서 식 그대로 (가속도가 설명 변수) | 3.55 | 3.53 | 2.94 | 3.30 | 3.33 |
| 설정 (`torque_plant.yaml`) | | | | | 8.90 |

- 두 방법이 8.4 ~ 9.05 로 설정값 8.90 을 사이에 둔다. **설정을 바꿀 이유가 없다** (W5: 9.05 로 바꿔도 m_w +1.7 %, 직진 최대 가속·μ 계산 −0.6 %).
- 지시서 식 그대로의 회귀는 3.3 으로 63 % 낮다 — 속도 잡음 때문에 가속도 계수가 줄어드는 치우침 (attenuation bias). 합성 자료로 예상한 방향·크기와 같다
  (`wheel_param_id.py --noise-study`: 잡음 0.3 rad/s · 10 Hz 에서 −57 %). 이 값은 쓰지 않는다.
- 피드백 토크 기준 회귀 (12~19) 도 쓰지 않는다 — 피드백 토크 자체가 잡음이 커서 반대쪽으로 치우친다.
- 지시서가 걱정한 "바퀴 자체 관성 누락" (10.9~12.1 이어야 함) 은 아니다.

## 구동계 마찰 τ = τ_c + b_v·|ω| (일정 속도 구간 15 점의 직선, 명령 = 실제 나간 값)

| 바퀴 | τ_c 전진 · 후진 [mN·m] | b_v 전진 · 후진 [mN·m·s/rad] | 직선 잔차 [mN·m] | 설정 (11-16) τ_c · b_v | 마찰 @ 10 rad/s: 오늘 / 설정 | @ 20 rad/s: 오늘 / 설정 |
|---|---|---|---|---|---|---|
| FL | 19.7 · 18.4 | 1.107 · 1.126 | 0.49 · 0.35 | 17.4 · 1.066 | 30.2 / 28.1 (+8 %) | 41.4 / 38.7 (+7 %) |
| FR | 21.8 · 21.6 | 1.294 · 1.281 | 0.41 · 0.13 | 20.6 · 1.158 | 34.6 / 32.2 (+7 %) | 47.5 / 43.8 (+8 %) |
| RL | 16.1 · 15.4 | 1.182 · 1.172 | 0.37 · 0.48 | 15.5 · 1.112 | 27.5 / 26.6 (+3 %) | 39.3 / 37.7 (+4 %) |
| RR | 18.0 · 18.0 | 1.242 · 1.227 | 0.36 · 0.37 | 15.7 · 1.177 | 30.3 / 27.5 (+10 %) | 42.7 / 39.2 (+9 %) |

- **방향에 따른 차이는 작다**: τ_c 는 FL 7 %·RL 4 %, FR·RR 은 같다. b_v 는 2 % 안. (11-16 값은 한 방향만 잰 것이었다 — 그대로 양방향에 써도 된다.)
- 직선이 잘 맞는다 (잔차 ≤ 0.5 mN·m, 8~25 rad/s).
- **오늘 값이 설정보다 3~10 % 크다 — 온도 차로 본다.** 오늘 26~34 °C, 설정값은 38~39 °C 에서 잰 값. 같은 바퀴 안에서도 판이 지나며 온도가 오르면
  같은 토크의 속도가 올랐다 (0.045 N·m: FL 28 °C 22.7 → 32 °C 23.8 rad/s, RL 29 °C 24.4 → 33 °C 25.2). 주행 중 온도 (38~39 °C) 에는 설정값이 더 가깝다.
- FR 이 가장 크다 (같은 속도에 다른 바퀴보다 5~8 mN·m 더) — 11-16 과 같은 순서.
