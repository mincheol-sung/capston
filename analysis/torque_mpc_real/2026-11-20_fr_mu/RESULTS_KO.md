# 바퀴별 μ — 오늘 실차 bag 으로 (FR 재측정 대신, 2026-11-20)

목적: C 의 가속을 묶는 FR μ̂ 0.285 (2026-11-19 (11) 사용자 값, 출처 bag 없음) 가 맞는지. 로봇을 움직이지 않고 오늘 정사각형 4 판
(171406·171640 퓨어 퍼슛, 171531·171735 MPC C) 의 /wheel_states (엔코더·토크 피드백)·/imu/base_link·/tracked_pose 로.
접지 토크 τ_c = |τ_fb| − (C_i + V_i|ω_i|) − J_w|ω̇_i| (2026-11-17_ramp/wheel_slip_onset.py 와 같은 식), μ = τ_c / ((r/√2)(m g/4)) = τ_c / 0.3163.

## 1. 헛돎 시작 토크 (상한 쪽) — 못 냈다
- `slip_events.py` (SLAM 속도 기준): 사건 68 건이 거의 다 네 바퀴 동시 + 낮은 토크 → SLAM 속도 오차 (17:12 판은 측위 보정 1.6 m 튐). 버림.
- `single_wheel_slip.py` (SLAM 없이, 자이로 ω_z + 나머지 세 바퀴로 몸체 속도 → 한 바퀴만 어긋남): 11 건, 대부분 RR, 토크가 낮아 한계값 아님.
  **FR 혼자 헛돈 사건은 0 건.** 실차 171640 t ≈ 3 s 의 1.4 m/s 헛돎은 한 바퀴가 아니라 여러 바퀴·몸체가 같이 밀린 것.

## 2. 미끄러지지 않고 버틴 접지 토크 (하한) — `traction_lb.py`, `fig_wheel_mu_lb.png`
네 바퀴 잔차 < 0.05 m/s (엔코더·자이로 일관) 인 표본에서 50 ms 이상 이어진 τ_c 의 최대.

| 바퀴 | 지금 설정 μ̂ | 오늘 하한 μ ≥ | 어느 판 |
|---|---|---|---|
| FL | 0.432 | 0.318 | 171640 |
| FR | 0.285 | **0.215** | 171640 |
| RL | 0.456 | **0.478** (설정보다 큼) | 171640 |
| RR | 0.350 | **0.417** (설정보다 큼) | 171640 |

- **RR 의 설정 0.350 은 너무 낮다** — 오늘 0.132 N·m (μ 0.417) 를 미끄러지지 않고 냈다. RL 도 0.456 → 0.478 이상.
- **FR 은 판정 불가** — 오늘 FR 이 낸 접지 토크가 최대 0.068 N·m (μ 0.215) 라 0.285 를 시험해 보지도 못했다.
  (정사각형 왼쪽 돌기에서 FR 몫이 작다.) FR 이 가장 약하다는 근거도, 아니라는 근거도 없다. 11-17 램프에서는 FL 5 번·FR 2 번 먼저 헛돌았다.
- C 의 앞 방향 최대 가속 (힘 분배 LP): 지금 1.18 m/s² → RR 만 0.417 로 1.31 → FR 도 0.413 이면 1.42.

## FR 을 재려면 (사람이 있어야 한다)
`amrramp dir:=fwd mu_hat:=0.6 bag:=ramp_fwd` 5 판 + `dir:=left` 5 판 (판마다 로봇을 출발점으로 되돌리고 `a`),
CSV 를 `../2026-11-17_ramp/wheel_slip_onset.py` 로. 네 바퀴 같은 토크라 먼저 헛돈 바퀴의 값만 한계 — FR 이 먼저인 판이 있어야 FR 값이 나온다.
`torque_ramp` 는 fwd·left 만이라 FR 은 1 사분면만 잴 수 있다.

## 결정 (2026-11-20, 사용자)
RR 0.417 반영은 보류 — `amrramp` 로 FR 을 잰 뒤 네 바퀴 값을 한꺼번에 정한다. 그때까지 `torque_plant.yaml surface.mu_hat_wheels` 는 [0.432, 0.285, 0.456, 0.350] 그대로.
