# 검토: 마찰 상한을 바퀴 전체 토크가 아니라 바닥 토크에 걸기 (2026-11-21, 코드 변경 없음)

## 지금
`torque_mpc.cpp` `solve_qp`: 바퀴 토크 τ_i 자체에 단순 상한 |τ_i| ≤ τ̄_i (τ̄_i = (r/√2)·μ̂_i·(mg/4)·c_s).
그런데 모델 (`G(θ)`, `m_eff`) 은 바퀴 관성을 몸체에 얹은 M = diag(m + 4J_w/r², m + 4J_w/r², I_z + 4J_w k²/r²) 이다 —
τ 의 일부는 바퀴를 돌리는 데 쓰이고 바닥에 안 간다. 슬립을 정하는 것은 바닥 몫이다.

## 식
무슬립: 바퀴 ω = Fᵀ v (F = force_map, 3×4, 행 [1 1 1 1], [−1 1 1 −1], [−k k −k k] / r), 바퀴 J_w ω̇ = τ − τ_g, 몸체 M_b v̇ = F τ_g.
→ (M_b + J_w F Fᵀ) v̇ = F τ (= 코드의 M_eff, F Fᵀ = diag(4, 4, 4k²)/r²) 이고
   **τ_g = P τ,  P = I − J_w Fᵀ M_eff⁻¹ F** (4×4, 대칭).
앞 방향 고른 토크면 바닥 몫 = 1 − (4J_w/r²)/(m + 4J_w/r²) = 1 − 2.225/6.785 = **0.672** (닫힌 꼴, LP 결과와 같다).

  8자 width 1.2 랩 3 구심 2.13 m/s² 도 2.88 안에 든다 (지금 1.94 는 모자라 상한에 81~93 % 걸렸다).

## 구현 (안)
1. `TorqueModel::ground_map()` = P.
2. `solve_qp`: 일반 제약에 블록 대각 P (스텝 j = 0 … Nc−1, 4·Nc 행) 를 더하고 경계 ±τ̄. τ 의 단순 상한은 모터 한계 ±τ_lim (1.2) 로. 변화율 제약 그대로.
   제약 수 36 → 56 (Nc 5), DAQP 일반 제약으로 그대로 들어간다.
3. 스위치 `torque_mpc.yaml torque_limit.cap_on: total | ground` (기본 total = 지금), launch 인자 하나. 기동 로그에 P 대각·앞 최대 가속.
4. 시험: gtest — 앞 고른 토크의 바닥 몫 0.672, LP 최대 가속 1.49 배, total 이면 지금과 같은 해.

## 위험 · 확인할 것
- 무슬립 가정 위의 식이다 — 상한이 지켜지면 그 가정이 맞는 영역이라 일관. 슬립이 시작되면 실제 바닥 토크는 마찰에서 잘리고 남는 몫이 바퀴 헛돎으로 간다.
- 새 μ̂ × c_s 0.8 로도 앞 2.88 m/s² 는 실측 바닥 한계 3.0 의 96 % — 여유가 거의 없다. μ̂ 를 바닥 실측 (≈ 0.43~0.48) 에 맞추면 2.4~2.6.
- 요 상한은 I_z 추정값에 달려 있다 (I_z 가 더 크면 바닥 몫이 커서 실제로는 덜 보수적이다 → 슬립 쪽). 제자리 회전 실측으로 I_z 를 먼저 재는 것이 좋다.
- 직선 C 출발 헛돎 (`RESULTS_KO.md` C 가속 스윕: 토크 0.14 N·m 에서 바퀴 0.16~0.65 m/s vs 몸체 0.06) 은 원인 미상 — 상한을 1.49 배 올리면 더 커질 수 있다. 먼저 원인을 본다.
- `torque_mpc.cpp`·`torque_mpc.hpp` 를 다른 세션이 오늘 22:11~22:12 에 고쳤다 (외란 관측기·ρ) — 같은 파일이라 그쪽과 순서를 맞춘다.
