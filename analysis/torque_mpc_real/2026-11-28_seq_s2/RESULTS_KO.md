### 판단 (2 회차씩이라 통계로는 아직 못 가른다 — p 0.19~0.43)
- 위치 RMS 는 세 가감속 모두 C 가 가장 작지만, **차이가 가감속을 올릴수록 줄어든다**: C − PP = −0.95 (1.15) → −0.64 (1.3) → −0.44 cm (1.5).
  C 가 1.15 → 1.5 에서 +0.97 cm 커지는 동안 PP 는 +0.46 cm.
- 까닭은 진행 방향: C 의 뒤처짐 평균이 +0.46 → +0.64 → +1.33 cm 로 늘어 1.5 에서는 PP·ADPP (+1.06 · +0.99) 보다 크다. 최고 속력도 C 는 기준보다 낮고 (1.43 vs 1.500),
  PP 는 기준을 넘는다 (1.57 — 바퀴 한계 V_LIMIT 1.55 m/s 도 넘음, k_along 보정 몫). 마찰 상한을 넘는 기준에서 C 가 "미끄러지는 대신 늦어지는" 설계대로 움직인 것이고,
  11-28 꺾은선 스트레스 회차 155209 (accel 1.5, 진행 오차가 주) 와 같은 모습.
- 대신 슬립은 1.5 에서 C 가 적다: 중간 슬립 38.7 vs 50.9 · 49.3 % (ADPP 대비 p 0.030), 큰 슬립 11.5 vs 15.8 · 16.5 %. 헤딩은 모든 조건에서 C 1° 안팎 vs PP 5~8°.
