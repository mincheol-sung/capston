# 옆걸음 단계 토크 — 옆 저항 (롤러 구름 저항 가설 확인)

식: Σ c_y,i·(모터 토크 − 띄운 마찰) = m_eff·a_y + F_c·sgn(v_y).  c_y = ±25 1/m (1/r), 바퀴당 1 mN·m = 옆 힘 0.10 N.
m_eff = 6.785 kg (바퀴 관성 포함, 지금 모델 6.785). IMU 위치 (0.1093, 0.0170) m 로 중심 가속을 옮김.
예측: 롤러 구름 저항 가설 (회전 저항 0.40 N·m / l_x 0.0862 m) → **F_c 4.6 N**, 지금 모델 → 0.
