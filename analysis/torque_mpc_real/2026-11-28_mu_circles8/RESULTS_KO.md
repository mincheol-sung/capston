| μ̂ | 옆 힘 상한 | 필요량 / 상한 | 측정 위치 RMS |

즉 이 원에서 μ̂ 0.33 의 C 는 "제어" 가 아니라 "스스로 건 토크 상한" 에 막혀 있었다.

## 판단
- **μ̂ 를 올리면 C 의 추종이 좋아진다 — 맞다.** 위치 RMS 11.7 → 8.0 → 3.7 cm (0.33 → 0.41 → 0.55), 0.33 대비 모두 p < 0.01. 옆·진행·헤딩이 같이 준다.
- **C 대 A 가 뒤집힌다**: μ̂ 0.33 의 C 는 PP 보다 나빴고 (11.7 vs 7.9 cm), 0.41 은 같고 (8.0 vs 7.9), **0.55 는 PP 보다 53 % 작다 (3.7 vs 7.9 cm)**. 판단 기준 (가감속 8 자에서 C > A) 에 직접 닿는 결과.
- **슬립은 거의 안 늘었다**: 큰 슬립 (> 0.5) 은 0.55 에서 7.2 % 로 0.33 (8.6) 과 같다 (p 0.62). 중간 슬립 (> 0.25) 은 0.41 에서 +12 %p (p 0.030), 0.55 는 +9 %p (p 0.23) 로 늘어 PP (43.6) 보다 높다.
  μ̂ 0.55 에서 큰 슬립의 헛돎 몫이 97 → 26 % 로 바뀌었다 (끌림 쪽) — 판 2 개라 확정은 못 한다.
- **슬립 되먹임 1.4 는 0.55 에서 나빠졌다** (3.70 → 5.74 cm, 진행 +1.0 → +2.9 cm). 큰 슬립은 5.6 % 로 조금 적다 (p 큼). 11-27 (5) 의 "1.0 이 낫다" 와 같은 방향.
- 남은 의문: **실제 바닥 μ 가 0.55 를 받쳐 주는가.** 11-24 바닥 단계 토크 시험이 0.33 (안전 계수 c_s 0.8 별도) 을 냈고, 11-17 램프는 판정 기준에 따라 0.15~0.51 이었다.
