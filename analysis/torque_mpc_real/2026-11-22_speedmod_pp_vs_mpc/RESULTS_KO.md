## 읽기

- **위치·슬립은 A, 헤딩·v_y·토크 매끄러움은 C.** 11-21 실차 비교와 같은 그림이다.
- C 의 위치 오차는 대부분 원 안쪽 +3.0 cm 치우침이다 (cross 4.1 cm, along 2.4 cm). 11-21 `../2026-11-21_pp_vs_mpc/RESULTS_KO.md` 1 절의
  "원 안쪽 약 3 cm" 와 같은 크기다 — 모델 구심 앞먹임 U_s 가 필요량의 1.4~1.6 배라는 2 절 진단과 맞는다. 적분 동작이 없어 남는다 (disturbance off).
- 헤딩: 두 판 모두 원 위에서 회전 방향으로 덜 돈다 (e_θ·sgn ω_ref 평균 A −1.23°, C −1.94°). C 는 원마다 부호가 바뀌는 ±2.5° 의 일정한 어긋남
  (11-21 2 절: 정속 회전 요 저항이 모델에 없음). A 는 교차점 (곡률 부호가 바뀌는 곳) 에서 −15°·+12° 로 튄다 — PP 는 헤딩을 따로 다루지 않고
  ω = vκ 만 내는데, lookahead 0.30 m 앞의 곡률을 미리 따라가서 교차점에서 헤딩이 크게 어긋난다.
- 속력: A 는 진폭을 다 내고 조금 넘친다 (이득 1.08, 봉우리 +5 %). C 는 봉우리에서 9 % 모자라고 (이득 0.87) 전체가 0.035 m/s 느리다.
  가속도 (IMU 기준) 도 같은 쪽: A 이득 0.99·50 ms 늦음, C 이득 0.77·지연 거의 없음. 오차 RMS 는 둘 다 0.150 m/s² 로 같다.
  d|v̂|/dt 는 잡음이 커서 (상관 0.75~0.79) IMU 쪽이 판정에 낫다.
- v_y: A 는 v_y 를 명령하지 않는데 (v_y = 0 고정) 속력 봉우리에서 바깥쪽으로 평균 0.086 m/s 미끄러진다 (구심 1.5 m/s²). C 는 v_y 를 상태로 잡고 있어
  RMS 가 A 의 55 %.
- 슬립: C 쪽이 많다. 출발 램프 (0 → 0.3 m/s, 1 m/s²) 에서 λ 1.95 까지 튀고, 그 뒤로도 4.2 % vs 1.3 %. C 는 감속 중 끌림이 대부분 (헛돎 23 %) 이고
  FL 이 가장 많다 (3.2 %). 0.5 s 평균 뒤 A 0 %, C 1.6 % — C 쪽은 짧은 튐만이 아니다.

## 검산

- 내가 다시 계산한 시간 기준 |e| RMS = 제어기 status 의 e_x, e_y RMS (A 3.5 = 3.5, C 4.7 = 4.7 cm).
- SLAM `/tracked_pose` 는 로봇 중심이 아니라 추적점 (0.1093, 0.017) m 의 포즈다. lever arm 을 빼기 전엔 추정기와 11 cm RMS 어긋났고 (시간을 +0.15~0.2 s
  밀면 줄어드는 꼴 — 앞쪽 점이라 진행 방향으로 앞서 보인다), 뺀 뒤엔 추정기 기준과 0.1~0.2 cm 차.
