## 4. C 가 왜 경로에 안 붙나 (`decomp.py`, `pole.py`, 그림 `fig_feedback.png`)
MPC 출력 τ 와 feedforward U_s 를 힘 변환 (torque_mpc.hpp `force_map`, [F_x, F_y, M_z] = (1/r)[1 1 1 1; −1 1 1 −1; −k k −k k] τ) 으로 몸체 힘으로 바꾸고,
feedback ΔF = F(τ) − F(U_s) 를 경로 좌표 (진행 t̂, 왼쪽 법선 n̂) 로 돌려 MPC 가 보는 오차 (status Xe) 와 맞춰 봤다.

1. **옆 오차는 측위 튐이 만들었다.** e_n 이 0.5 → 0.6 s 에 +10 → +100 mm. 같은 때 SLAM 포즈가 추정기 이동과 68 mm (0.49 s)·95 mm (0.69 s) 어긋남.
   C 상한으로 낼 수 있는 옆 힘 최대 Σ τ̄_i / r = 12.4 N → 1.83 m/s² → 0.1 s 동안 정지에서 옆 이동 ≤ ½·1.83·0.1² = 9.2 mm. 90 mm 는 그 10 배라 바퀴로 간 거리가 아니다.
   추정기는 위치 측정이 SLAM 하나뿐이라 (`est_mode: kf`, 입력 `/imu/base_link` + `/tracked_pose`) 튐이 그대로 들어온다 — PP 도 같은 추정기를 쓴다.
   11-21 판의 SLAM 튐 (> 3 cm) 은 17 번·최대 95 mm, 11-20 190506 은 43 번·최대 167 mm.
2. **옆으로 되돌리는 MPC 가 느리다.** 무제약 closed-loop pole (`pole.py`: torque_mpc.cpp step() 의 H·g 를 그대로 옮겨 직선에서 선형 이득 → 증강 10 상태 closed loop.
   검증: torque_mpc.yaml 2026-11-18 (4) 주석값 5.2 Hz ζ 0.72 / 8.9 Hz ζ 0.80 / 13.2 Hz ζ 0.77 / "가장 느린 ≈ −1.03" 을 5.20 / 8.87 / 13.18 Hz · −1.03 으로 다시 냄):
   지금 (Q = diag(5, 5, 2.5, 2, 2, 1), w_Δ 100, r_U 10) x·y 가장 느린 pole −0.89 (시정수 1.12 s). 실차 회귀 (포화 아닌 표본, R² 0.28) −0.58 ± 1.01j,
   이 값으로 0.9 s 뒤 남는 몫 0.59 — 측정 115 → 69 mm = 0.60.
3. **되돌리는 동안 진행 방향이 밀린다.** 옆으로 −y 힘을 내려면 FL·RR 을 올리고 FR·RL 을 내리는데, 가속 중 FL·RR 은 이미 상한 근처 → 포화 100 %, 진행 feedback −0.10~−0.15 m/s².
   = 3절 4 의 "포화 때 토크가 앞 방향 밖으로" 의 정체. 옆 오차와 lag 가 같은 바퀴 상한을 나눠 쓴다.
4. 튐 직후 큰 옆 feedback (−0.38~−0.46 m/s²) 은 위치 오차보다 추정기의 거짓 옆 속도 몫이 크다 — 무제약 이득으로 옆 위치 0.10 m → −0.04 m/s², 옆 속도 0.30 m/s → −0.22 m/s².
