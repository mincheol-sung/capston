# 구동계 마찰 보상을 빼고 d̂ 로 대신하면? — 시뮬 + 실차 bag 계산 (2026-11-23)

계기: 교수님 "구동계 마찰은 d̂ 에 포함된 외란이니 (torque_output 마찰 보상을) 빼라". d̂ = offset-free MPC 의 input disturbance estimate
(Pannocchia·Rawlings 2003, Maeder·Borrelli·Morari 2009) — 모델에 없는 힘을 잔차로 추정하는 항이 맞다. 시험할 것은 우리 d̂ 가 마찰을 대신할 수 있나.

구현: launch `friction_comp:=false` → `torque_output` `compensation_scale` 0 (coulomb·viscous·정지 마찰 보상 모두 0). 기본은 그대로 (0.9).
조건: circles8 1.6 · laps 2 · speed 0.69 · accel 3.0 계단 변조 (마찰 밖 기준) · 바닥 μ 0.55 · 플랜트 h 0.2 · C (limit_mode friction, mpc_com_height 0.2).
시뮬 플랜트 구동계 마찰 = torque_plant.yaml 실측값 그대로 (정지 마찰 없음). 기록기 `pf_rec.py` (참값 λ). `runner.sh cases*.txt runs …`

- 보상을 빼면 위치 오차 34 → 62 mm. d̂ 상한·대역폭을 바꿔도 61–64 mm — **d̂ 의 추정 문제가 아니다** (yaw 는 빠른 d̂ 에서 1.15 → 0.85° 로 조금 낫다).
- 원인은 **상한 상자 위치**: 바닥 토크 rF = τ_m − τ_f·sgn ω − J_w ω̇. 보상을 빼면 MPC 의 |τ_i| ≤ τ̄_i 가 모터 토크에 걸려, 가속 때 바닥에 가는 몫이 τ̄ − τ_f 로 준다
  (기준이 마찰 밖이라 늘 상한에 붙는 판). τ̄ 를 마찰 몫만큼 올리면 (cap13) 추종은 37 mm 로 돌아오지만, 제동 때도 같이 올라가 (바닥 |τ_m| + τ_f)
  큰 슬립 0 → 1.9 %, λ RMS 0.042 → 0.073.
- 맞는 상자는 바퀴마다 마찰만큼 비대칭: −τ̄ + τ_f·sgn ω ≤ τ_m ≤ τ̄ + τ_f·sgn ω. 이는 τ = τ_m − τ_f(ω) 로 변수를 바꾼 |τ| ≤ τ̄ 와 같고,
  **지금 torque_output 보상이 바로 이 변수 바꿈**이다 (MPC 결정 변수 = 바닥 쪽 순토크). 몸체 3 차원 상수 d̂ 는 바퀴별 상자를 못 옮긴다.
- 정리: 마찰은 "모르는 외란" 이 아니라 벤치로 잰 바퀴별 ω 의 함수라 모델 (입력 변수 바꿈) 에 두고, d̂ 는 남는 몫 (보상 ×0.9 의 10 %, 질량·μ·하중 오차) 을 맡는 지금 구조가
  offset-free MPC 의 쓰임 (점근적으로 일정한 외란) 에 맞다. 시뮬에는 정지 마찰이 없어 실차에서는 보상을 빼면 바퀴 역회전 (FL 한 판 10–12 번) 에서 더 나쁠 것.
