# MPC 입력 가중치(R) 튜닝 — Q 고정, use_w, 헤딩 있는 경로 (2026-11-20)

구조: 퓨어 퍼슛은 바퀴 PI 를 **엔코더**로, MPC 는 **추정기** 속도로 (둘 다 지금 기본값 — `wheel_pi` speed_source wheels,
`torque_mpc.yaml` velocity_source estimator). Q = `W [5, 5, 2.5, 2, 2, 1]` (교수님 지시값) 고정, R 두 항
`w_dudt` (r_τ̇, 토크 변화율) × `r_u` (r_U, 목표 입력 U_s 편차) 격자. 시뮬 `plant:=sim`, 슬립 모델 `surface_mu`, 상태 = 추정기.

## Q 를 고정하고 R 만 바꿔도 되는가 — 된다
비용 J(Q, R) 에 α > 0 를 곱하면 J(αQ, αR) = αJ(Q, R) 이고 제약(토크 상한·변화율)은 가중치와 무관 → 해가 같다.
검산 (응축 MPC 꼴 유계 최소제곱, BVLS, 입력 8 개 중 5 개가 상한에 붙은 경우): α 0.01·7·1e3·1e6 에서 |U_α − U_1| ≤ 3.6e-16.
대조: Q 그대로 r_Δ 10 → 100 이면 |ΔU| 0.35, Q 모양만 바꾸면(θ 가중 ×4) 0.52.
→ R 스윕이 덮는 것은 **Q:R 전체 비율과 R 두 항 사이 비율**. Q 안의 비율(x:y:θ:ẋ:ẏ:θ̇)은 이 스윕이 다루지 않는다.

## 1. 속도·슬립 (circles8 W2.0 tangent, 바닥 μ 0.4, 지금 R) — `speed/`, `fig_speed_slip.png`
필요 μ = √2·v²/(R g): 1.1 m/s 에서 0.349 < 0.4 → 기준이 마찰 안쪽. 퓨어 퍼슛은 0.6~1.1 m/s 내내 |λ|>0.1 시간 1.2~2.6 %
(안 미끄러지는 것이 정상), MPC B 5~47 %, C 4~15 % — **MPC 가 스스로 만든 슬립**. 퓨어 퍼슛이 미끄러지는 속도는 이 트랙의
상한(1.11 m/s) 안에 없다.

## 2. circles8 1.1 m/s R 스윕 (참고) — `R_v1.1/`, `c8_v1.1_*`
r_u 10 이면 MPC B 슬립 시간 46 → 8~13 % (위치 오차 25 → 40~52 mm). 이 판의 C 는 바퀴별 μ̂ (FR 0.285) 그대로라 상한에 묶여 뒤처졌다.

## 3. 정사각형 1.5 m/s 조건 고르기 — `../2026-11-20_square_friction/`
가속 2.5 m/s² (필요 μ 0.36): 셋 다 정사각형을 못 따라감 (윤곽 RMS 0.2~0.5 m). 가속 1.0~1.5 에서 모양이 유지된다.
**가속 1.5 m/s², 최고 1.5 m/s, 바닥 μ 0.4** 를 튜닝 조건으로 (변 가운데 실제 1.50 m/s).
슬립 지표: |λ|>0.1 시간은 tanh 마찰 모델이 저속 미끄럼까지 세서 부풀려진다 → **헛돎 = |λ|>0.5 시간**과 λ max 를 쓴다.

## 4. 정사각형 R 스윕 (가속 1.5, μ 0.4, B·C 각 20 판) — `R_square_a1.5_mu0.4/`, `fig_R_sweep_square.png`
- R 을 키울수록 B 의 헛돎·λ max 가 줄고 (지금 10 %·1.72 → w_dudt 0.003~0.01 · r_u 10 에서 4 %·0.71~0.95),
  C 의 윤곽 오차가 준다 (지금 128 → 73~91 mm). C 의 헛돎은 모든 R 에서 0 %.
- B 는 r_u 0.01~0.1 · w_dudt 0.0001 에서 이탈 (Δτ 0.05).

## 5. C 의 안전 여유 (c_s 0.8) — `c_margin/`
μ̂ 0.4 (μ̂·c_s 0.32): 윤곽 135~137 mm. μ̂ 0.45: 106~121. **μ̂ 0.5 (μ̂·c_s 0.40 = 바닥)**: 54~65 mm, 헛돎 0 %, λ max 0.46.
시뮬은 바닥 μ 를 정확히 알기 때문에 가능한 값 — 실차는 μ̂ 측정 오차만큼 여유가 필요하다.
