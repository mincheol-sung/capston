# 롤러 구름 저항을 MPC·시뮬 모델에 넣는 안 (2026-11-25, 결정 전)

근거: 11-25 실차 회전 단계 54 회 (`analysis/torque_mpc_real/2026-11-25_rot`), 옆 단계 83 회 (`analysis/torque_mpc_real/2026-11-25_lat`).
계산: `corner_estimate.py` → `corner_estimate.txt`.

## 1. 넣는 것 — 식

메카넘 롤러는 바퀴 림에 대해 미끄러지는 속도가 있을 때만 돈다. 그 속도는 접점 속도에서 바퀴 림 속도 r·ω_i 를 뺀 값이다 (T⁻¹ 행과 바퀴 위치로 계산).

| 바퀴 | 롤러 상대 속도 크기 |
|---|---|
| FL · FR (앞) | √2·\|v_y + l_x·ψ̇\| |
| RL · RR (뒤) | √2·\|v_y − l_x·ψ̇\| |

l_x = 0.0862 m (wheel_base_m / 2). 앞 속도 v_x 는 들어가지 않는다.

롤러마다 일정한 크기 F_rr 의 구름 저항 (rolling resistance, Gillespie 1992 의 F_r = C_rr·N 꼴을 롤러에 적용) 이 걸린다고 본다.
그러면 저항 일률은 P = F_rr·Σ|롤러 상대 속도| 이고, 몸체가 받는 저항은 Q = −∂P/∂[v_x, v_y, ψ̇] 이다.
아래 값은 유한차분으로 계산했다 (F_rr 0.88 N).

| 움직임 | 앞 저항 | 옆 저항 | 회전 저항 |
|---|---|---|---|
| 앞 1 m/s | 0 | 0 | 0 |
| 옆 0.3 m/s | 0 | −4.98 N | 0 |
| 제자리 회전 1 rad/s | 0 | 0 | −0.429 N·m |
| 옆이 우세할 때 (\|v_y\| > l_x\|ψ̇\|), 옆 0.3 m/s + 회전 1 rad/s | 0 | −4.98 N | **0** |
| 회전이 우세할 때, 옆 0.05 m/s + 회전 2 rad/s | 0 | **0** | −0.429 N·m |
| 접선 헤딩 원 1 m/s · 반지름 0.5 m (v_y = 0) | 0 | 0 | −0.429 N·m |

- 순수 옆걸음 저항은 4√2·F_rr, 순수 회전 저항은 4√2·l_x·F_rr 이다. 파라미터는 **F_rr 하나**다.
  - 옆 시험값 4.99 N → F_rr = 0.88 N.
  - 회전 시험값 0.37~0.44 N·m → F_rr = 0.76~0.90 N.
- 옆이 우세하면 회전 저항이 0 이 된다. 앞 롤러와 뒤 롤러의 모멘트가 서로 지워지기 때문이다.
  → 이 식으로 옆 시험에서 몸체가 1.5~18° (최대 61°) 돈 것이 설명된다. 옆걸음 중에는 회전을 붙잡는 저항이 없어서, 작은 모멘트 차이만 있어도 돌아간다. 다만 그 모멘트 차이가 어디서 오는지는 확인하지 않았다.
- 실제 계산에서는 sgn 대신 tanh(s/s₀) 를 쓴다 (s₀ = 0.01~0.02 m/s 후보).

## 3. 기대효과 — 꺾은선 정지 코너 제자리 90° (rot_s 1.0 s, 최고 2.36 rad/s · ±9.4 rad/s²)

부호는 회전 방향 기준이고, 값은 바퀴당 회전 꼴 바닥 토크 "계획 − 필요" [mN·m] 이다.
− 이면 회전 방향 토크가 필요보다 작다는 뜻이다. 가속 국면에서는 덜 미는 것이고, 감속 국면에서는 너무 세게 제동하는 것이다. 어느 쪽이든 덜 돈다.
필요 = (실제 관성 0.115 × 기준 각가속도 + 실제 회전 저항 0.43) / 19.32.

| 모델 | 가속 중간 (0.25 s) | 감속 중간 (0.75 s) | 감속 국면 평균 |
|---|---|---|---|
| **지금** (관성 0.143, 저항 0) | **−15.5** | **−29.1** | **−28.9** |
| 관성만 고침 (0.115, 0) | −22.3 | −22.3 | −22.1 |
| 저항만 넣음 (0.143, 0.43) | +6.8 | −6.9 | −6.8 |
| 둘 다, 저항 낮게 (0.115, 0.37) | −3.1 | −3.1 | −3.1 |
| 둘 다 (0.115, 0.43) | 0 | 0 | 0 |

- **지금 모델의 계획은 감속 국면에서 두 배 더 틀린다.** 관성을 크게 잡은 몫과 저항을 빼먹은 몫이 감속에서는 같은 쪽으로 더해지고, 가속에서는 일부 지워진다.
  - 실차와 맞는 쪽이다. MPC 회전각 오차가 회전의 25 / 50 / 75 / 100 % 지점에서 +0.3~0.8 / +0.8~1.7 / +1.2~2.5 / +4.1~5.1° 로, 마지막 4 분의 1 에서 가장 크게 는다.
  - 증명은 아니다. 실제 MPC 는 피드백과 외란 추정으로 일부를 고친다. 이 표는 "어느 국면에서 얼마나 틀린 계획을 세우나" 만 보여 준다.
- **관성만 고치면 오히려 나빠진다.** 가속 국면 −15.5 가 −22.3 이 된다. 저항과 같이 고쳐야 한다.
- **상한 여유:** 가속 쪽에서 필요한 값은 출발 직후 73, 가속 중간 50 mN·m 이다. 최고 각가속도에서는 78 로 상한 약 80 에 붙는다. 감속 쪽은 최대 37 이다.
  - rot_s 를 1.2 s 로 늘리면 가속 쪽 61 · 감속 쪽 17, 1.4 s 면 51 · 6 mN·m 가 된다. 이건 기준을 바꾸는 별도 선택이다.

## 4. 값 후보 — 구동 쪽 · 제동 쪽 따로 (슬립 우선)

| 롤러당 F_rr (회전 저항 환산) | 근거 | 구동 쪽 (가속 국면) | 제동 쪽 (감속 국면) |
|---|---|---|---|
| 0.76 N (0.37 N·m) | 회전 시험의 아래 끝 | 3 mN·m 덜 민다 → 덜 돎이 조금 남고, 상한 쪽으로 더 가지 않는다 | 3 mN·m 더 제동한다. 필요한 값이 −6~−37 이라 상한 80 까지 여유가 크다 |
| 0.88 N (0.43 N·m) | 옆 시험 4.99 ± 0.11 N (가장 정밀) · 회전 중앙 | 0 | 0 |
| 실제보다 큰 값 (예: 1.0 N, 0.50 N·m) | — | 더 민다 → 상한 78 에 더 붙는다 (구동 쪽 슬립 위험) | 덜 제동해서 지나친다 |

- 상한 (바닥 토크 τ̄ = 마찰계수 0.33 × c_s 0.8 기준) 은 이 항과 무관하게 그대로다. 값을 틀려도 바퀴 토크는 상한을 못 넘는다. 틀린 값이 바꾸는 것은 추종이고, 큰 쪽으로 틀리면 상한에 붙는 시간이 는다.
- 관성 (I_z) 후보: 0.06 → 0.03 (실측 I_eff 0.11~0.12 − 바퀴 몫 0.083 = 0.026~0.037). 0.06 은 균일판 4 kg 으로 가정한 추정값이었다.

| A | 시뮬 플랜트에 항 추가 (기본 0) | 시험: 0 이면 지금과 같은 출력, 유한차분 = 식. 시뮬 회전·옆 단계 시험이 실차값 (가속비 0.45 / 0.70 / 0.81, 옆 5 N) 을 재현 |

- 공정성: 이 항은 MPC 가 쓰는 플랜트 지식이다. PP 는 모델을 쓰지 않으니 줄 대상이 없다.
  모든 제어기에 줘야 하는 기구학 보정 (drive_yaw 2.4°) 과는 다르다. 발표에서는 "MPC 모델에 식별한 롤러 저항을 넣었다" 고 밝힌다.

## 6. 필요 없는 것

- 상한 식 변경: 필요 없다. 롤러 저항은 바닥 토크 τ_g 로 이겨야 하는 힘이고, τ_g 상한은 그대로 둔다.
- `fric_rolling` (바퀴마다 붙고 앞에도 걸리는 항): 쓰지 않는다. 기본 0 그대로 둔다. 앞 등속 시험의 바닥 손실은 바퀴당 2.7~5 mN·m 로 작았다.
- PP·어댑티브 PP 변경: 없다.
- 외란 추정 끄기: 필요 없다. 남는 오차를 계속 맡는다 (켬 그대로).

## 7. 결정할 것

1. 진행 여부와 범위: A·B (시뮬로 원인 확인) 만 먼저 할지, C·D 까지 할지.

4. rot_s 1.0 → 1.2 s (상한 여유) 는 따로 정한다.
