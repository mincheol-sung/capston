## 슬립 (`slip.py` → `slip_summary.json`, `fig_square_slip.png`)
λ_i = (ω_i − ω_nom,i)·sgn(ω_nom,i) / max(|ω_i|, |ω_nom,i|, ω_ε), ω_nom = T⁻¹·(참값 몸체 속도) (`slip_logger.py`).
구동이면 1 − v/(rω), 제동이면 rω/v − 1 — Wong (Theory of Ground Vehicles) 의 구동 slip · 제동 skid 를 max 분모로 합친 꼴. λ > 0 헛돎, λ < 0 끌림.

- A 의 큰 슬립은 전부 꼭짓점 0.3 m 안, 92~98 % 가 끌림 (λ < 0, 바퀴가 지면보다 느리게 돈다) . 시각은 PP 가 꼭짓점 전에
  꺾기 시작하는 구간과 겹친다 (stop r1 첫 꼭짓점: 헤딩이 t 1.5 s 부터 돌고 큰 슬립도 1.4~2.0 s). 어느 바퀴가 왜 끌리는지는 아직 안 봤다
  (r1 바퀴별 최대는 pass FL 1.00·RR 1.09, stop FR 1.85). stop 에서도 18 → 13 % 로만 준다.
- B·C 는 stop 에서 큰 슬립 0. C 는 pass 에서도 0 (마찰 상한이 바퀴 토크를 묶는다).
- 앞서 (2026-11-20 표들) "헛돎" 이라 부른 |λ| > 0.5 비율은 A 에서는 대부분 끌림이다 — 이름을 "큰 슬립" 으로 바로잡는다.

## 읽기
- **C 가 B 와 같아졌다.** 시간 추종 RMS 103~110 → 51~54 mm, 윤곽 RMS 53 → 20~21 mm, 뒤처짐 −60~−73 → −11~−15 mm.
  포화 49 → 7~8 %, 앞먹임이 상한을 넘는 시간 32 → 0 % — 2026-11-20_square_profile 의 계산 (stop 이면 앞먹임 최대 0.96) 과 맞는다.
  남은 포화 7~8 % 는 직선 가감속 (RR 상한의 96 %) 에 피드백이 얹힌 순간.
- B 는 시간 추종은 그대로 (53~58 → 53~54), 윤곽·헤딩·큰 슬립이 조금 좋아졌다 (큰 슬립 0.4~1.0 → 0 %).
- **A (퓨어 퍼슛) 는 stop 에서 헤딩이 나빠졌다** (RMS 13 → 25°, 최대 40 → 85°). 원인 (PP_stop_r1, 첫 꼭짓점):
  기준이 1.5 m/s 에서 꼭짓점으로 감속하는 동안 룩어헤드 0.30 m 원이 다음 변과 만나 κ = 2y_l/L² 가 커지고, PP 가 꼭짓점 전에 이미 돈다
  (t 1.5 s 에 ψ 20°, 1.9 s 에 77°, 기준 헤딩은 0°). 로봇은 (1.53, 0.13) 까지 다음 변으로 올라가고, 기준이 서서 돌기 시작하면
  회전 모드 ω = ω_ref + k_heading (θ_ref − θ) 가 헤딩을 77° → 47° 로 되돌렸다가 기준을 따라 다시 돌린다.
  = 퓨어 퍼슛 기하가 꼭짓점을 미리 도는 구조적 성질. 꼭짓점 정지 기준에서도 A 의 "코너 자르기·헤딩 앞서감" 은 남는다.
- 대가: 주행 9.1 → 13.1 s (꼭짓점 3 개 × 1.2 s + 감속을 0 까지).
