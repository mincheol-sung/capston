# 구동계 마찰 보상을 빼면? — 시뮬 (2026-11-23)

질문: torque_output 의 마찰 보상 (coulomb·tanh(ω/ω_s) + viscous·ω, 측정 ω 방향, × compensation_scale 0.9) 은 MPC 모델 밖이니 빼도 되나.

## 모델 안·밖
- MPC 예측 모델 Ẍ = M⁻¹R(θ)(T⁻¹)ᵀτ + w 의 τ 는 **바퀴에 실제로 전달되는 순토크** (torque_output.py 머리말 "바닥에 전달하려는 토크").
  감속기·베어링 마찰은 모델에 없다 → 마찰 자체가 모델 밖이고, 보상은 모터 명령 = τ + τ_fric 로 그 마찰을 지워 **구동기를 모델이 가정한 이상 토크원으로 만드는 층**
  (model-based friction compensation, Armstrong-Hélouvry·Dupont·Canudas de Wit 1994, Automatica 30(7)).
- 보상을 빼도 마찰은 없어지지 않는다 — 모델 밖 외란으로 플랜트에 남는다.

- **A 는 거의 그대로, B·C 는 4 배 나빠진다.** A 의 바퀴 PI 는 적분기가 마찰을 스스로 메운다. MPC 는 적분 동작이 없고 외란 추정이 기본 꺼짐이라
  마찰만큼 순토크가 모자란 채로 뒤처진다 (MPC |τ| 평균은 켬·끔 모두 0.045~0.047 — 더 내지 않았다).
- 보상을 빼면 비교가 MPC 에 불리하게 기운다 (A 는 PI 적분으로 보상받고 B·C 만 못 받는다).
- 슬립은 이 속도에서 켬·끔 모두 큰 슬립 0.
