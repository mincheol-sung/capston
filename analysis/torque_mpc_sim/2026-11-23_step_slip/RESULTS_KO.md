## 왜 계단 변조인가 (`../2026-11-23_min_time/` 계산)
- 같은 랩타임 등속 (gerono) 은 굽은 곳 바퀴 속도 부하 114~129 % → 기준 노드 거부·모터 한계. 쓸 수 없다.
- 부하 예산 (1.55) 안의 정상 선회로는 μ_hat 을 못 넘는다: 최대 C 상한의 1.197 배 (R 0.19 m) < 1.25 (= 1/c_s).
- 가감속이 선회와 겹치면 넘는다: circles8 width 1.6, speed 0.69 (부하 99 %), speed_mod_shape square (0.345 ↔ 1.035 m/s), accel 2.0 → 필요 토크 C 상한의 2.1 배, μ_hat 넘는 시간 10 %.
- speed 0.70 은 부하 100.47 % 라 기준 노드가 거부 (runs/ 의 네 판은 무장만 되고 DAMPING) — 반올림한 값을 그대로 쓴 실수.
