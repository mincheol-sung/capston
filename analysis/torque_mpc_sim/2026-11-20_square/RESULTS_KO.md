# 정사각형 경로 시뮬 비교 — MPC (B·C) vs 퓨어 퍼슛 (2026-11-20)

기준: `shape:=square` (core/square.py, stack_changelog 2026-11-20 (4)). 한 변 1.5 m, 1 바퀴, 왼쪽으로, `yaw_mode:=tangent`
(꼭짓점 헤딩 완화 0.3 m, 끝에서 align_s 1.5 s 제자리 회전), 꼭짓점 0.1 m/s, 변 가운데 최고 √(0.1² + a·1.5).
시뮬 `plant:=sim`, 슬립 없음, 상태 = 추정기 (잡음 포함) — `_truth` 판만 참값 상태. ROS_DOMAIN_ID 93. 판마다 1 회.
B = `limit_mode` motor_only (τ̄ 1.2 N·m), C = friction (바퀴별 μ̂ [0.432, 0.285, 0.456, 0.350] × c_s 0.8 → τ̄ FR 0.0721).
퓨어 퍼슛 상한은 같은 날 바뀐 v_max 1.7 · w_max 8.7 (`pp_a1.0_w3` 만 w_max 3.0 — 설정 복사본을 `AMR_MPC_TORQUE_BASELINE_A_YAML` 로).

## 읽은 것
1. 퓨어 퍼슛은 꼭짓점을 72~79 mm (a 0.4) · 152~168 mm (a 1.0) 안쪽으로 지난다. 참값 상태로 돌려도 158~161 mm 라
   추정기 탓이 아니라 구조 (룩어헤드 L_d = 0.5 s × v, 꼭짓점 근처 v 가 커지는 a 1.0 에서 더 깊다). w_max 3.0 ↔ 8.7 차이 없음.
2. MPC B 는 꼭짓점 4~43 mm. 참값 상태면 10~12 mm, 추종 RMS 8.4 mm → 추정기 상태 판의 오차 대부분은 추정기 몫
   (mpcB_a1.0 의 43 mm 는 꼭짓점 앞 0.25 m 를 변과 나란히 안쪽 약 35 mm 로 달려온 것이지 대각으로 자른 게 아니다 — fig_trajectory 아래 확대).
3. MPC C a 1.0: 꼭짓점 통과 1 mm 는 우연 — 위 변을 바깥 50~65 mm 로 달려와 꼭짓점을 바깥에서 스치며 지났다 (윤곽 RMS 39.5).
   가속 1.0 m/s² 는 병진만으로 C 상한의 94 % (2026-11-20 계산) 라 꼭짓점 헤딩 회전·보정 토크를 더하면 상한에 묶여 뒤처지고 밀린다.
   C 로 정사각형을 보이려면 a 0.4 (38 %) 쪽.
4. 퓨어 퍼슛 토크가 꼭짓점 0.2 s 앞에서 한 틱 0.49~0.52 N·m 로 튄다 (세 꼭짓점 모두). w_max 3.0 판도 같아 오늘 상한 변경과 무관.
   원인 (룩어헤드 점이 다음 변으로 넘어가며 곡률이 바뀌는 순간으로 추정)은 확인 안 함 — ω 명령을 기록하지 않았다.
5. 헤딩 고정(fixed) MPC 는 요 RMS 0.26°, 윤곽 RMS 10.5 mm. 퓨어 퍼슛은 v_y = 0 이라 이 모드를 못 돈다.
