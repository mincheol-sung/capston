# 현재 MC 설정의 충돌확률 추정 정확도 — 2026-10-22

**그림 업데이트(2026-10-23):** `probability_comparison.png`는 사용자 요청으로
**8배 MC 예산(밀도992)** 결과로 교체했다. 아래 본문의 수치와 원시 CSV는 기존
1배 측정 기록이다. 이전 그림은 `probability_comparison_density124.png`에 보존했다.
8배 수치는 [예산별 결과](../mc_budget_theta_2026-10-23/results.md)를 참고한다.

현재 YAML을 변경하지 않고 검사했다. 설정: `monte_carlo`, scrambled Halton,
밀도124/m², guide 최소128/최대1024, final 최소256/최대4096,
underresolved reject=true, 반경0.45m, epsilon=0.05, K500, N10, dt0.2.
Adaptive Halton이므로 `mc_samples: 2048`이 실제 고정 표본 수가 아니다.
이번 실제 후보 영역에서 사용한 수는 guide **128~425/step**, final **256~620/step**였다.

**결론: 평균 오차는 약 1%p이지만, 5% 임계값 주변을 정확히 구분한다고 보기는 어렵다.**
아래 수치는 제공된 Gaussian 확률모델의 원형 충돌영역 확률과 MC 추정의 차이다.
실제 사람의 미래 위치/충돌 실측 자료가 없어 예측모델의 실세계 보정 정확도는 측정하지 않았다.
표에서 %p는 절대 확률 차이다. 예를 들어 5%→7%는 2%p 오차이다.

## 시험과 기준값

1. 고정 기준점 40개 분포: 등방 sigma .08/.2/.6, 좁거나 넓은 회전 이방 분포,
   1/5/10/20개 장애물 및 2-mode 혼합. 등방은 참확률 1/4.9/5.1/10/50/90% 중
   해당 분포에서 가능한 값을 사용했다. 이방은 5% 임계값 양쪽 거리를 사용했다.
   다른 후보의 중심 범위(span)를 0/.25/.5/1/2m로 바꾸고 16개 Halton scramble로 반복했다.
   target 위치는 같으며 영역에 포함되는 다른 후보만 변한다. 각 평가의 세 중심은
   영역 외곽을 지정한다. 표본 설정을 정확히 동일하게 사용했고 K500 시험은 아래 별도 수행했다.
2. 실제 controller가 만든 K500 guide fan, 최종 5대표+Stop 형상:
   초기 yaw 0/-70/180도, 단일 횡단/정면접근5/평행이동10/다중모드20,
   N10, 8개 scramble 반복. Guide별 분리 영역과 최종 공통 영역을 실제 구현으로 평가했다.
   최종 후보 형상은 위험비용 OFF로 한 번 생성해 고정한 후 각 위험 분포에 적용했다.
   위험비용을 반영한 최적화의 최종 선택이나 로봇 폐루프를 검사하는 시험은 아니다.
3. 기준값: 등방 Gaussian은 비중심 chi-square CDF,
   회전 이방 Gaussian은 별도 polar radial/angle 적분(80→160 refinement).
   Covariance floor와 1e-12 regularization, mode mixture, 장애물 독립 결합을 구현과 일치시켰다.
   이방 기준 적분의 최대 refinement 차이는 2.67e-15였다.

총 **492,160개 candidate-step 추정값**(고정점 6,400 + guide480,000 + final5,760).
이들은 같은 환경과 후보에 대한 반복값이므로 독립적인 49만 개 주행 실험이 아니다.
기본 seed17에서 guide1009+g/final2003 offset을 적용하고 repeat 값을 더했다.
repeat0은 운용 estimator 초기 seed와 같고, 이후 repeat는 scramble 민감도를 본다.
실행시간 약 11.3초; ROS 장기 시험과 파라미터 튜닝은 수행하지 않았다.

## 5% 위험 임계값 판정

여기서 false-safe는 기준 확률>5%인데 MC≤5%인 경우다.

| 평가 | 전체 위험 step 중 false-safe | 기준 확률 3~10% 구간의 위험 step 중 false-safe |
|---|---:|---:|
| Guide 1차 | 2,621/222,808 (1.18%) | 2,500/38,848 (6.44%) |
| 최종 대표/Stop | 26/2,976 (0.87%) | 25/208 (12.02%) |

Final의 step false-safe는 26건이고, 기준 확률≥6%인 경우도 15건 포함됐다.
예: 정면접근5, yaw−70°, 대표3, timestep index6: **기준10.5142% → MC4.6451%**.
Guide에서도 기준15.6050% → MC4.7583%인 사례가 있었다.

반면 10 step 중 하나라도 epsilon을 넘으면 위험으로 판정하는 전체 궤적 기준에서는:

- Guide: 위험 궤적 28,224개 중 false-safe 95개.
- Final: 위험 궤적 368개 중 false-safe 0개.

Final step에서 낮게 추정한 궤적은 다른 step이 위험으로 검출됐다.
따라서 26 step 오류가 최종 위험 궤적 26개 통과를 의미하지 않는다.
Final의 전체 궤적 false-safe 0건도 모든 분포/입력에서의 안전 보장은 아니다.
이 검사는 대표들의 위험 판정만 비교하며 switching/선택 후 실제 충돌 여부는 측정하지 않았다.

## 분포·영역 크기 영향

Underresolved가 아닌 고정점 시험만 포함한 분포별 오차:

| 분포 | Guide 평균 / p95 / 최대 (%p) | Final 평균 / p95 / 최대 (%p) |
|---|---:|---:|
| 등방, 다양한 확률 | 1.43 / 7.27 / 25.05 | 1.55 / 7.23 / 36.31 |
| 회전된 좁은 분포, 5% 근처 | 0.90 / 2.14 / 4.17 | 0.84 / 2.24 / 5.55 |
| 회전된 넓은 분포, 5% 근처 | 0.39 / 1.04 / 1.87 | 0.40 / 0.99 / 2.33 |
| 분리된 2-mode 혼합, 5% 근처 | 0.90 / 2.26 / 4.19 | 0.86 / 2.16 / 5.45 |

동일 target의 다른 후보를 ±1m/±2m까지 벌리면 guide 공유 사각형 면적이
8.41/24.01m²가 되고, 밀도124로 요구되는 표본이 guide 상한1024를 넘는다.
각 span의 640회 모두 `mc_reject_underresolved=true`에 의해 CP=1로 처리됐다.
이는 적분 성공값이 아니라 보수적인 invalid 처리이며, 위 분포별 오차 표에서 제외했다.
Final 상한4096은 이 영역 크기를 수용했지만 좁은 분포에서는 큰 적분 오차가 남았다.
실제 K500 fan에서는 guide 면적 .956~3.423m², final .926~4.997m²였고,
underresolved와 empty-circle은 모두 0이었다. 적분 오차는 이 보호장치가 발동하지
않는 경우에도 발생했다.

## 해석

현재 예산은 빠르지만 σ가 작은 밀도의 급한 변화와 원형 경계를 적은 표본으로
적분하는 데 한계가 있다. 서로 다른 후보들이 사각형을 넓히면 같은 target CP도
추정치가 달라진다. 평균 오차만으로 5% 임계값 판정의 신뢰성을 나타낼 수 없다.
높은 정확도가 필요하면 이 시험의 임계값 오분류까지 확인하며 예산/적분 방법을
검토해야 한다. 이번 요청에서는 YAML이나 planner 계산 방식을 수정하지 않았다.
