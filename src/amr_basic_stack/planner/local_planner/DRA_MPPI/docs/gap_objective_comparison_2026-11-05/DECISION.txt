2026-11-05: gap 목표점별 비용 기준 비교 및 권고

2026-11-06 재검토: 아래 권고는 일관성 중심 baseline이며 성능 우위가 입증된 것이 아니다.
seed 순위와 실제 MPPI 대표 순위가 뒤집히는 저장 사례를 추가 확인했다.
후속 근거와 적용 한계는 ../gap_objective_review_2026-11-06/REVIEW.txt 참조.

결정: 방향별 가치를 판단하는 기준은 기존 MPPI의 비동적 비용을 재사용한다.
새로운 gap 전용 가치 기준/가중치를 별도로 유지하지 않는 방향을 권고한다.
다만 기존 함수를 그대로 수치미분 반복하는 구현은 현 50ms 후보 예산에 부적합하다.
권고 계산 구조는 기존 공통 주행 비용의 미분 가능한 국소 근사로 seed를 구하고,
완성된 seed/nominal을 실제 기존 비용으로 재평가하여 샘플 배분에 사용하는 것이다.
이 문서는 설계 결정이며 운영 gap 최적화 코드를 변경하지 않았다.

1. 두 비용의 차이 (코드 확인)
기존 common_cost.py:
  전역 경로까지의 평균 제곱거리 * 64
  경로 arc-length 진행 오차 제곱 * 8
  경로 heading과의 wrap된 오차 제곱 평균 * 3
  경로 방향 속도와 공통 기준 속도의 오차 제곱 평균 * 1.78
  입력 변화량 제곱 평균, 축별 [0.5, 0.5, 0.055]
  실제 goal 근처에서만 terminal 위치 오차 제곱 * 24
  정적 soft 비용은 별도 _static_obstacle_cost에서 추가된다 (현재 가중치 8).
현재 gap_optimization.py:
  공통 기준점까지 종단 Euclidean 거리 제곱 * 8
  해당 gap 중앙 방향선까지 거리 제곱 평균 * 4
  고정 시간별 경로 heading과의 unwrapped 오차 제곱 평균 * 3
  입력 변화량 제곱 평균, 축별 [0.5, 0.5, 0.055]
  기존 path_error, 경로방향 speed, near-goal terminal 및 정적 soft 항이 없다.
따라서 이름이 유사해도 같은 비용을 빠르게 계산하는 관계가 아니다.

2. 실제 저장 데이터 비교
자료: gap_value_optimization_2026-11-05/raw 및 *_results.npz의 16개 bag 장면.
같은 seed 제어열을 고정한 채 현재 gap 비용 / 기존 공통비용 /
기존 공통비용+정적 soft로 각각 재평가했다. 동적 비용은 전혀 사용하지 않았다.
기존 실험에서 수렴했고 정적 충돌이 없는 gap seed를 사용했다.
nominal도 함께 평가하지만 순위 변경 집계에서는 gap끼리만 비교했다.
여러 gap seed가 있는 장면 11개 중 6개에서 순위가 달라졌다.
가장 낮은 비용의 gap 자체가 바뀐 장면은 1개다.
동일 seed의 순위 비교이며 각각 새 비용으로 완전히 최적화한 해의 순위 비교는 아니다.

최종 주행 품질 개선이나 dynamic-aware 최종 순위를 입증하는 실험은 아니다.

3. 계산량
장면별 nominal+유효 gap 전체를 한 번에 평가, 2회 warmup 후 10회 측정:
  현재 gap 평가: 평균 0.147ms, p95 0.239ms.
  기존 공통+정적 soft 평가: 평균 0.813ms, p95 0.909ms.
  이 시간에는 별도 swept hard 검사와 geometry/MPPI/ROS가 포함되지 않는다.
따라서 완성된 소수 seed를 기존 비용으로 재평가하는 비용은 이번 입력에서 작았다.

장면당 첫 유효 gap 1개씩, 기존 저장 seed와 동일 도달점으로 value만 다시 최적화:
  기존 공통비용, 30변수 벡터 유한차분:
    평균 40.080ms, 최대 119.416ms, 16개 중 수렴 15.
  기존 공통+정적 soft, 30변수 벡터 유한차분:
    평균 73.491ms, 최대 251.313ms, 수렴 13, 250ms deadline 2개.
    1개는 45회 iteration limit 도달.
  현재 해석미분 gap 목적함수: 평균 1.104ms, 16개 수렴.
    다만 초기값이 이미 이 gap 목적함수로 최적화된 저장 seed이므로 유리한 조건이다.
    이 숫자로 목적함수 자체의 계산속도 비율이나 최적 알고리즘 간 우열을 단정하지 않는다.
  새 해석미분/근사 solver의 성능을 측정한 것은 아니다.

4. 권고할 최종 구성
  a. 방향별 목표점 q_g = p0 + min(D_g, d_g) e_g는 제약으로 둔다.
     q_g에 잘 도착했다는 오차만 비교하면 방향의 가치가 구분되지 않는다.
     공통 경로/진행 기준은 모든 gap에서 유지한다.
  b. J_base = J_path + J_progress + J_heading + J_speed + J_delta + J_terminal.
     의미/가중치는 MPPI 설정과 공유한다. gap 중앙선 직진 항을 별도로 추가하지 않는다.
  c. 최적화 중 경로 투영의 활성 선분 등을 고정/갱신하는 국소 근사와 해석미분을 사용한다.
     실제 rollout이 비선형이므로 제곱 잔차만으로 전역 QP가 되는 것은 아니다.
     이 solver는 아직 구현/측정하지 않았다. 정확한 원비용의 단조 개선/제약 위반을 검사해야 한다.
  d. 완료한 seed에 대해 실제 common_costs와 정적 soft를 재계산한다.
     swept hard 충돌이면 배분 후보에서 제외한다.
     score_g = J_base(seed_g) + J_static_soft(seed_g).
     동적 비용은 이 seed 최적화/점수에서 제외하며 최종 MPPI의 동적 검사는 유지한다.
  e. nominal도 같은 실제 비용으로 평가하여 기존 가변 배분에 사용한다.
     원비용 재평가 점수는 근사 seed의 실제 점수이며 전역 최적 비용이라고 부르지 않는다.
  f. 후진/우회는 기존 진행/속도 항에서 불리할 수 있다.
     비용만으로 전부 제거하지 않고 기존 최소 배분과 균등 탐색분을 유지한다.
     최대 3개 제한으로 모든 후방 후보의 보존이 보장되는 것은 아니다.

5. 아직 주장할 수 없는 것
  권고한 근사 solver의 50ms 충족, 변경 후 전체 5Hz, 주행 성공률 개선은 미검증이다.
  이번 비교는 비용 기준 선택을 위한 offline 분석이다.
  운영 코드, 설정, ROS 주행 동작은 이번 분석에서 변경하지 않았다.
