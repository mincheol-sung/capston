2026-11-06: gap 비용 설계 재검토

결론
기존 MPPI의 비동적 주행 비용을 공통 기준으로 쓰는 것은 합리적인 baseline이다.
그러나 이전 비교의 'seed 비용 순위가 다르므로 기존 비용을 쓰는 편이 더 낫다'는
추론만으로 배분 성능 향상을 주장할 수 없다. 두 비용의 최종 주행 성능 우열은 미검증이다.
공통 비용 구성은 유지하되, 고정 목표점 seed의 비용은 탐색 가치의 근사 지표로 취급한다.
이번 검토에서 운영 코드/가중치/배분 동작은 변경하지 않았다.

중요한 구분
1. seed 최적화는 p_N ~= q_g라는 특정 최대거리 목표점 조건이 있다.
2. MPPI 샘플과 대표는 그 q_g에 도달하도록 종단이 고정되어 있지 않다.
3. 따라서 같은 J를 써도 seed 점수와 최종 그룹 대표 점수의 순위는 다를 수 있다.
4. seed에서의 J를 더 정확히 최소화하는 것만으로 이 차이가 없어지지는 않는다.

실제 저장 결과 재평가
자료: gap_value_optimization_2026-11-05/nominal_distribution_b2_060/replay_arrays.npz.
동일 b2_060 저장 샘플/대표를 기존 common_costs + static soft로 재평가하고,
swept static collision 후보는 invalid 처리. 동적 비용은 이번 재평가에서 제외.
초기 seed 비용은 앞선 comparison.json과 같은 정의:
                       G1          G2
seed 점수              8.413       6.958
저장 MPPI 대표 점수     1.983       5.226
저장 샘플 유효 하위10%  2.157       4.674
원래 샘플 수           167         89
전체 샘플 중 정적유효  161         57
저장 대표는 원 실험의 동적 평가를 포함한 MPPI가 만든 것이다.
이번에는 해당 제어열을 바꾸지 않고 동적 비용 없이 재평가했다.
샘플 수가 다르므로 통제된 배분 정책 비교나 인과적 성능 개선 증거는 아니다.
하지만 특정 seed 점수의 우열이 그 주변 MPPI 대표의 우열과 같다는 주장은 성립하지 않는다.
원시 결과: b2_060_nodynamic_recheck.json.

비용 항 검토
- path / progress / speed는 완전히 같은 항이 아니다.
  path는 경로 이탈, progress는 종단 경로 진행 위치, speed는 중간 단계 속도다.
  speed는 종단 진행량이 같더라도 중간의 정지/급가속 패턴 등을 구분할 수 있다.
- 목표점이 고정되어 있으면 단순한 경로에서 종단 progress 항은 사실상 상수이다.
  이 항은 seed 내부 모양 개선에는 영향이 작지만 서로 다른 gap 목표점 비교에는 필요하다.
- heading은 차체 yaw와 경로 heading의 차이이며 병진 방향과 동일하지 않다.
  메카넘 후진/측면 이동 자체에 yaw 회전을 강제하는 항으로 바꾸면 안 된다.
- 실제 goal 근처의 terminal 항은 조건부이며 일반 주행에서는 0이다.
- 별도의 gap 중앙선 직진 항을 기존 path 항 위에 더하지 않는다.
- 동적 비용은 seed 점수에서 제외하고 최종 MPPI 위험 평가에 유지한다.
- 정적 충돌은 별도 배제, 정적 soft는 seed 완성 후 실제 비용으로 평가한다.
- 기존 가중치 공유는 최종 기준과의 일관성을 위한 초기 기준이지 최적 가중치 인증이 아니다.

최대거리 목표점 해석
q_g = p0 + min(D_g,d_g)e_g를 고정하면 d가 줄 때마다 서로 다른 종단 조건이다.
따라서 d가 줄어들 때 최적 비용이 반드시 증가한다는 수학적 보장은 없다.
반면 '최대거리 안의 어떤 종단도 허용'하는 문제는 영역이 축소되므로,
다른 조건이 동일하고 전역 최소를 구한다면 최적 비용이 감소하지 않는다.
두 정의는 다른 설계이다. 후자는 정지/아주 작은 이동을 택해 후보가 중복될 수 있어
최소 이동량 등 별도 조건이 필요하다. 사용자 합의 없이 고정 목표점 방식을 바꾸지 않는다.

권고
공통 비동적 MPPI 비용 + 정적 후평가를 baseline으로 유지한다.
새로운 가중치를 임의로 확정하거나 '기존 비용이 더 좋음'으로 결론내리지 않는다.
seed 점수 기반 배분은 부드럽게 하고 기존 최소 배분/균등 탐색분을 유지한다.
최대 3개 후보 제한에서는 최소 배분만으로 모든 gap의 탐색을 보장하지 못한다.
다음 성능 비교는 같은 scene/상태/nominal/노이즈/총 예산과 동적 설정으로
실제 그룹 대표의 비용 개선 및 막힘/후진 성공 여부까지 비교해야 한다.
최적 seed 점수나 최저 한 샘플 점수만으로 정책 우열을 판정하지 않는다.
