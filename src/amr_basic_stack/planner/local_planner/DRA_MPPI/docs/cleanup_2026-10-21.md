# 2026-10-21 전략 정리

지원 전략은 `standard`와 `guide_conditioned`(guide-only)다.

- Crab/Turn `mode_conditioned` 구현, `mppi.mode_*`, 전용 RViz 표시 제거.
- 사용하지 않는 `cost.cross_track_gain`, `cost.max_cross_track_speed`,
  `traversability.clearance_margin`, `static_cost.hard_penalty` 제거.
- 공통 비용으로 대체된 이전 tracking/heading/speed/rotation 비용 함수와
  distance field의 이전 exponential 비용 함수 제거.
- guide anchor가 실제 사용하는 경로 기하 계산은 유지.
- guide-only에서는 standard용 noise 배치를 생성하지 않음.
- 공통 비용, static on/off, 동적 위험, Stop, 종단 정렬은 유지.
- 기존 가중치와 속도 설정값은 변경하지 않음.

이전 검증 폴더와 2026-10-20 보고서는 당시 결과를 보존한 기록이다.
그 안의 제거된 파라미터는 현재 설정 예시가 아니다.
noise/cost 변경은 YAML 수정과 노드 재시작으로 적용하며,
`static_cost.enabled`는 런타임 변경을 지원한다.

검증: pytest 160개 통과, `colcon build --packages-select dra_mppi` 성공.
설치된 패키지에서 두 전략의 ROS 노드 초기화, 제거된 파라미터 미선언,
`static_cost.enabled` false/true 런타임 전환을 확인했다.
실차 주행과 장시간 p99 측정은 이번 정리 작업에서 수행하지 않았다.
