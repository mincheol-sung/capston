2026-11-06 실제 bag 장면 기반 gap seed 비용 / 샘플 배분 분리 실험

결론
현재 5Hz 목표의 운영 후보로는 기존의 가벼운 4항 seed 비용을 유지한다.
기존 MPPI 주행 비용을 seed 최적화에 그대로 넣으면 gap 대표의 품질은 좋아졌으나,
이번 직접 최적화 구현에서는 계산 시간이 너무 늘었다. 비용 기반 샘플 배분의
전체 성능 향상은 확인되지 않았다. 현재 비용/배분이 최적이라는 결론도 아니다.
운영 planner, YAML, 500개 평가 비용, 최종 대표 평가/선택 코드는 수정하지 않았다.

1. 무엇을 실제로 실험했는가

원본 MCAP에서 이전 작업 때 추출하고 원본과 대조했던 16개 스냅샷을 사용했다.
이번에는 raw/*.npz를 재사용했으며 MCAP을 다시 추출했다고 주장하지 않는다.
원본 bag: mpc_chain_20260923_113151, _135325, _135606.
위치/시각/파일 해시는 configuration.json 및 각 *_seeds.json에 기록했다.
동적 예측이 저장된 장면은 6개. 모든 최종 평가에서 해당 예측을 유지했다.

  6가지 seed 목적함수 × 3가지 배분 × 16장면 × 8개 paired 노이즈 = 2,304회
  nominal 단독 500개 대조군 × 16장면 × 8개 노이즈 = 128회
  합계 2,432회, 매회 실제 rollout 500개, 총 1,216,000개 샘플 궤적 평가.
  별도로 전체 오프라인 처리 시간 6방법 × 16장면 × 3회 = 288회 측정.

각 방법을 실제로 다시 최적화했다. 저장 seed의 비용만 다시 계산한 실험이 아니다.
각 그룹에서 기존 MPPI 가중 평균으로 대표 제어열을 만들고, 대표를 실제로 다시
rollout/evaluate하여 최종 대표를 선택했다. 정적 충돌 및 동적 위험 기준도 그대로다.

2. 공정한 비교를 위해 고정한 조건

- 동일 LiDAR/맵/경로/현재 속도/기록된 nominal.
- 동일 gap 중앙 방향, 동일 최대거리 목표점, 동일 초기 제어열.
- N=10, dt=0.2초, 2초 예측구간. 메카넘 속도/가속도/휠 제약 동일.
- 같은 trial의 제어 Halton 노이즈 및 위험 적분 난수의 시작점을 맞춤.
  그룹 수/샘플 수에 따라 위험 적분 공간은 기존 구현대로 달라진다.
- gap 그룹은 현재 4항 비용으로 최대 3개를 고른 뒤 모든 방법에 동일하게 고정.
  즉, 새 비용에 유리하게 gap을 다시 선택하지 않았다. 현재 비용을 선호할 수 있는
  설계상의 한계이며, 새 비용에 따른 gap 선택 정책 자체는 이번 검증 범위 밖이다.
- nominal 최소 100개, gap마다 최소 30개, 총 500개를 동일하게 유지.
- 각 snapshot/trial마다 시간적 히스테리시스와 warm start 이력을 초기화.
  시간 연속적인 전환 안정성은 이 실험으로 검증하지 않았다.

구역에서 얻은 방향 후보는 51개. b2_100 G2는 최대거리 최적화가 수렴하지 않아
모든 방법에서 공통 제외했다. 나머지 50개에 대해 각 목적함수를 최적화했다.
최종 고정 그룹에 들어간 gap은 16장면 합계 39개다.

초기값은 특정 비용으로 이미 최적화했던 과거 seed가 아니라, 비용과 무관한
도달거리 최적화 결과를 사용했다. 최적화 실패 또는 정적 충돌이 발생하면
모든 방법에서 같은 안전한 초기 제어열로 대체하고 실패를 기록했다.
실패 후보를 성공한 최적화 결과로 집계하지 않았다.

3. 목표점과 제약

e_g = [cos(theta_g), sin(theta_g)]^T : gap 중앙의 병진 이동 방향
D_g = max_U e_g^T(p_N-p_0)         : 장애물 제한 없는 도달거리의 국소해
d_g = LiDAR/맵과 로봇 크기를 반영한 해당 방향의 이동 가능 깊이
rho_g = min(D_g, d_g)
q_g = p_0 + rho_g e_g

D_g를 구할 때 heading 비용은 넣지 않는다. omega는 0으로 고정하지 않고,
vx, vy와 함께 결정한다. 모든 단계에서 다음 휠 부하 제한을 만족한다.

  |vx_t| + |vy_t| + 0.19835 |omega_t| <= 0.78

축별 속도 및 가속도 제한도 적용한다. 최종 위치는 gap 중앙선 위에 두고,
진행량은 [max(0.25, rho_g-0.01), rho_g] 범위로 제한한다.
중간 위치의 gap 방향 투영은 d_g 이하. 실제 swept footprint 정적 충돌을 재검사한다.
후진도 e_g가 뒤를 향할 뿐 같은 조건을 쓴다.

SLSQP, 최대 45회, ftol=1e-6, 제약 허용 오차 1e-5.
도달거리와 비용 최적화 모두 비선형 국소 최적화이며 전역 최대/최소 증명은 없다.
비용 품질을 비교하기 위해 이 실험은 50ms seed deadline으로 풀이를 중단하지 않는다.
따라서 실제 deadline/cache/fallback을 포함하는 현재 ROS 실행 결과와 동일시하면 안 된다.

4. 비교한 seed 목적함수

모든 방법은 동적/정적 장애물 비용을 seed 목적함수에서는 제외한다.
정적 장애물은 공통 LiDAR 깊이 제약과 풀이 후 충돌 검사에 반영한다.
정적 soft 비용은 아래 공통 배분 점수 및 기존 500개/최종 대표 평가에는 유지한다.

기호:
  pref : 모든 gap에서 공통인 경로 진행 기준점
  psiref_t : 공통 경로 heading 기준
  eperp_g : gap 중앙 방향에 수직인 단위벡터
  delta_u_t = u_t-u_(t-1), u_0의 이전 입력은 현재 측정 입력
  R = diag(0.5, 0.5, 0.055)

A. current: 현재 가벼운 4항

  J_A = 8 ||p_N-pref||^2
      + (4/N) sum_t [eperp_g^T(p_t-p_0)]^2
      + (3/N) sum_t (psi_t-psiref_t)^2
      + (1/N) sum_t delta_u_t^T R delta_u_t

  순서대로 공통 기준점으로의 진행, gap 중앙선에서 벗어남,
  차체 heading 오차, 입력 변화다. heading은 병진 방향과 다르다.
  뒤쪽 gap이라고 차체를 반드시 뒤로 돌리지는 않는다.

B. smooth: J_B = (1/N) sum delta_u^T R delta_u
  목표점/제약은 그대로 두고 입력 변화만 최소화.

C. smooth_heading: J_C = J_B + (3/N) sum (psi-psiref)^2
  단순한 smooth 비용에 경로 heading만 추가.

D. guide_tracking: A의 중앙선 이탈 항을 시간별 중앙 가이드 추종으로 교체

  pguide_t = p_0 + (t/N) rho_g e_g
  J_D = 8||p_N-pref||^2 + (4/N) sum ||p_t-pguide_t||^2
      + heading + delta

E. existing: 기존 common_costs의 주행 비용을 그대로 최적화

  J_E = J_path + J_progress + J_terminal + J_heading + J_speed + J_delta

  기존 가중치 64, 8, 24, 3, 1.78, [0.5,0.5,0.055] 그대로.
  terminal은 기존 goal 근처 활성 조건을 그대로 적용.
  경로 투영/heading lookahead/속도 기준도 실제 common_costs 호출을 사용.
  목적함수 미분은 30개 입력변수에 대한 batched finite difference이다.
  계산 시간이 늘어난 결과는 이 구현에 대한 측정이며, 모든 최적화 기법의
  불가피한 하한이라는 뜻은 아니다.

F. linearized_common: E의 1회 Gauss-Newton 근사 (추가 검증)

  J_E(U) = ||r(U)||^2
  J_F(U) = ||r(U_neutral) + Dr(U_neutral)(U-U_neutral)||^2

  E의 가중 잔차를 공통 초기 제어열에서 한 번만 선형화한다.
  목적함수는 제어열에 대한 이차식이며, 실제 비선형 동역학/제약은 유지한다.
  이 잔차 제곱합이 원래 common_costs 값과 같음을 수치 검사했다.
  새로 제안한 실험용 근사이지 아래 논문의 구현을 그대로 복제한 것은 아니다.

5. 연구에서 가져온 설계 근거

Batch Non-Holonomic Trajectory Optimization / Multi-Modal MPC (RA-L 2022)
https://arxiv.org/pdf/2109.10392
다중 목표점으로 궤적을 최적화하며 생성 목적함수와 meta-cost를 구분한다.
원문 생성 비용은 가속도/heading 가속도의 제곱합이다. 우리의 B/C는 메카넘
입력 변화와 heading으로 적용한 변형이며 논문과 같은 식/동역학은 아니다.

AERO-MPPI (2025 preprint v1)
https://arxiv.org/html/2509.17340v1
가이드별 추종 비용과 최종 비교 기준을 구분하는 구조를 D의 비교 근거로 사용.
원문은 다항식 guide와 드론 모델을 사용하므로 우리의 gap seed SLSQP와 다르다.

Topology-Driven Parallel Trajectory Optimization / T-MPC++ (T-RO 2024)
https://arxiv.org/html/2401.06021v2
서로 다른 guidance에 공통 주행 목적을 적용하는 구조를 E의 근거로 사용.
원문은 contour/lag, 속도, 입력 비용과 위상 제약을 사용한다.
우리의 LiDAR 각도 gap은 논문의 homotopy class와 같은 보장을 갖지 않는다.

세 논문이 우리의 'seed 비용 softmax에 따른 샘플 수 배분'을 검증해 주는 것은 아니다.
그 규칙은 별도의 실험 가설로 취급했다.

6. 배분 규칙 세 가지

M은 nominal까지 포함한 그룹 수, f=[100,30,...,30], B=500-sum(f).
동일한 f를 먼저 보장하고 남은 B개를 다음 비율로 배분했다.

uniform: pi_i = 1/M
  4개 그룹일 때 [178,108,107,107]. 전체를 125개씩 나눈 비교가 아니다.

native: 각 방법의 최적화 목적함수 값을 J_i로 사용.
common: 완성된 seed를 기존 common_costs + static soft로 다시 평가한 J_i 사용.
  동적 비용은 둘 다 배분 점수에 넣지 않는다.

  tau = max(1, median_i(J_i-min_j J_j))
  pi_i = 0.2/M + 0.8 exp(-(J_i-Jmin)/tau) / sum_j exp(-(J_j-Jmin)/tau)
  n_i = f_i + floor(B*pi_i) + 최대 나머지 순서로 1개씩 보정

nominal도 같은 규칙으로 점수를 매긴다. native에서 중앙선/가이드가 필요한 경우
nominal의 자체 종단 방향/거리로 가이드를 정의한다. 공통 진행 기준점은 바꾸지 않는다.
E와 F의 common에는 static soft가 추가되므로 native와 같은 배분이라는 보장은 없다.

이번 집합에서 native가 전체적으로 더 좋다는 결과는 나오지 않았다.

특정 seed의 비용은 그 주변에 샘플을 추가했을 때 얻을 개선량을 직접 나타내지 않는다.

익숙한 실제 b2_060 장면 (8개 노이즈 평균):
  현재 seed + uniform:  [178,108,107,107] -> 최종 비용 2.0299
  현재 seed + native:   [138,173,143, 46] -> 최종 비용 1.9731
  현재 seed + common:   [136,147,171, 46] -> 최종 비용 2.0172
  기존 주행 비용 seed + uniform: [178,108,107,107] -> 1.9851
  기존 주행 비용 seed + native:  [141,137,176, 46] -> 2.0048

이 장면에서는 현재 native가 uniform보다 좋다. 그러나 이것만으로 전체 배분 규칙을
확정하면 안 된다. 특히 common 점수는 G2를 G1보다 낮게 평가하여 G2에 더 배분하지만,
실제 MPPI 최종 선택은 G1이다. seed 점수와 주변 샘플의 가치를 구분해야 한다.

9. 계산 주기

단계별 중앙값을 더한 추정이 아니라, geometry/두 번의 도달거리 계산/한 가지 비용으로
seed 생성/배분/500개 MPPI/최종 대표 평가를 순서대로 실행한 실제 시간을 측정했다.
48회/방법, cache 없이 모두 새로 계산, 기존 180ms deadline 중단은 적용하지 않았다.
ROS 콜백/TF/deskew/퍼블리시/다른 노드의 부하는 제외했다.

방법                   평균        p95         최대        200ms 초과
A 현재 4항             135.9ms     190.4ms     220.6ms       1/48
B 입력 변화만          136.3ms     203.7ms     210.5ms       3/48

D 중앙 가이드 추종     135.1ms     194.5ms     195.5ms       0/48

E를 이 구현 그대로 매 주기 모든 gap에 직접 푸는 것은 5Hz 목표에 맞지 않는다.
A 역시 이번 무제한 재계산 실험으로 전체 시스템의 5Hz를 보장할 수 없다.
운영의 50ms seed budget, 재검증 cache, fallback을 유지한 별도 통합 측정이 필요하다.
C/D에서 200ms 초과가 0이었다는 결과도 실제 ROS 5Hz 보장이 아니다.

10. 이번 결과로 정하는 방안

seed 목적함수: 당장은 A의 가벼운 4항을 유지한다.
  E는 gap 대표를 개선하는 근거가 있으므로 연구 비교 기준으로 보관한다.
  다만 현재 직접 수치미분 최적화를 운영 주기에 넣지는 않는다.
  F의 단발 근사는 빨라졌지만 gap 대표 평균은 악화되어 채택하지 않는다.
  D는 최종 비용 차이가 작고 계산 이득이 없어 현재 것을 교체할 근거가 부족하다.

배분: 현재 softmax 배분의 우위는 미검증이다.
  nominal/gap 최소 수량 보장을 유지하고, uniform을 대등한 대조군으로 남긴다.
  이번 결과만으로 비용 집중을 더 강하게 하거나 비싼 gap을 버리지는 않는다.
  gap 최적화 비용의 의미는 '그 endpoint에 도달하는 seed의 주행 적합도'이며,
  '그 gap에 샘플을 1개 더 썼을 때 얻을 개선량'과 같지 않다.

평가 비용: 모든 500개 및 최종 대표의 기존 비용과 안전 검사는 유지한다.
  이번 실험으로 64/8/3/1.78 등 운영 가중치를 다시 튜닝하지 않았다.

11. 검증과 한계

- 2,432회 모두 500개 평가, 동일 기존 선택 안전 검사 통과.
- trial 0의 304개 저장 batch, 152,000개 제어열에 속도/가속도/휠 제한 확인.
- 모든 방법/배분의 nominal 샘플 공통 prefix가 bitwise 동일함을 확인.
- 새 해석 미분/이차 근사의 gradient를 중앙차분과 대조, 최대 오차 4.51e-9.
- 기존 evaluator 및 YAML 파일 SHA-256이 전후 동일함을 확인.
- 선택 대표의 동적 충돌 확률 최댓값은 1.88e-10으로 매우 낮았다.
  이 데이터는 동적 위험이 큰 회피 상황의 우열을 검증하기에 부족하다.
- 정지 snapshot의 1-step 계획 비교다. 충돌률, 목적지 도달률, 실제 후진 탈출 성공률,
  시간적 전환 빈도, full-stack 5Hz가 검증된 것은 아니다.
- SLSQP 실패/초기값 의존성, 현재 기준으로 고정한 gap 선택, 소수 장면과 고정 가중치의
  한계를 갖는다. 후보/가중치 전 공간의 최적 비용함수를 찾았다는 주장은 하지 않는다.
