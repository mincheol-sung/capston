# 제어입력 직접 샘플링과 cubic B-spline 비교 — 2026-10-27

500개 후보 × 10개 구간 × 제어3축(vx,vy,yaw_rate), 최종 배열(500,10,3)을 생성하는 비용을 측정했다. 충돌확률 MC, 비용 평가, 제어 제한 투영, 로봇 rollout은 샘플 생성 시간에 포함하지 않았다.

## 조건

- Intel Core 5 210H, NumPy1.26.4, SciPy1.11.4, BLAS/OMP1 thread.
- guide_noise_std=[0.15,0.12,0.45], seed7. 각 방법 warmup20회, 측정1000회. 매 반복마다 실행 순서를 회전했다.
- 모든 방법은 시간별 제어 잡음을 출력한다. 기준 제어입력에 더하는 연산은 제외했다.
- 독립 Gaussian: NumPy default_rng.standard_normal((500,10,3))*std.
- 직접 Halton: 현재 구현과 같은 scrambled Halton/clip/ndtri/scale, 차원은10×3=30. 시간별 spline 보간은 하지 않는다.
- 현재 spline: HaltonSplineSampler.sample(500) 그대로 사용. 4점×3축=12차원 Halton을 정규변환한 뒤 make_interp_spline(k=3)으로10시점 보간.
- sampler/engine 생성은 아래 샘플 생성 비교에서 제외. 현재5개 캐시 초기화 측정에는 생성 비용도 포함.

## 샘플 생성시간

| 방법 | 평균(ms) | 중앙값(ms) | p95(ms) |
|---|---:|---:|---:|
| 직접 독립 Gaussian | 0.135925 | 0.135292 | 0.140209 |
| 직접 Halton30차원 | 0.593061 | 0.592387 | 0.607246 |
| 현재 cubic spline/Halton12차원 | 0.507478 | 0.505081 | 0.523562 |

- spline은 독립 Gaussian보다 3.73배 느림. 차이는 0.372ms/500개.
- 동일 Halton 기반 직접 생성 대비 spline은 14.4% 빠름. Halton 생성 및 ndtri 차원이30→12로 줄어 보간 비용을 상쇄했다.

## 계산량

| 항목 | 직접 샘플링 | cubic spline |
|---|---:|---:|
| 후보당 샘플 차원 | 10×3=30 | 4×3=12 |
| 500개에 필요한 Gaussian 값 | 15,000 | 6,000 |
| 추가 보간 | 없음 | 1,500개의 4점 시퀀스를10시점으로 cubic 보간 |
| 출력 실수 수 | 15,000 | 15,000 |
| float64 출력 배열 크기 | 120,000bytes | 120,000bytes |

같은 Halton 방식에서 표본 좌표 생성/역정규 CDF 평가 수는60% 줄지만, spline 계수 계산과 평가가 추가된다. 3차 B-spline 평가는 출력당 최대4개 계수의 가중합으로 표현할 수 있다. 라이브러리 내부의 해법·메모리 복사·벡터화 비용 때문에 이를 정확한 FLOP 카운터로 환산하지는 않았다. NumPy 독립 Gaussian은 Halton+ndtri와 다른 난수 생성 알고리즘이므로 표본 개수만으로 연산시간을 비교할 수 없다.

## 현재 guide 구현의 실제 호출 시점

guide_conditioned.py는 생성자에서5개 가이드용 spline 잡음 배열을 미리 만든다. 각각498개씩 총2490개 잡음 시퀀스를 보관한다. 매 제어주기마다 sample(500)을 다시 호출하지 않는다.
모든5개 가이드가 활성인 경우 총500개 후보를100개씩 배분한다. 그룹별2개 기준 후보와98개 캐시 잡음 후보로 구성한다. 실제 주기에는 캐시 일부를 읽어 중심 제어입력에 더하고 이후 제어 제한 등을 적용한다.

- 실제와 같은5×498 캐시 생성: 평균 3.936ms (준비1회/측정50회, engine 생성 포함).
- 캐시 잡음 배열 메모리: 597,600bytes (약 583.6KiB).
- 5개 캐시에서98개씩 읽어2개 기준 후보와 합쳐500개 배열을 채우는 별도 축약 측정: 0.056401ms (1000회 평균). 실제 guide 전체 함수의 시간은 아니며 clipping/투영/anchor 생성은 제외.
- 고정된500×10×3 제어입력의 운동모델 rollout만 측정: 0.173752ms. 제어입력 값에 따라 삼각함수 시간 등이 달라질 수 있으며 전체 경로 생성 시간은 아니다.

## 해석

독립 Gaussian이 단순 생성 속도는 가장 빠르다. spline은 표본 차원을 줄이고 시간상 부드러운 잡음을 만드는 것이 목적이며, 독립 시점 잡음과 같은 분포가 아니다. 보간점의 표준편차가 같아도 중간 시점의 분산 및 시간 상관이 달라질 수 있다. 이 측정으로 최적화 품질이나 회피 성능이 동등하다고 판단할 수 없다.
현재 구현에서는 spline이 초기화 때만 계산되므로, 위 0.5ms가 매 제어주기에 추가되는 구조가 아니다. 매 주기 독립 난수를 새로 생성하는 방식과 현재 고정 캐시 재사용 방식은 탐색 다양성도 다르다.
