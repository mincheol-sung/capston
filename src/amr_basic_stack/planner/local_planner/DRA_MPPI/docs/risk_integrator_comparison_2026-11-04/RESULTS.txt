DRA-MPPI: MC와 Gaussian 충돌 원 직접 적분 비교
2026-11-04

결론
- 현재 8배 MC를 전부 직접 적분으로 바꾸는 것은 권장하지 않는다.
  등방 분포에는 매우 유리하지만, 강한 이방성과 많은 사람이 겹치면 더 느리다.
- 우선 적용·후속 검증 후보는 혼합 방식이다.
  1차 500개 rollout: 기존 8배 MC 유지.
  최종 guide 대표 및 Stop(최대 6개): 직접 적분으로 재평가.
  이번 이방 분포 시험에서 전체 optimizer 평균 시간이 약 18~24% 감소했다.
- 직접 적분의 수치 정확도가 훨씬 높아 최종 5% 임계값 판정에도 유리했다.
  단, 1차 MC 오차에 따른 대표 궤적 생성/누락까지 해결하지는 않는다.
- 운영 YAML 및 planner 구현은 변경하지 않았다. 혼합 방식은 시험 도구에서만 구성했다.

1. 시간 비교 방법
- 현재 YAML: guide K500, horizon 10, dt 0.2 s, worker 2, 정적 검사 ON.
- 사람 수 5/20/40명, 사람당 2 Gaussian modes.
- 동일 공간 범위 안에서 사람 수를 늘려 밀집도를 높였다.
- 등방: covariance=0.04 I.
- 보통 이방: covariance=[[0.05,0.025],[0.025,0.025]].
- 강한 이방: 표준편차 0.08/0.8 m, 회전 0.7 rad.
- 매 실행 warm start를 초기화하고 1차 후보 SHA256 일치를 확인했다.
  각 방법의 가중평균 이후 대표 궤적은 다를 수 있다.
- 조건/방법별 warm-up 3회 + 측정 30회. 방법 실행 순서를 교대했다.
- OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1.
- 전체 optimizer 시간이며, 위험 적분만의 시간이 아니다.
  ROS/TF/DDS/perception/MPC 부하 및 실제 주행은 포함하지 않는다.
- offline timeout은 10초로 늘려 느린 결과도 끝까지 측정했다.
  운영 timeout 180 ms에서 해당 결과가 정상 반환된다는 뜻이 아니다.

2. 전체 방식 비교: 평균 ms

직접 적분은 후보×사람×mode×시간별 적분이 필요하다.
MC는 동일 guide/시간의 공간 표본 PDF를 여러 후보가 공유한다.
따라서 후보와 사람이 많고 이방성이 강하면 직접 적분의 계산량이 커질 수 있다.
위 시간 시험에서는 직접 적분 미수렴과 MC 표본 cap 미충족 모두 0이었다.

3. 혼합 방식 추가 비교: 평균 / p95 ms
조건            기존 MC 8배       1차 MC 8배 + 최종 직접 적분
보통 이방 20명   119.8 / 124.5      98.9 / 101.7
보통 이방 40명   186.9 / 193.2     152.9 / 156.9
강한 이방 20명   153.6 / 159.2     120.5 / 123.2
강한 이방 40명   253.5 / 259.0     193.7 / 199.1

최종 평가 평균 시간만 비교하면:
- 보통 이방 20명: 23.7 -> 3.2 ms.
- 보통 이방 40명: 40.4 -> 5.3 ms.
- 강한 이방 20명: 38.0 -> 5.6 ms.
- 강한 이방 40명: 69.2 -> 9.9 ms.

혼합 방식에서도 강한 이방 40명은 30회 모두 180 ms 초과였다.
200 ms 아래라는 이유로 현재 운용 가능하다고 판단하면 안 된다.
사람별 영향 상한을 활용한 계산 생략과 불필요 표본 계산 제거가 추가로 필요하다.

4. 정확도 비교 방법
- 독립적인 극좌표 적분을 기준값으로 사용했다.
  운영 직접 적분은 조건부 Gaussian 1차원 적분이므로 적분 구성이 다르다.
- 기준 적분 차수 96/192의 최대 차이는 7.88e-15였다.
  차수 일치는 엄밀한 오차 증명이 아니므로 절대적인 참값 보장은 아니다.
- 6종 분포: 등방, 보통 이방, 회전된 좁은 이방, 거의 수직인 좁은 이방,
  표준편차 0.08/3.2 m의 매우 긴 이방, 원래 최소축 0.02 m의 floor 적용 사례.
- 사람 수 1/5/20명, 각 2 modes. 두 방식 모두 같은 최소 표준편차 0.08 m 적용.
- 기준 CP 1%, 4.9%, 5.1%, 6%를 갖도록 위치를 설정했다.
- 72개 분포/CP 조건 × 4개 후보 영역 = 288개 질의 형상.
- MC는 3개 seed, guide/final 예산을 각각 검사했다.
  직접 적분은 결정적이므로 seed 반복을 하지 않았다.
- 공분산 보정, mode 가중치, 사람 간 독립 가정, 충돌 반경 0.45 m를 일치시켰다.
- 총 3,744회 평가. 반복 seed와 영역 변화는 독립적인 실세계 장면이 아니다.

5. 최종 평가 예산 기준 정확도
항목                     MC 1배       MC 8배        직접 적분
평균 절대 오차(%p)        0.80982      0.21903       0.0000403
95백분위 절대 오차(%p)    2.35374      0.64898       0.0001188
최대 절대 오차(%p)        4.11312      1.06261       0.0001239
위험을 안전으로 판정      130/432      85/432        0/144
안전을 위험으로 판정      112/432      82/432        0/144

%p는 확률의 퍼센트포인트 차이다. 예: CP 5%를 4%로 계산하면 오차 1%p.
위험을 안전으로 판정: 기준 CP > 5%인데 계산 CP <= 5%인 수치 판정.
MC 8배의 85건 중 83건은 기준 CP 5.1%, 2건은 기준 CP 6%였다.
이는 임계값 근처를 의도적으로 집중 시험한 결과이며 실차 충돌률이 아니다.
직접 적분의 미수렴은 0이었다. 일반적인 안전성이나 예측 정확도 보장은 아니다.

guide 예산 주의:
- 넓은 후보 영역(span 1.5 m, 사각형 면적 15.21 m²)에서는 guide 표본 상한이
  요구 밀도를 충족하지 못해 MC 1배/8배 각각 216/864건을 보수적으로 거부했다.
- 이것은 확률 적분 오차와 구분해야 하므로 accuracy_summary.json에는
  전체 결과와 cap/미수렴 거부를 제외한 결과를 별도로 기록했다.
- 최종 MC 예산은 이번 영역들에서 cap 미충족이 없었다.

6. 권장 후속 단계
- 첫 변경 후보: 최종 대표/Stop 평가만 직접 적분으로 교체하고 1차 MC는 유지.
- 최종 후보 모두에 동일 적분기를 적용하고 기존 정적 검사와 5% 판정을 유지.
- 이후 실제 예측 bag, 폐루프 주행, ROS 전체 callback/발행 간격을 비교.
- 1차 MC에서 좋은 후보가 사라지거나 대표 생성이 왜곡되는 문제는 별도 평가.
- 모든 후보의 직접 적분은 등방성 비중, 사람 수, 공분산 조건에 따라 선택적으로 검토.
- 낮은 예산 MC가 빠르다는 이유만으로 1배로 복원하지 않음.

7. 검증 및 재현
- DRA_MPPI 전체 테스트: 192 passed (3.18 s).
- 원자료 수: timing 810행, hybrid timing 240행, accuracy 3744행.
- 운영 YAML SHA256이 시험 시작/종료 사이 동일함을 확인했다.
- source/config/environment 해시는 각 manifest에 기록했다.
- 최초 timing 실행 당시 도구는 comparison_script_initial.py에 보존했다.
  이후 hybrid 실행 옵션만 추가했으며 기본 timing/accuracy 알고리즘은 동일하다.
