01. 전·후방 LiDAR를 같은 기준으로 맞춥니다
입력의 역할 · 원본/수신 시각 검사 · odometry와 센서 TF를 이용한 보정
사용하는 입력과 역할
전·후방 LiDAR: 장애물 위치와 거리 급변 지점
Traversability 지도: 장애물과 미관측 영역 보완
Odometry: 현재 위치·방향·속도, scan 시간 보정
Global path: 경로 비용과 차체 heading
동적 예측: MPPI의 동적 충돌확률 계산
입력 유효성 조건
각 scan의 원본 시각 나이와 수신 후 경과시간 ≤ 0.25초
전·후방 scan의 시각 차이 ≤ 0.05초
로봇 이동을 고려해 beam마다 odometry를 보간합니다.
센서 장착 위치·방향은 TF로 반영합니다.
입력이 불충분하면
odometry로 보정할 수 없는 beam은 사용하지 않습니다.
입력 누락·만료·TF/보정 실패이면 해당 주기는 hold합니다.
이 그림은 저장된 시간 보정 좌표를 재사용했습니다.
온라인 freshness/TF 검사를 다시 실행한 결과는 아닙니다.
결과: 실제 입력: 전방 1,752개 + 후방 1,804개 유효 beam. 원본 장면 audit의 예측 객체 수는 0개입니다.

02. 로봇이 실제로 들어갈 수 있는 공간을 계산합니다
LiDAR 측정 거리 r와 로봇 중심의 이동 가능 거리 d(θ)는 구분합니다.
로봇 중심의 로컬 지도
8m × 8m, 해상도 4cm의 로컬 지도를 만듭니다.
라이다 관측을 넣고 미관측 영역은 유효 지도로 보완합니다.
장애물 정보는 유지하고, 남은 unknown은 막힌 영역입니다.
방향별 이동 가능 거리
360도 전체를 1도 간격으로 확인합니다.
최대 확인 거리 2m, 거리 간격 2cm입니다.
로봇 반경 0.20m와 추가 여유 0.05m를 적용합니다.
격자·swept 검사에 필요한 보수적인 여유도 반영됩니다.
d(\theta)\geq 0.5\,\mathrm{m}
d(θ): 해당 방향으로 로봇 중심이 이동 가능한 거리
위 조건을 만족하는 방향들을 연결해 열린 구역을 만듭니다.
연속 구간 폭이 최소 6도인 경우에만 유지합니다.
결과: 실제 결과: 열린 연결 구간 3개. 이 단계에서는 아직 raw 거리 급변으로 추가 분할하지 않았습니다.

03. 열린 공간을 거리 급변 지점에서 나눕니다
raw LiDAR 거리 급변 + 지속성 + 로봇 이동 공간 변화 → gap 경계
앞서 설명한 거리 급변 기준
|r_{i+1}-r_i|\geq\max(0.4\,\mathrm{m},\;0.12\min(r_i,r_{i+1}))
r: 같은 센서의 인접 beam 측정 거리
40cm 이상 급변을 찾고, 먼 물체는 거리 비례 기준을 적용합니다.
구현에서는 양쪽 3-beam 중앙값으로 안정화
T=\max(0.4\,\mathrm{m},\;0.12\min(\tilde r_L,\tilde r_R))
실제 코드의 비례 기준은 인접값 대신 양쪽 중앙값을 씁니다.
인접 차이와 중앙값 차이 모두 T 이상, 변화 방향도 같아야 합니다.
양쪽 각 3 beam의 흔들림은 중앙값 차이의 35% 이하여야 합니다.
실제 이동 공간에서도 경계인지 검사
원래 경계 ±8도에서 양쪽 진입 깊이 차이 ≥ 0.25m를 확인합니다.
강한 경계를 우선 남겨 경계 간격 ≥ 20도, 구역 폭 ≥ 6도를 유지합니다.
먼 벽의 거리만 달라지고 이동 공간이 같으면 추가 분할하지 않습니다.
열린 구역이 전혀 없을 때만 추가 여유 5cm를 제거해 재시도합니다.
로봇 반경은 유지합니다. 이번 장면에서는 재시도하지 않았습니다.
결과: 실제 결과: 열린 구간 3개 + 내부 경계 3개 → G1~G6. 앞선 간략 수식과 코드의 중앙값 적용 차이를 함께 명시했습니다.

04. 각 gap 중앙 방향으로 seed를 하나 만듭니다
중앙은 각도 구간의 중앙입니다. XY 영역의 무게중심을 계산하는 방식은 아닙니다.
목표점과 제어열 생성
① gap의 중앙 각도를 구합니다.
② 그 방향의 이동 가능 거리에서 10cm를 남깁니다.
③ 현재 속도와 입력 제약으로 2초 내 도달 거리를 계산합니다.
④ 도달 거리의 약 90%를 반영해 목표점을 정합니다.
⑤ 목표점을 향하는 10-step 제어열을 만듭니다.
u_t=[v_x,\;v_y,\;\omega],\quad\Delta t=0.2\,\mathrm{s},\quad N=10
vx, vy: 차체 기준 병진 속도  /  ω: 차체 회전 속도
속도·가속도·바퀴 속도 제한을 적용합니다.
병진 이동은 gap 중앙을, 차체 yaw는 경로 방향을 따릅니다.
뒤쪽 gap으로 가기 위해 차체를 반드시 뒤로 돌릴 필요는 없습니다.
360도가 하나의 열린 구역일 때
중앙 각도가 없으므로 경로를 약 1m 따라간 점의
방향으로 seed 하나를 만듭니다. 이번 장면에는 해당하지 않습니다.
결과: 실제 결과: 6개 gap에 중앙 seed 6개 생성. 색 실선은 rollout, ×는 목표점, 검은 점선은 기존 nominal입니다.

05. 탐색할 만한가? 먼저 도달 가능성을 검사합니다
최적 경로인지보다, 그 방향으로 실제 움직일 수 있는 중앙 seed인지 확인합니다.
세 조건을 모두 만족해야 합니다
1. 전체 이동 구간의 swept footprint에 정적 충돌이 없음
2. 2초 뒤 위치와 목표점의 거리 ≤ 0.35m
3. 해당 gap 방향으로 이동한 거리 ≥ 0.25m
E_g=\|p_{g,N}-q_g\|\leq0.35\,\mathrm{m}
m_g=(p_{g,N}-p_0)^{\mathsf{T}}e_g\geq0.25\,\mathrm{m}
p0: 현재 위치  /  pg,N: gap seed의 마지막 위치
qg: seed 목표점  /  eg: gap 방향의 단위벡터
후진도 같은 기준입니다
후방 gap이면 eg도 뒤를 향합니다.
뒤로 제대로 이동하면 mg는 양수이므로 같은 기준으로 통과합니다.
이번 장면은 6개 모두 충돌·오차·이동량 조건을 통과했습니다.
중앙 seed 하나에 대한 근사 판단입니다. 중앙이 탈락해도
gap 내부의 모든 경로가 불가능하다는 뜻은 아닙니다.
결과: 실제 G4(165°): 목표 오차 0.078m, gap 방향 이동 0.652m → 후방 후보도 도달 가능성 통과.

06. nominal이 이미 탐색하는 방향을 중복 제거합니다
같은 시간의 XY 위치를 비교합니다. RMS와 마지막 3점 조건을 동시에 만족해야 제외합니다.
nominal은 어디서 오는가?
직전 최종 선택 제어열을 한 step 이동한 값입니다.
최초 실행 또는 reset 직후에는 기존 경로 추종 seed를 사용합니다.
D_{\mathrm{RMS}}=\sqrt{\frac{1}{N}\sum_{t=1}^{N}\|p_{g,t}-p_{\mathrm{nom},t}\|^2}
D_{\mathrm{tail}}=\frac{1}{3}\sum_{t=N-2}^{N}\|p_{g,t}-p_{\mathrm{nom},t}\|
pg,t / pnom,t: 같은 시점의 gap / nominal XY 위치
D_{\mathrm{RMS}}<0.22\,\mathrm{m}\quad\wedge\quad D_{\mathrm{tail}}<0.30\,\mathrm{m}
두 조건을 모두 만족하면 nominal 중복으로 제외합니다.
nominal 자체가 정적 충돌이면 이 중복 제외를 적용하지 않습니다.
이번 장면의 nominal은 정적 충돌이 없어 중복 검사를 적용했습니다.
실제 G5와 G6의 차이
G5: RMS 0.127m AND 끝 3점 0.176m → 중복 제외
G6: RMS 0.192m지만 끝 3점 0.304m → 중복 아님
결과: 실제 결과: G5만 nominal 중복 제외. 후방이라는 이유로 제거한 것이 아니라 기존 nominal과 같은 탐색이기 때문입니다.

07. 필요한 경우에만 비용으로 순위를 정합니다
통과 gap이 3개 이하이고 서로 충분히 다르면 모두 유지합니다.
사전 비용을 계산하는 경우
• 통과한 gap이 3개 초과
• 또는 gap seed끼리 XY RMS 거리가 0.25m 미만으로 겹침
J_{\mathrm{pre}}=J_{\mathrm{common}}+J_{\mathrm{static}}
Jcommon: 경로 오차, 진행량 오차, heading, 속도,
입력 변화량, 목표 근처 종점 오차
Jstatic: 장애물과 가까운 정도에 대한 정적 soft cost
선택 순서
비용이 낮은 후보부터 확인하며 서로 겹치는 후보를 제거하고
최대 3개를 남깁니다. 이 사전 단계에서는 동적 MC를 추가하지 않습니다.
nominal보다 비용이 낮아야 통과한다는 조건도 없습니다.
후진 후보에 대한 의미
후진·우회를 사전에 무조건 제거하지는 않습니다.
다만 후보가 많아 비용 경쟁을 하면 경로 추종 비용 때문에
후진이 밀릴 수 있습니다. 항상 후진을 보존하는 구조는 아닙니다.
결과: 실제 사전 비용: G4 13.18 < G6 14.36 < G3 19.19 < G1 22.89 < G2 27.56. 선택 gap은 G3·G4·G6입니다.

08. 총 500개를 배분하고 그룹별 MPPI를 실행합니다
현재는 비용 비례 배분이 아니라 gap당 고정 100개, 나머지는 nominal입니다.
이동 rollout 예산
K_g=100,\quad K_{\mathrm{nom}}=500-100G,\quad 0\leq G\leq3
G: 선택된 gap 수. 독립 감속 Stop은 최종 검사에 별도로 추가합니다.
이번 장면은 nominal 200개 + G3·G4·G6 각 100개입니다.
그룹별 MPPI
① nominal 또는 중앙 seed 주변에 Halton spline noise 추가
② 입력 제약을 적용하고 각 후보를 rollout
③ 기존 공통 비용 + 정적 비용 + 동적 위험으로 평가
④ MPPI 가중평균으로 그룹별 대표 제어열 하나 생성
기본 2개 worker가 그룹 평가를 나눠 처리합니다.
gap은 sampling의 시작 방향입니다
최적화된 궤적을 gap 안에 묶거나 중앙 목표점에 반드시
도착하도록 강제하지 않습니다. 평균 대표도 다시 검사해야 합니다.
그림은 실제 생성한 전체 500개이며 무효 표본도 포함합니다.
이번 재생에는 동적 예측이 없어 동적 위험 계산이 생략됐습니다.
결과: 실제 결과: nominal 200 + G3 100 + G4 100 + G6 100 = 500개. 그룹별 최적화 뒤 이동 대표는 4개입니다.

09. 대표 궤적 재검사 → 최종 선택 → 다음 nominal
평균 대표의 안전성을 다시 확인합니다. Stop은 유효한 이동 대표가 없을 때 사용하는 대안입니다.
기존 최종 안전 검사를 유지합니다
sampling 동적 위험: Monte Carlo
최종 대표·Stop 동적 위험: Gaussian disk 직접 적분
정적 충돌: 이동 구간 전체의 footprint 검사
이번 재생에는 동적 예측이 없어 동적 검증은 실행하지 않았습니다.
최종 선택 규칙
① 검사를 통과한 이동 대표가 있으면 그중 최저 비용 선택
② 통과한 이동 대표가 없으면 현재 속도에서 감속하는 Stop
③ Stop도 불가하면 no_safe_candidate_hold
Stop은 유효한 이동 대표와 최저 비용을 경쟁하지 않습니다.
출력과 다음 주기 연결
선택한 10-step pose·velocity reference를 MPC에 전달합니다.
직전 최종 선택 제어열을 한 step 이동해 다음 nominal로 씁니다.
U_{\mathrm{nom}}^{\mathrm{next}}=[u_2^*,u_3^*,\ldots,u_N^*,u_N^*]
gap 번호는 매 주기 다시 붙입니다. 이전 번호의 제어열이나
switching hysteresis를 새 구역에 그대로 이어 붙이지 않습니다.
결과: 실제 최종 비용: nominal 6.547 < G4 8.627 < G6 9.545 < G3 15.756. nominal 선택, safety_status=ok(이번 재생 범위).

10. 예외와 시간 제한을 처리합니다
아래 예외는 구현 동작 설명입니다. 이 정상 입력 장면에서 모든 예외를 발생시킨 것은 아닙니다.
계산 제한과 5Hz의 관계
t_{\mathrm{gap+MPPI}}>0.18\,\mathrm{s}\quad\Rightarrow\quad\mathrm{reject\ result\ /\ hold}
T_{\mathrm{cycle}}=\frac{1}{5\,\mathrm{Hz}}=0.20\,\mathrm{s}
0.18초는 늦은 계산 결과를 사용하지 않기 위한 제한입니다.
worker 종료를 기다리는 시간이 있으므로 전체 실행시간을
반드시 0.18초 안으로 제한하는 장치는 아닙니다.
ROS 입출력·TF·동시 실행 부하까지 포함해 5Hz를 확인해야 합니다.
현재까지 확인한 범위
구현 당시 전체 240개 테스트 통과
실제 기록 10개 장면의 gap 경계가 기존 실험과 일치
패키지 빌드 및 세 전략의 ROS 초기화 확인
동적 장애물+ROS 전체 부하의 5Hz 충족은 별도 검증 필요
이번 PNG의 범위
같은 b2_100의 저장된 실제 계산 결과를 그림으로 설명합니다.
동적 예측, 온라인 freshness/TF, 실제 MPC 추종은 재생하지 않았습니다.
다음 nominal은 제어열 shift이며 다음 센서 장면은 아닙니다.
결과: 빈 gap은 정상적인 탐색 결과이며 입력 오류와 다릅니다. 0개면 nominal 탐색을 계속하고, 입력 오류이면 hold합니다.
