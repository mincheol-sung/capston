2026-11-06: 운영 gap의 바퀴 한계 / LiDAR 적용 도달점·비용 분리

구현한 동작

기존에는 ReachProblem에 LiDAR 깊이를 처음부터 넣었다.
이제 각 gap 중앙 방향마다 다음 순서로 별개의 문제를 푼다.

1. LiDAR/장애물 없이 바퀴·축별 속도·가속도 한계로 최대 도달거리 D_g 계산.
   목적함수는 -e_g^T p_N. heading 비용 없음, omega는 자유 최적화 변수.
   현재 제어입력, 실제 비선형 메카넘 적분, 종단의 중앙 방향선 제약을 적용한다.
   초기 제어열도 LiDAR 깊이나 해당 gap의 이전 seed에 의존하지 않도록 생성한다.

2. q_wheel = D_g e_g에 도달하도록 현재 4항 비용을 최적화해 V_wheel 계산.
   이 비교 경로가 실제 장애물을 통과할 수 있어도 wheel 비교 비용은 계산한다.
   이 경로를 곧바로 실행 후보로 채택하지 않는다.

3. rho_g = min(D_g,d_g), q_actual = rho_g e_g 설정.
   LiDAR 제한이 없고 wheel 경로의 중간 깊이 조건도 만족하면 해/비용을 재사용한다.
   LiDAR가 목표점을 줄이거나 중간 깊이 조건을 만족하지 않으면 같은 비용으로
   실제 목표점까지의 문제를 다시 최적화한다. 결과는 U_actual, V_actual이다.

4. U_actual의 제약 적용 후 swept footprint, gap 종단, 깊이, 이동량을 재검사한다.
   통과한 실제 제어열을 같은 4항으로 재평가한 V_actual을 정렬·샘플 배분에 사용한다.
   V_wheel은 비교용 진단값이다. 완료하지 못한 V_actual 대신 V_wheel을 사용하지 않는다.

5. nominal과 최대 3개 gap에 총 500개 샘플을 배분한다.
   최신 확인 내용인 '실제 목표점 비용이 낮은 곳에 더 배분'을 유지했다.
   nominal 최소 100개, gap 최소 30개; 잔여 예산은 20% 균등 + 80% 비용 softmax.
   앞서 별도 실험 후 제안한 완전 균등 잔여 배분으로 바꾸지는 않았다.
   비용 기반 배분의 성능 우위가 검증되었다는 의미는 아니다.

6. 기존 MPPI가 모든 500개 샘플을 평가하고 그룹별 대표를 만든다.
   대표들을 다시 기존 정적·동적 비용/안전 기준으로 평가해 최종 대표를 선택한다.
   이 evaluator 및 그룹 대표 생성·선택 코드는 이번 변경에서 수정하지 않았다.

수식

  D_g = max_U e_g^T p_N
        subject to wheel/box/rate/kinematics and e_perp_g^T p_N = 0

  V_wheel = min_U J_g(U), p_N approximately D_g e_g

  rho_g = min(D_g,d_g)
  V_actual = min_U J_g(U), p_N approximately rho_g e_g,
             e_g^T p_t <= d_g at every step

종단의 along 방향 허용 오차는 1cm, 최소 이동량은 0.25m.
wheel 풀이의 유한 깊이 상한 T*Vmax는 모든 실현 가능한 경로를 포함하는
물리적 상한이며, D_g를 T*Vmax로 대신 계산한 것이 아니다.
||v_world||_2 = ||v_body||_2 <= |vx|+|vy| <= Vmax이므로 이 상한은
LiDAR와 독립적이며 가능 경로를 불필요하게 줄이지 않는다.

  J_g = 8 ||p_N - p_ref||^2
      + 4 mean((e_perp_g^T p_t)^2)
      + 3 mean((psi_t-psi_ref_t)^2)
      + mean(delta_u_t^T diag(0.5,0.5,0.055) delta_u_t)

두 가치 최적화의 p_ref/psi_ref/가중치는 동일하다.
q_actual은 도달해야 할 점이고 p_ref는 공통 주행 평가 기준점이다.
V_wheel=50, V_actual=80으로 나왔다면 샘플 배분 점수는 80이다.
고정 목표점을 바꾸는 문제이므로 짧아질 때 비용이 항상 증가한다는 보장은 없다.
SLSQP의 국소해이며 전역 최대 도달거리/최소 비용을 증명하지 않는다.

시간 제한과 실패 처리

기존 seed 준비/최적화 50ms, MPPI 100ms 예약, 전체 180ms 설정을 유지했다.
세 문제 전체가 이 예산을 공유한다. 모든 gap을 매 주기 끝까지 푼다고 보장하지 않는다.
시간 부족/미수렴/최적화 경로 충돌 시 사전 검증된 이전 seed 또는 규칙 seed를 사용한다.
이 대체 seed의 실제 비용은 다시 계산하지만 최적 비용이라고 표시하지 않는다.
wheel 값만 구한 뒤 actual 풀이가 중단되면 actual_value_cost는 null로 남는다.
전체 cycle의 deadline을 초과하면 기존 방식대로 결과를 폐기한다.

진단 토픽: /dra_mppi/gap_diagnostics

  target_policy: wheel_then_lidar
  allocation_policy: cost_softmax_with_reserves
  value_model: four_term_gap
  global_optimality_certified: false

후보별:
  wheel_distance_m                D_g
  wheel_value_cost                바퀴 한계 목표점의 국소 최적 비용
  actual_target_distance_m        min(D_g,d_g), 풀이 여부와 별도로 구분
  actual_value_cost               실제 목표점의 비용, 미완료면 null
  value_difference                V_actual - V_wheel, 미완료면 null
  lidar_limited                   d_g < D_g 여부
  actual_value_reused_from_wheel  같은 해/비용을 그대로 썼는지
  wheel_trajectory_within_lidar_depth  중간 투영 깊이 조건도 만족하는지
  wheel_reach_status / wheel_value_status / actual_value_status
  optimization_stage             중단된 단계 또는 complete
  cost                           후보 정렬/배분에 실제로 쓰는 점수
  allocation_cost_source         optimized_actual / reused_seed / fallback_seed / none

최적화 계산이 끝났더라도 collision 검사에서 탈락하면 해당 V_actual은 비교용으로
남을 수 있다. 실제 채택 점수는 cost와 allocation_cost_source로 확인해야 한다.
seed_source가 optimized인 경우 cost == actual_value_cost를 assert하여 검증했다.
재사용 cycle에서 과거의 wheel/actual 최적값을 현재 cycle 값으로 복사하지 않는다.
