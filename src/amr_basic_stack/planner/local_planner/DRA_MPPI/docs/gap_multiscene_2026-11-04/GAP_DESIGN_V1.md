# Gap 분할·탐색 후보 선택 확정안 v1

2026-11-04. 이 문서는 당시 확정한 valley 분할·다중 방향 seed 개발 명세를 보존한다. **후속 합의의 현재 초기 설정은 거리 급변 분할 + gap당 중앙 seed 1개이며, [중앙 seed 탐색 가치 기준](midpoint_value_v1/DECISION.txt)을 따른다.** 운영 노드에 적용했다거나 고정 5방향보다 주행 성능이 우수하다는 의미는 아니다. 당시 대응 설정은 [gap_design_v1.json](gap_design_v1.json)이며, 운영 YAML이 아닌 명세 파일이다.

**결정: 깊이 골짜기로 공간 구간을 나누고, 각 구간에서 만든 모든 seed를 합쳐 실행 가능성·nominal 중복·후보 간 중복을 검사한 뒤 기존 비용 순으로 최대 3개를 탐색한다.**

실제 기록 LiDAR로 재현한 [전체 flow PNG](gap_v1_actual_flow/00_full_flow.png), [18단계 상세 그림 모음](gap_v1_actual_flow/00_all_18_steps.png), [그림·수치·재현 코드 ZIP](gap_v1_actual_flow/gap_v1_actual_flow_pngs.zip)을 제공한다. 주 장면과 필터 탈락·gap 재시도·hold 장면까지 총 4개 실제 snapshot이며, 입력과 최종 결과를 기존 오프라인 실험과 대조했다.

## 1. 용어와 입력

- gap: 로봇 중심에서 직선으로 진입할 수 있는 방향들의 각도 구간.
- seed: 한 방향을 향해 실제 제약을 적용해 만든 2초 제어입력열과 궤적.
- guide: MPPI sampling 예산을 배정받은 seed. **하나의 gap에서 둘 이상의 guide를 선택할 수 있다.**
- nominal: 현재 기준 제어입력열. 운영 통합 시 이전 실행용 선택 결과를 현재 시점에 맞춘 warm start를 사용한다. 앞선 오프라인 실험은 기록 reference로 복원했다.
- 입력: 시간·좌표 정렬한 앞/뒤 LiDAR, odometry/TF, 유효한 지도, global path, 현재 속도, nominal, 기존 동적 예측.
- 미확인 영역은 차단한다. 유효한 지도는 scan 관측 빈틈을 보완한다. inf scan을 임의로 긴 free ray로 바꾸지 않는다. 입력이 무효이면 기존 입력 실패 처리를 적용하며, 이를 '유효 입력에서 gap 없음'과 구분한다.

## 2. 공간을 나누는 규칙

1. 360°를 1° 간격으로 평가한다. 각 방향에서 시작점부터 연속해서 몸체가 진입할 수 있는 깊이 `d_free(θ)`를 구한다. 최대 2 m, 거리 표본 간격 0.02 m다.
2. 몸체 반경 0.20 m와 후보 생성용 추가 여유 0.05 m를 반영한다. 격자 해상도 0.04 m에서는 EDT에서 격자 대각선 `sqrt(2)*0.04`와 sweep 보수성 0.01 m를 제외한다. 단순 원시 scan 거리와 다르다.
3. `d_free >= 0.5 m`인 연속 각도 bin들을 원형으로 묶는다. ±180° 경계에서 연결된 구간을 끊지 않는다.
4. 깊이 profile을 Gaussian σ=2 bins로 평활화한다. peak prominence≥0.25 m, peak 간격≥20 bins 조건으로 깊게 열린 방향을 찾고, 인접 peak 사이 최소 깊이 위치에서 구간을 나눈다. 명확한 peak가 없으면 구간 최대값을 대표 peak로 삼는다. 평활화는 분할/방향 검출에만 쓴다.
5. 분할된 구간은 최소 6개 angle bin을 가져야 한다. **1° 표본 6개라는 조건**이며 endpoint 각도차를 정확히 6°로 요구하는 조건이 아니다.

반경 0.5/1.0/1.5 m별로 같은 공간을 gap 후보로 복제하지 않는다. gap은 공간의 위상적 통로를 완벽히 판별한 결과가 아니라, 제한된 직진 깊이로 정의한 탐색 방향 구간이다.

## 3. gap에서 seed를 만드는 규칙

각 gap에서 다음 방향을 최대 3개 사용한다. 같은 angle bin이면 하나만 만든다.

1. 평활화된 깊이 profile의 대표 peak 방향.
2. 구간 중앙 angle bin.
3. 경로를 따라 약 1 m 앞의 점을 향하는 방향과 가장 가까운 gap 내부 angle bin.

각 방향의 가용 목표 거리 `L = max(0.1, d_free(θ)-0.10)`으로 임시 제어열을 만들고, 제약 rollout의 2초 후 변위를 해당 방향에 투영한 도달 거리 `r`을 구한다. 실제 목표 거리는 `min(L, max(0.25, 0.90*r))`로 정한다. 접근 가능성을 보장하는 해석식은 아니므로 이후 목표 오차를 다시 검사한다.

목표 위치를 향한 병진 속도를 만들고, 몸체 heading은 기존 경로 방향을 따른다. 매 step 기존 속도 box·휠 L1·가속도 제약을 적용한다. Horizon은 10 steps, dt=0.2 s다. **여기서 별도의 수치 최적화나 gap당 3개 MPPI를 실행하지 않는다.**

## 4. 탐색 가치 판단: 자격 검사 → 비용 순위 → 중복 제거

### 자격 검사

다음 후보는 제외한다.

| 검사 | 제외 기준 |
|---|---|
| 정적 실행 가능성 | 기존 swept-body 검사에서 장애물·미확인·지도 밖 충돌 |
| 목표 도달성 | 2초 후 목표 위치 오차 > 0.35 m |
| nominal 중복 | 위치 RMS 차이 < 0.22 m **동시에** 마지막 3점 평균 차이 < 0.30 m |

nominal 자체가 정적 충돌하는 경우에는 nominal 중복 검사를 해제한다. 동적 MC는 기존 MPPI rollout 및 최종 공통 재평가에서 처리하며, 후보 생성 단계에서 별도의 MC를 추가하지 않는다.

### 비용 순위와 선택

gap별로 미리 하나를 남기지 않는다. 자격을 통과한 **전체 seed**를 아래 비용의 오름차순으로 정렬한다.

`J_seed = 기존 common_costs 합 + 기존 static soft cost`

정적 충돌 후보는 자격 검사에서 이미 제외된다. common_costs의 경로·진행·terminal·heading·속도·입력 변화량 가중치는 기존 설정을 사용한다. 별도 경로 근접성 R이나 nominal에서 멀수록 주는 보상은 추가하지 않는다.

비용 순서로 보면서, 이미 선택한 guide 중 하나와라도 위치 RMS 차이가 0.25 m 미만이면 중복 제외한다. 나머지를 최대 3개 선택한다. 같은 gap에서 둘 이상 선택해도 된다. 정확한 비용 동률은 gap 순서/angle bin 순서로 결정한다. solver에는 선택 순위와 별개로 결정적인 ID 순서로 넘겨, 동일 후보 집합의 단순 순서 변경이 random stream을 바꾸지 않게 한다. 이 ID는 주기 간 영속적인 공간 ID가 아니다.

**탐색할 가치가 있다는 뜻은 '제약을 지키며 진입 가능한 별개의 움직임이고, 제한된 예산에서 기존 목적함수상 우선순위가 높은 후보'라는 뜻이다. 실제 최종 개선을 보장하는 점수는 아니다.**

- nominal보다 seed 비용이 좋아야만 허용하는 강제 개선량 gate는 사용하지 않는다. 초기 seed 비용만으로 sampling 후 개선 가능성을 기각하지 않는다.
- 후방이라는 이유만으로 배제하지 않는다. 후방 후보를 무조건 하나 보장하는 quota도 사용하지 않는다.
- 3개 미만이면 빈자리를 억지 후보로 채우지 않는다.

## 5. gap이 없는 경우

1. 추가 여유 0.05 m를 적용한 **raw gap이 0개일 때만** 재시도한다.
2. 후보 생성용 추가 0.05 m를 제외하고 한 번 다시 분할한다. 반경 0.20 m, 격자/sweep 보수성, 미확인 차단, 최소 깊이 0.5 m 및 최소 6 bins는 유지한다. 최종 궤적 충돌·MC 기준도 그대로다.
3. raw gap은 존재하지만 seed가 후속 필터에서 모두 제외되었다면 이 여유 재시도는 하지 않는다.
4. 최종 추가 guide가 없으면 nominal만 500 rollout을 사용한다. **gap 없음 자체는 Stop 조건이 아니다.**
5. 최종 안전 이동 후보가 없을 때 기존 Stop/hold 처리를 따른다. 시작점부터 충돌로 판정되면 `no_safe_candidate_hold`가 발생할 수 있으며, 이를 안전한 정지 궤적을 찾았다는 의미로 해석하지 않는다.

## 6. MPPI 예산과 이번 범위

- 구성: nominal 1개 + gap 기반 guide 최대 3개 + 기존 Stop 평가.
- 선택된 추가 guide 수가 `g`이면 각 guide 100 rollout, nominal `500-100*g`. 이동 rollout 총량 500.
- 기존 2 worker 구조와 MC/최종 공통 안전 재평가를 사용한다. guide별로 500 rollout을 새로 추가하지 않는다.
- 공통 비용만 별도 수치 최적화하는 seed는 이번 gap v1 구성에 포함하지 않는다.
- 운영 통합의 gap별 영속 warm start는 별도 구현 항목이며, 새 gap 순번에 다른 과거 gap의 제어열을 재사용해서는 안 된다.

```text
유효 입력 → 방향별 몸체 진입 깊이 → 열린 각도 구간 → 깊이 골짜기 분할
                    ↓ raw gap 0개일 때만 추가 여유 없이 1회 재시도
각 gap의 peak / 중앙 / 경로 방향 seed → 전체 seed 합치기
→ 충돌·도달 불가·nominal 중복 제외
→ 기존 비용 오름차순 → 선택 guide와의 궤적 중복 제외 → 최대 3개
→ nominal과 총 500 rollout 분배 → 기존 MPPI·MC·최종 안전 재평가
```

## 7. 이 규칙으로 고정하는 근거와 검증 한계

이 명세는 `experiment_gap_diversity.py`의 `all_options_hard_fallback` 절차를 기준으로 한다. 앞선 'gap당 대표 하나' 제한은 후방과 전방 움직임을 같은 공간 구간이라는 이유로 압축했다. 전체 seed에서 선택하면 후방 보유 장면이 74→99개, gap 없음 재시도까지 포함하면 102개가 됐다. raw gap 없음 8장면 중 3개에서 후보를 복구했다.

그렇다고 성능 우월성을 확정한 것은 아니다. 최종 비용은 gap당 대표 하나 대비 3장면 개선/111개 유사/10개 악화였고, 주행 성공률을 측정하지 않았다. 선택한 절차의 offline p95는 167.9 ms, 254회 중 6회가 200 ms를 초과했다. **확정한 것은 다음 구현의 알고리즘·초기 수치이며, 안정적인 5 Hz 및 운영 성능 통과 판정은 아니다.**
